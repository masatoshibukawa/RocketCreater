# RocketWright アプリ全体のデモ

Built with Claude: Japan 2026の提出に向け、実アプリの「要求 → 候補 → 検査 → 修正 → 成果物」を一本の利用体験として見せる。現在は**設計・計画段階**で、完成動画はまだ採用していない。

| 保存先 | 内容 | Git |
| --- | --- | --- |
| `AIvideo/product-demo/` | 提出条件、構成、台本、絵コンテ、字幕原稿、制作補助コード | 対象 |
| `output/media/product-demo/` | 収録素材、音声、中間ファイル、試作動画、非公開の確認記録 | 対象外 |
| `assets/product-demo/overview/` | 採用した完成動画、サムネイル、出典、検証記録 | 採用後に対象 |

`current-design/`と`design-revisions/`は設計別CGのまま保つ。アプリの収録と設計別の参考CGを混ぜて、一つの実行の成果と見せない。

## 制作の基準

- [提出条件](requirements.md)：日本語、3分以内、実動作中心。締切は2026年11月8日20:00 JST。
- 本編は**175秒の初稿**を作り、180秒の上限に5秒の余裕を取る。タイトル・無音・余韻も総尺に含める。
- 見せ場は、Claudeが実際の検査結果を受けて候補を選び直す場面。3DやCGは判断と成果物を理解するために使う。
- 実装を読んだこと、実行が成功したこと、収録できたこと、完成映像が確認済みであることを分ける。

提出フォームの最新設問・概要の指定形式と文字数は未確認。計画の作成で課金APIを有効化したり、収録・動画公開・大会提出を行ったりはしない。

`plan.json`を正本とし、台本・絵コンテ・仮字幕は標準Pythonだけで更新できる。

```powershell
python -X utf8 AIvideo/product-demo/tools/prepare.py
python -X utf8 AIvideo/product-demo/tools/prepare.py --check
```

最初のコマンドは、Git対象外の作業用フォルダー、収録ログの空テンプレート、`output/media/product-demo/planning/storyboard.html`の構成ラフも作る。実アプリの収録・モデル呼出・音声生成・動画書出し・公開は行わない。2つ目は計画の時刻、参照、字幕、保存先、未採用状態を確認する。

次は**構成と流れを先に検討する**。台本・絵コンテ・仮字幕は未採用の参考原稿として保留し、流れが決まってから具体化する。その後にS05の「検査→修正→再検査」を実際の一件で試し録りする。完成動画を採用する前に、実行・視聴・権限を別途確認する。
