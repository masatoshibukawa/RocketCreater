## 制作の基準

- [提出条件](requirements.md)：日本語、3分以内、実動作中心。締切は2026年11月8日20:00 JST。
- 本編は**175秒の構成案**とし、180秒の上限に5秒の余裕を取る。タイトル・無音・余韻も総尺に含める。
- 見せ場は、Claudeが実際の検査結果を受けて候補を選び直す場面。3DやCGは判断と成果物を理解するために使う。
- 実装を読んだこと、実行が成功したこと、収録できたこと、完成映像が確認済みであることを分ける。

提出フォームの最新設問・概要の指定形式と文字数は未確認。計画の作成で課金APIを有効化したり、収録・動画公開・大会提出を行ったりはしない。
