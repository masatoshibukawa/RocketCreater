# チーム紹介：2枚の緑の透明スクリーン

必要性を最優先にする最新版では、**課題を伝えた後の00:50〜01:06、16秒**に置く。課題を知った状態で、この2人が取り組む理由へつなぐ。紹介から宇宙への動きもこの16秒に含める。

| 時間 | 画面 |
| --- | --- |
| 00:50–00:52 | 宇宙船のコックピット。緑色の大きい透明スクリーンが2枚起動 |
| 00:52–00:56 | 左の内田大智 / Taichi Uchidaへ注目。氏名と短い本人確認済みの説明 |
| 00:56–01:00 | 右の渋川雅人 / Masato Shibukawaへ注目。同じ文字量・同じ見せ方 |
| 01:00–01:02 | 2画面を一緒に見せ、専門性が合流する |
| 01:02–01:04 | 窓枠を使うマッチカットで宇宙船の外景へ引く |
| 01:04–01:06 | 航跡の光が集まり、設計データへ。次の実アプリへ接続 |

宇宙船が進む案と光が集まる案を一つの短い転換にする。スクリーンを透過型にし、額縁と光を緑で統一する。写真は自然な色を残し、目の高さと顔の大きさをそろえる。氏名・肩書は後から別レイヤーで合成する。船体外形やコックピットの寸法は本制作で固定する。
