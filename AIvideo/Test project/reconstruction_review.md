# RocketWright再現映像の確認

## 出力

RocketWrightの概念機体を工場内に置き、見上げから全体へ移るカメラと、シアン色の技術HUDを重ねた映像を新規に制作した。制作方式はAI支援で記述したBlenderの3Dと、Pythonによる画面合成・音の合成である。拡散モデルによる動画生成は使用していない。

映像は1280×720、30fps、310フレーム。映像ストリームは約10.333秒で、ステレオ音声を含むコンテナは約10.43秒。参照で取得できた映像とフレーム数・fps・画面比率を合わせた。

## 参照と比較した要素

| 要素 | 再現した内容 | 残る差分 |
| --- | --- | --- |
| 主題と構図 | 開いた二つのフェアリング、中央のトラスとノズル、工場の屋根 | 元の機体そのものではなく新規の概念形状。細部と寸法比は異なる |
| カメラ | 天井を大きく含む見上げから、機体全体を見せる傾きの変化 | 元撮影のカメラを厳密に解いたものではなく、観察から設定したパス |
| HUD | 外周フレーム、左上のブランドと説明、右上のバー、中央と右下の図、左下の機体図 | RocketWrightの名称、独自の線画と文字、概念表示へ変更 |
| 状態表示 | 表示レイヤーのバーと有効表示 | 原映像の正常表示や材料説明を、実証された解析結果として流用していない |
| 尺と暗転 | 310フレーム、30fps、暗い冒頭と終盤の黒へのフェード | フェード曲線とパネルの出現は独自の実装で、画素単位では一致しない |
| 質感と背景 | カーボン調の内面、金属の縁、トラス、屋根と黄色い架台 | 撮影素材の使用感や細かな設備の密度、元映像の光学的な見え方は未一致 |
| 音 | 独自のステレオ環境音と短い電子音 | 原音の複製や厳密な音響再現ではない |

## 実施した確認

代表フレームのレンダリングを見て構図を確認してから本番連番を出力した。完成MP4を全310フレームデコードし、時刻付きの抽出画像でHUD、カメラの変化、明るさ、黒への移行を確認した。コーデック、音声トラック、サンプルピーク、冒頭・末尾、ファイルハッシュ、コンテナの文字メタデータはスクリプトで確認した。

音はデジタル信号の有無、チャンネル、長さ、クリッピングを確認した。聴覚的な音質評価と、元映像との画素単位の同一性は確認済みとはしていない。

## 納品範囲の点検

対象は新規MP4、ポスター、Blenderシーン、独自音声、コードと記録を含むプロジェクトZIP。元動画、生のページメタデータ、第三者の抽出フレーム、取得時の署名付きURL、依存ライブラリのバイナリ、連番キャッシュはZIPへ含めない。

MP4のタイトルとコメントはRocketWrightの概念映像として設定し、元入力のメタデータを継承しない。Blenderファイルのバイト列では、不要な助手由来の作業名称とユーザーディレクトリの絶対パスが見つからなかった。プロジェクトのAI支援という説明、参照元、ソフトウェア名、ライセンスの説明は保持した。

ZIPを展開して格納ファイルのハッシュ一致を確認する。リポジトリは通常の開発PRとして更新し、既存の共有履歴、ブランチ名、他者のコメントは変更しない。最終提出としてリポジトリや公開URLを渡す場合は、その提出範囲を対象に別途点検する。
