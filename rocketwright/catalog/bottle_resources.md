# ペットボトルロケットの部材・材料・機材

[候補データ](bottle_resources.yaml)は、従来の「何を変える／どう解析する／何で評価する」に対して、**何を使って作るか、何を使って確かめるか**を供給する。部材・材料・機材は三つの解析層すべてから参照できる。機材の購入費と、実際に機体に載せた部品の質量や費用は別に集計する。

| 棚 | 今回の候補例 | 何を選び分けるか |
| --- | --- | --- |
| 部材 | 炭酸飲料用 PET、コカ・コーラ 1.5 L／2 L、タカギ A401 機体セット | 容量の指定、機体の構成、ノズル・発射台との適合 |
| 材料 | 尾翼の PP 板・牛乳パック板紙・CFRP 板、ノーズの画用紙、回収傘の薄膜・布、炭素繊維の品番 | 同じ形状で作ったときの質量・剛性・回収傘の開きやすさ |
| 機材 | 尾翼の取付治具、A400 の発射台、手動ポンプ、はかり 2 種、ノギス、六軸 IMU | 工作・発射の適合条件、測れる範囲、必要な精度と記録条件 |

## 粒度は、解析層とは独立に選ぶ

- **ボトル：** 炭酸飲料用 PET（種類）→ 日本向けコカ・コーラ 2 L（商品）→ 手元でラベルを確認したボトル（現物）。商品の容量表示は飲料の公称量。口部形状、実内容積、空質量、許容圧力は別の情報。メーカーの過去の製品掲載は、今の手元在庫や別ロットとの同一性を示さない。
- **カーボン：** 炭素繊維 → T700SC → T700SC 12K 50C（原糸の仕様）。12K は一束のフィラメント数で、板厚や積層数ではない。完成した板を買う場合は別の枝を使う。例は CFRP 板 → 蕨山Carbon SN010-T-G（公称 1 mm）→ 切り出したフィン。原糸と板の組み合わせを示す根拠がない限り、両者を結び付けない。固有振動数を求めたい場合は、方向別の曲げ剛性と実際の取付条件を追加するか、取り付けた状態で応答を測る。
- **機材：** 質量測定 → HL-200i（型式）→ 校正状態がわかる手元のはかり（個体）。最小表示だけでは測定の不確かさは決まらない。

各行の `id` は候補の識別子、`shelf` は棚、`level` は種類・仕様・原材料等級・製品の粒度。`parent_id` は同じ対象を絞る関係、`part_family_id` は従来の概算部品表への参照で、どちらも物性の継承ではない。`facts` は出典で確認した仕様、`needs` は目的に応じて現物・資料・試験で補う入力。現物を入手したら、試行記録に以下を追記する。初期カタログには所持を確認した現物はない。

| 現物に残す記録 | 例 |
| --- | --- |
| どの個体か | 候補 ID、個体 ID、ラベル／品番、ロットまたは識別写真、入手日、数量、状態 |
| 何を測ったか | 値・単位・不確かさ、部品単体か組立後か、方向、測定日、機材の個体 ID、測定記録 |
| どの判断に使えるか | 適用範囲、適合を確認した相手部品、未確認項目、価格が必要なら日付・数量を伴う見積り |

## 解析から候補を引く例

既存の `search_catalog` に `{"tier":"bottle","kind":"resources","query":"mass_measurement"}` を渡すと、はかりの型式・ひょう量・最小表示と確認項目を引ける。`fins` なら尾翼に関わる部材・材料・機材、`vibration` なら計測用センサ、`null` なら全候補。検索結果は候補で、実機への採用判定ではない。

| 上位の要求・手元の条件 | 今回の候補をどう使うか | 次の層に渡す証拠 |
| --- | --- | --- |
| 1.5 L 限定の既存機と比較 | 2 L 品はこの試行では除外。容量自由の別試行なら空質量、実内容積、胴径、口部を測る | 個体 ID と実測値。発射台との適合や許容運用条件は機材資料で別に確認 |
| 搭載物は 60 g。質量を 0.1 g 刻みで読みたい | HL-200i は 200 g／0.1 g。治具込みの荷重がひょう量内か確認。HL-2000i は 2000 g／1 g なので表示条件を満たさない | 校正状態、支持条件、繰り返し測定から得た質量と不確かさ |
| 組立品が 350 g で同じ表示条件 | HL-200i は過荷重、HL-2000i は表示が粗い。登録済みの 2 台には適合候補なし | 350 g 以上を載せられ、要求精度を満たす別機種の登録を求める |
| フィンを替えた後の姿勢・振動が気になる | 低層でフィン単体の質量・剛性、中層で取付後のモードと減衰、高層で搭載位置の加速度・角速度を比較 | IMU 単体を記録計と見なさず、帯域・サンプル周期・飽和・固定・搭載質量を含む時系列と試験条件 |

資料の起点は [D01 基本型](https://www.yac-j.com/wp-content/uploads/2024/11/1-1.pdf)、[D02 回収傘付き](https://www.yac-j.com/wp-content/uploads/2024/11/1-2.pdf)、[P01 発射台を含むキット](https://prd1.takagi-member.jp/store/products/detail/248)、[P02 機体セット](https://prd1.takagi-member.jp/store/products/detail/249)。それ以外の銘柄・品番・機器仕様は候補データの各行に一次資料を記した。
