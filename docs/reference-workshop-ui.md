# Reference workshop UI

The current-design production extension is documented in [saved design production](design-production-flow.md):
editable persistent revisions, CAD-derived mass, adoption, assembly PDFs, S5 packages and local films.
The reference library remains separate. The older boundaries below describe the original workshop
rebuild; persistent projects and current-design film/manual production are now connected by this extension.

The active Next.js home screen follows the docked workshop in
`final output ui example/ux-spec.md`, its design tokens and drafts 01, 04, 07 and 08.
The reference is a whole-screen composition: dark continuous docks, the stage bar,
a large model or analysis screen, a context-sensitive object list and explanation/chat.
The guides occupy the workshop foreground rather than a separate dashboard card.

## Connected behavior

- The stage bar offers conditions, design, analysis, comparison, assembly preparation
  and output. Navigation never initiates a design, CFD calculation or print job.
- Design streaming, source IDs, requirement values and pass/fail checks are unchanged.
  The right consultation remains mounted so draft text survives stage changes.
- The model, side view, flow analysis, flight playback and altitude plot use backend
  results. Model/guide motion and the character visibility preference are independent
  of computation. A manual model refit and a larger central workspace are available.
- The comparison shows only received candidates. Selecting one updates the context,
  results and production gate. A failed candidate is never labeled as passing.
- Production files are generated by the existing package API. Its returned PDF,
  Markdown, JSON, CSV and SVG links appear in the left dock only for that request.
  Manufacturing files use the existing design-specific S5 geometry/slice endpoint;
  their returned links belong to the same displayed design.
- The project bar saves the displayed design and source-linked metrics as JSON.
  The header says it is a session draft; it does not claim durable project storage.
- Validated reference films are read through the existing media library. They retain
  the reference case label, and current-candidate metrics are hidden beside them.
  Missing files are shown as unavailable rather than completed exports.
- On a narrow screen, the object dock opens as a drawer; focus enters it and Escape
  returns to the trigger. Explanation/chat sit below the central figure. Display
  settings use a native modal dialog with normal Escape behavior.

## Deliberate boundaries

The concept model remains a dimensional illustration, not manufacturing CAD.
The idle workshop picture is labeled as an illustration, not a generated design.
Assembly preparation does not assert hand/tool clearance, physical verification,
or completed assembly steps. Saved design projects now provide explicit dimensions,
CAD-derived mass, persistent editable versions and adopted-version films/manuals.
Reference-case artifacts remain separately labeled.
