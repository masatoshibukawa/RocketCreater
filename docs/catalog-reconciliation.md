# 候補・文献の統合記録

旧ローカル保存の`bottle_variables.yaml`と`bottle_literature.yaml`を、現在の
`bottle_analysis.yaml`を維持したまま追加した。旧agent loopは復元していない。
`GET /design-projects/catalog`から同じ比較記録を取得できる。

- 直接使える設計入力、環境入力、フィン実寸は、現在の保存スキーマへ明示的に対応させる。
  m→mmは1000倍。容量から実測径を補わない。乾燥質量はCAD/実測からハーネスが求める。
- `simulate_design`、`estimate_cost`、`run_dispersion`は既存ツールの有無を照合する。
  旧評価パスは参考契約として保持し、現在の保存案件の要求判定へ流用しない。
  特に旧価格推定は見積・調達費として合格根拠にしない。
- 文献由来の湿り空気、ノズル過渡、空力極線、傘展開、ロバスト設計、飛行再現の6契約は
  `planned`。実行登録や検証済み表示を追加しない。予約変数と必要な測定条件は残す。
- 各参照IDと評価の観測量が存在することを検査する。現行の有限候補プールは自身の
  依存・対象・手法・評価の整合検査を使う。API応答には内容ハッシュを付ける。
- 確定済みの印刷信頼性skillsを取り込んだ。ブリム・速度・材料の推奨値と実機確認は
  同一視しない。今回は利用者の指示により新規の実機確認を行わない。

これは出典と実行可能性の統合であり、文献の実験を本機で再現した記録ではない。
