## 根拠の読み分け

- **研究知見:** 実験やメタ分析で、理解・記憶などへの効果を調べたもの。教育場面の結果を、投資判断や受賞確率へ直接換算しない。
- **実務ガイド:** 投資家、大学、主催者、指導者の経験に基づく助言。対象の聴衆と発表時間を確認して使う。
- **大会条件と講評:** 募集要項、審査基準、主催者・参加者への取材。開催回や賞によって条件が異なる。
- **制作への適用:** 資料を踏まえたチーム向けの作り方。効果を実測した結果として扱わず、初見の人に試して修正する。

## 制作で優先すること

1. 発表後に、誰に何を理解・判断・行動してほしいかを一文にする。
2. 一番伝えたい主張と、それを確かめられる証拠を対応させる。
3. 動画や実演では、利用者の入力から成果まで一つの流れを見せる。
4. 画像・数字・用語を、説明の対象と近い場所・タイミングに置く。
5. 声を出して練習し、初見の人が説明し直せない部分を直す。

## 調査範囲

38件の公式ガイド、研究論文の該当箇所・摘要、審査員への取材、受賞者紹介を使用した。参考映像の全編視聴による演出分析や、非公開の採点理由の再現は行っていない。各出典の確認範囲は[出典一覧](sources.md)に記載した。

日本語・英語の実務資料と言語・文化に関する研究を照合する。ある言語で書かれたガイドを、その国の聴衆全体の好みの証拠として扱わない。
