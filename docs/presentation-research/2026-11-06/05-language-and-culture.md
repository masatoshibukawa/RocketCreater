# 言語と文化と聴衆に合わせる

## 調整する条件を具体化する

文化、専門分野、組織、使用言語への習熟度、発表形式は、説明の受け取られ方に影響する。ただし、国籍から個々の聴衆の好みを決めない。

高文脈・低文脈という枠組みの国別分類を検討したレビューは、分類を支える証拠の弱さや矛盾を指摘している。文化価値に合わせた広告を扱うメタ分析も、平均的効果の小ささと実務への助言の不安定さを報告する。後者は広告研究であり、プレゼンの直接実験ではない。[S25](https://dspace.stir.ac.uk/handle/1893/3174)、[S26](https://journals.sagepub.com/doi/10.1177/23294884231199088)

制作では、対象者について次の条件を確認する。

| 条件 | 調べること | 調整するもの |
| --- | --- | --- |
| 共通の知識 | 製品、課題、専門用語を知っているか | 定義、背景、具体例 |
| 判断の目的 | 学術的な妥当性、導入、投資、受賞のどれか | 証拠と説明の順序 |
| 使用言語 | 母語か、第二言語か、翻訳を使うか | 文の長さ、話速、字幕 |
| 組織と役割 | 意思決定者、利用者、専門審査員のどれか | 依頼、責任、技術の深さ |
| 慣習と形式 | 質問のタイミング、持ち時間、求める形式 | 敬意の示し方、交代、質疑の準備 |

## 日本語と英語での制作案

| 場面 | 試す方法 | 避ける曖昧さ |
| --- | --- | --- |
| 日本語の短いピッチ | 対象、できること、結論を早く示す | 主語が変わっても省略し続ける |
| 日本語の技術説明 | 専門用語と図の対象を対応させる | 「これ」「こちら」だけで指す |
| 英語の国際ピッチ | 短い文、一貫した用語、明示的な移行表現を使う | 慣用句、長い従属節、文化依存の冗談 |
| 多言語の聴衆 | 入力、処理、結果を視覚でも追えるようにする | 言語ごとに異なる機能名や単位 |
| 翻訳を介する発表 | 文と話題の区切りを明確にし、間を取る | 同時に話し続ける、途中で文を言い換え続ける |

これらは国民性の記述ではなく、理解の障害を減らす制作案である。日本語の大学教材にも、聴衆の知識、ページの結論、図の近くの説明、発表練習を重視する助言がある。[S37](https://ss.scphys.kyoto-u.ac.jp/legacy_QM.php?p=%2Feducation%2Fb4%2Fhandout%2F2019-2%2FB4_s1.pdf)、[S38](https://www.graco.c.u-tokyo.ac.jp/labs/morihata/presentation_memo.htm)

## 英語は理解できた内容で確かめる

MunroとDerwingの実験は、訛りの強さ、理解しやすさの評定、実際の聞き取りを分けて調べ、強い訛りが必ずしも低い理解可能性を意味しないと報告している。特定の話者・聞き手集団の研究であり、全アクセントが同じ効果を持つという結果ではない。[S27](https://onlinelibrary.wiley.com/doi/10.1111/j.1467-1770.1995.tb00963.x)

練習では、機能名、数字、単位、否定、比較対象が正しく伝わったかを聞き手に説明し直してもらう。発音の印象だけで評価しない。

## 字幕は短くすればよいとは限らない

第二言語のフランス語動画を見た大学生の実験では、全文字幕の群が、字幕なし・キーワード字幕の群より全体理解の問いで良い成績を示した。一方、音声を参照できる詳細理解の問いでは群間差がなかった。キーワードだけにすることを普遍的な改善策にしない。[S28](https://eric.ed.gov/?id=EJ1020100)

W3Cは、同言語の字幕と翻訳字幕を区別し、理解に必要な発話・音情報を同期して提供する方法を示す。Section508.govも、表示時間と同期、意味のある音の表現を求める。[S21](https://www.w3.org/WAI/media/av/captions/)、[S22](https://www.section508.gov/create/captions-transcripts/)

制作では次を確認する。

- 同言語字幕を正確に作り、機能名・固有名・数字を校正する。
- 翻訳字幕は意味を保ち、画面上の機能名との対応を固定する。
- 日英の長文を同時に焼き込む前に、言語を選べる字幕トラックを検討する。
- 字幕と重要なUIが重ならない領域を確保する。
- 読み切れないときは、まず発話と編集の密度を調整する。

## 主張と謙遜とユーモア

実装済み、検証済み、仮説、将来案を言い分ける。自信は、確認できた範囲を明確に述べることで示す。「自分たちだけができる」は、経験や洞察によって実際に変わった設計で説明する。

ユーモアは、訳したときの意味、背景知識、対象者を確認する。内輪の冗談を理解しなくても主張が追えるようにする。敬意や形式の期待は、主催者や対象者に確認できる範囲で合わせる。

## 対象者に試す

同じ内容を、専門家、専門外の人、使用言語が第二言語の人に見せる。誰がどこで止まったかを記録し、前提知識、言語、図、情報密度のどれが原因かを切り分ける。国籍だけに理由を求めず、説明の修正で確かめる。
