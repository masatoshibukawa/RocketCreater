# 統合版が引き継ぐ設計・制作の根拠

2026-11-06に関連する設計、動画制作、UI・出力仕様のチャットの最新完了内容とリポジトリを照合した。個別の作例や条件付き解析を、現在選択している設計の実機実証と混同しない。

| 元の作業 | 引き継ぐもの | 統合版での扱い |
| --- | --- | --- |
| AIvideoの写真調制作 | HDRI、地面の写真素材、透明PET、地上カメラ、CC0出典、全フレーム検査 | `realism/appearance.py` を共有。現在の製作ファイルの寸法・計算軌跡を使って新しく描画。固定2 Lの16秒／12秒作例は資料ライブラリで区別 |
| ペトロケの具体的材料・取付案 | G10FR4フィン、PETG外付けクランプ、追加質量、CFD・構造・安定性の適用条件 | [具体案の結果](../scenarios/concrete_fin/RESULTS.md) と [材料カタログ](../rocketwright/catalog/bottle_concrete_fin.yaml) を保持。PLA印刷による置換は別の質量・構造条件なので再解析が必要 |
| UI・出力内容の設計 | 工程・版と根拠の分離、組立PDF、JSON/CSV、ファイル整合検査、閲覧と実作業完了の分離 | 製作フローのrevision・ハッシュ検査、組立PDF、部品・図面・解析ファイル、動画・印刷データの保存へ接続 |
| S5フィン実機試作 | 初層密着後の終盤転倒、7 mmブリムと隙間、実映像・観察 | [失敗記録](../assets/print-trials/2026-11-06-fin-retry02/README.md) を保存。接続した20 mm以上の除去ブリム、形状別姿勢、重心投影・実経路検査へ反映 |

具体材料案の条件付き予測は約19.3〜19.7 mで、30 m目標を満たしていない。空力モーメントの格子差27.4%も精度基準を満たしていない。一方、固定した姿勢モデル76点のLaSalle判定と、飛行全体の初期2度差が約4.64度へ拡大した結果は両立する。固定モデルでの収束を、時変・非線形の飛行全体の保証へ広げない。GrönwallとBarbalatも前提条件を照合して選ぶ。

統合画面の1.5 L・20 m探索例、上記30 m具体材料案、既存2 L CAD・動画作例は別ケースである。全ケースが同じ設計として確定・印刷・飛行実証された、という状態にはしない。印刷用部品も耐圧容器を含まず、新しいブリム条件での実機再試作は未確認として残す。

ファイル内容とUIの元仕様は [出力内容設計](../final%20output%20ui%20example/export-content-spec.md)、[UI・UX仕様](../final%20output%20ui%20example/ux-spec.md)。画面で未実装の比較・採用・実寸の手や工具の経路など、仕様にある全項目の実装完了をこの接続からは導かない。
