# 第7段階：階層型・適応型解析の通し検証

2026年11月7日、指定された5状況を検証した。5項目とも、今回の有限なシナリオの期待動作を確認できた。これは設計機体の性能合格や、任意の入力に対するLLMの正しさを意味しない。

解析・ハーネスは第6段階と同じ `1067698` の実装。Gemma 4 12Bが第7段階で35回選択し、CAD・熱・推進・飛行・梁振動を実計算した。CFD/FEMの判定失効には、ハッシュ照合済みの第6段階の実成果物を使った。さらに、選択された平均化時間を独立点で再計算した。64件の回帰テストが成功し、失敗・スキップは0。

## 結果

| 状況 | 観測した動作 | 判定 |
|---|---|---|
| 1. 同じ高度不足でも探索余地によって選択を変える | 圧力300→350 kPaを選び、登録した運用候補を使い切るとフィン厚2.4→2.04 mmへ移行。新しいCAD質量・熱・飛行・確認結果を生成 | 確認済み |
| 2. 剛性を上げても高度が不足する場合に戻れる | 2.4→3.6 mmで変形比1.521→0.925%、乾燥質量298.50→344.70 g、高度11.222→9.324 m。厚い案から3.06 mmへ変更して再解析 | 確認済み |
| 3. 空力精度不足を設計の優劣より先に扱う | 第6段階の不合格後は再設計を候補から外し、平均化延長を選択。未解決の精度条件を保持。18 m/s・10度・20 cells/Dの独立点で40→60 D/Uも実行 | 確認済み。CFD表全体は未再計算 |
| 4. 材料・取付変更で古い判定を引き継がない | 保存状態のコピーで材料→PETG、取付→強化ばねを個別に変更。CAD形状は有効のまま、FEM・振動・安定性・最終確認はいずれも失効 | 確認済み |
| 5. 定理の前提が不足すると未証明を保つ | 無外力の凍結モデルではLaSalleを選択。外力ありでは適用を拒否して未証明。時間変化するモデルでは有限時間のGrönwall評価を選び、有限区間からBarbalatを適用しない | 確認済み |

最初の設計更新シナリオは3版目でも高度14.811 m、厚さのシナリオは2版目でも10.119 mで、いずれも30 mに届かず `unresolved` で止まった。期待する分岐が働いたことと、機体が要求を満たすことを分けて記録している。

独立CFD点の40→60 D/Uの正規化差は4.43%で、時間設定の要求3%を満たさない。1点の再計算が完了しても、CFD表の更新や設計合格へ格上げしていない。

## 検証条件と限界

選択分岐を確認する2つの小さな設計シナリオでは、CFD/FEMを使わず、CAD・熱・推進・解析的空力の6自由度計算・暖機後梁モデルを使う。その他の乾燥部品の位置を機体長の0.30、静安定余裕のしきい値を0.01径として、運用と質量の分岐を確認した。第6段階の製作候補に設定した1径の条件は変更していない。この検証用条件を製作の合格基準に流用しない。

材料・取付の失効確認は、完了時の数値設定をメモリ上のコピーに復元して行う。元の保存プロジェクト・予算・精度・生データを書き換えない。変更後の材料強度を実証する検査ではない。

定理の確認は、条件を明示した凍結線形モデルと区分的アフィンモデルの計算。実飛行の非線形・時変・流入出・スロッシング・柔軟モードを含む漸近安定性の証明ではない。

最初の検証起動では不変の形状モデルへの直接代入が拒否された。形状をコピーして変更するよう修正し、新しい出力先で再実行した。完了した実計算にソルバー失敗はなく、LLM選択はすべて実ローカルモデルで、ベースラインへのフォールバックは使っていない。

## 再実行

[検証スクリプト](../scripts/verify_adaptive_scenarios.py)は、既存の第6段階プロジェクトの生データを照合してから、2つの設計更新シナリオと定理の分岐を実行する。

```powershell
# ローカルモデルを起動し、接続先とモデル名をホスト環境変数で指定する。
python -m scripts.verify_adaptive_scenarios <第6段階プロジェクト> <新しい出力先>
```

`--planner baseline` は実LLMを使わない別の検証モード。今回の記録は既定の `local_llm`。第6段階と解析実装が違う場合、その古い成果物を現在の結果として扱わず、第6段階から再生成する。

選択された平均化時間による独立CFDケースを生成済みなら、`--refinement-case <ケースのディレクトリ>` を加える。形状・ソース・格子・境界・速度・迎角が同じで、選択された計算時間だけが変わったことを検査してから添付する。
