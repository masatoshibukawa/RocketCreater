# ドラフトと統合画面の対応

2026-11-06更新。[ドラフトの入口](../final%20output%20ui%20example/ui-drafts.html#explained)とUX仕様を基準に、現在の設計画面を暗色の工房UIへ再構成した。以下は現行画面の状態であり、ドラフト全体の実装完了を意味しない。

| ドラフトの項目 | 統合画面の実装状態 |
| --- | --- |
| 暗色のドック・上部工程バー・左の対象一覧・中央の工房・右の解説と相談 | 現行のNext.js画面に実装。独立した白い3列ダッシュボードを置き換えた |
| 工房前景の3D整備員 | 実際の処理に連動して点検・待機・片付けへ切替。停止・非表示・動作軽減設定に対応 |
| 解析の目的・結果・未確認事項 | 解説と実際の計算結果を表示。流れの画像、飛行再生、高度グラフを中央のスクリーンで切替。詳細な断面操作は未実装 |
| 結果の固定・最新への復帰 | 表示する設計案の手動選択と最新追従に対応。図ごとの時刻固定・新着件数は未実装 |
| 候補の比較・選択 | 受信した案のモデル・数値・合否・出典を表示し、選択を製作データへ接続。編集・差分確認は未実装 |
| 編集の保存・影響範囲に応じた再解析・採用 | 未実装。既存の工程実行・採用確認とは別機能 |
| 実寸の手・工具、進入・抜き取り経路、干渉判定 | 未実装。機体の表示や小さい作業キャラクターから寸法を推定しない |
| 工程別の組立観察記録・実物の完了状態 | 未実装。PDF閲覧やファイル生成で組立完了を記録しない |
| 製作票PDF・部品表・レポート・側面図 | 表示中の合格案を既存APIで再計算して生成。返却されたファイルだけを左の成果物一覧に表示 |
| 設計ごとの3Dプリント出力 | 既存の形状生成・検査・S5スライスの入口を接続。実機への送信や確認完了を自動化しない |
| 動画 | 保存済みの設計例を既存メディアAPIから再生・保存。現在の設計案の映像と区別。新規の設計ごとの写実映像生成はこの画面から未接続 |
| 組立手順PDF | 凍結した設計の出力APIは残る。自由設計の案へ別機体の手順を流用しない。組立画面は準備と概略形状の確認まで |
| 出力テキストと読取専用スクリプト | 内容設計と見本を取り込み済み。見本の全パッケージを生成するAPIは未実装 |
| 設定 | 整備員表示・動作停止と、印刷出力先の確認を実装。機材プロファイルの編集は未実装 |

現行画面は[page.tsx](../web/app/page.tsx)。操作と検証の詳細は[工房UIの実装](reference-workshop-ui.md)。判断基準は[UX仕様](../final%20output%20ui%20example/ux-spec.md)、[組立仕様](../final%20output%20ui%20example/assembly-spec.md)、[出力内容設計](../final%20output%20ui%20example/export-content-spec.md)。
