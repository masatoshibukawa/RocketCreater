# ドラフトと統合画面の対応

2026-11-06確認。[ドラフトの入口](../final%20output%20ui%20example/ui-drafts.html#explained)にある最新3画面と、統合画面を照合した。PR #21はmainへマージ済みだが、ドラフト全体の実装完了ではない。

| ドラフトの項目 | 統合画面の実装状態 |
| --- | --- |
| 暗色のドック構成・機体・解析・出力の表示切替 | 実装済み。画面構成・余白・図の表現を含む完全な再現ではない |
| 解析の目的・結果・未確認事項 | 文章と数値の表示を実装。ドラフトの詳細な解析図・凡例・断面操作は未実装 |
| 過去結果の固定・新着件数・最新への復帰 | 実装済み。結果の閲覧は進行中の解析から独立 |
| 旧版と変更案の比較・編集・差分確認 | 未実装 |
| 編集の保存・影響範囲に応じた再解析・採用 | 未実装。既存の工程実行・採用確認とは別機能 |
| 実寸の手・工具、進入・抜き取り経路、干渉判定 | 未実装。機体の表示や小さい作業キャラクターから寸法を推定しない |
| 工程別の組立観察記録・実物の完了状態 | 未実装。PDF閲覧やファイル生成で組立完了を記録しない |
| 組立手順PDF | 凍結した設計の部品表・手順・出典・記録欄の出力を実装。実機の確認完了は別途必要 |
| 出力テキストと読取専用スクリプト | 内容設計と見本を取り込み済み。見本の全パッケージを生成するAPIは未実装 |
| 保存した機材プロファイルを編集する設定画面 | 未実装。実際の印刷準備ではCuraの機種・材料プロファイルを使用 |

主な実装は[WorkbenchPanel](../web/app/components/WorkbenchPanel.tsx)、[AnalysisEvidence](../web/app/components/AnalysisEvidence.tsx)、[ローカルAPI](../api/workbench.py)。判断基準は[UX仕様](../final%20output%20ui%20example/ux-spec.md)、[組立仕様](../final%20output%20ui%20example/assembly-spec.md)、[出力内容設計](../final%20output%20ui%20example/export-content-spec.md)。
