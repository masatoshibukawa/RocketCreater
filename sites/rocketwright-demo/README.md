# RocketWright 公開デモ

- [画面デモ](https://rocketwright-ui-demo.taichi-uchida-offici.chatgpt.site/): 既存のアマチュア2案を使った画面・操作確認。
- [統合版の機能デモ](https://rocketwright-ui-demo.taichi-uchida-offici.chatgpt.site/functional/): 既存の製作ワークベンチで、解析8工程、履歴の固定表示、製作・印刷ファイル、動画、資料検索を体験。

利用者の依頼で、誰でもURLから利用できる公開設定にしています。最終提出用のアプリではなく確認用デモです。

## 統合版の再利用

`integrated-src/` は「統合設計とLLM活用の実装」で検証したワークベンチ（コミット `3b236f19078c31dc30e5f614296558c2d0fabf6c`）の画面を再利用しています。機体表示、解析の根拠と履歴、製作・印刷ファイル、動画、参照機体と資料検索を同じ画面構成で提供します。

公開デモは保存記録の再生です。初期表示は完成例で、「工程を最初から」から構成確認、飛行解析、条件試行、独立確認の8工程をたどれます。新しい解析・LLM呼び出し・形状生成・スライス・動画生成・プリンター送信を実行したようには表示しません。工程ボタンと出力ボタンも「保存済み」と明示しています。

`integrated-src/public/demo-data.json` は実行済みプロジェクトの記録です。各段階で選べるのは次の収録工程だけです。生データと成果物は元のプロジェクトに結び付け、コピー時に元ファイルのSHA256を照合しています。組立PDFはこの確定パケットから統合版の既存 `write_manual` 関数で公開用コピーへ生成し、元プロジェクトには書き込んでいません。資料の絞り込みと履歴の選択はブラウザ内で実際に操作できます。ローカル機器や認証情報を公開しません。

1.5 Lの設計説明・飛行CGは、元のGemma提案とBlenderによる各4秒の生成済み映像です。「設計例と資料」の1080p映像とCADは、別の2 L試作v2の参照例です。両者を混同しないよう元の画面上の注記を保持しています。元のLLM見出しに文字化けがあったため、表示見出しを記録された撮影対象に沿う日本語へ整えています。

## ビルドと確認

`integrated-src/` の依存は既存の統合版 `web/package.json` と同じです。Next.js / Reactの依存を用意してから、次を実行します。

```powershell
node scripts/build-integrated.mjs
node --test tests/recording.test.mjs
node serve.mjs
```

`http://127.0.0.1:4173/functional/` を開きます。`dist/functional/` は静的ビルド出力のためGit管理外です。Sitesへの配信対象は `dist/` で、正確なソースをビルドしてアーカイブに含めます。

収録データの再取得には `scripts/import-integrated.py --source <統合版の作業ツリー> --project <実行済みプロジェクトID> --media <既存AIvideo>` を使います。元プロジェクトは読み取り専用です。既に取り込んだ画面へのデモ用変更は上書きしません。
