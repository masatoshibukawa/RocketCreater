# RocketWright 操作確認デモ

既存の `final output ui example/` のワークベンチを、そのまま操作できる静的な Sites デモにしたものです。画面の機体・左右のパネル・寸法図・飛行グラフ・出力を再利用しています。

- [画面デモ](https://rocketwright-ui-demo.taichi-uchida-offici.chatgpt.site/): 保存済みのアマチュア2案で画面と操作を確認。
- [機能デモ](https://rocketwright-ui-demo.taichi-uchida-offici.chatgpt.site/functional/): 入力値からペットボトルの簡易飛行を計算し、水量9案の比較・判定・グラフ・JSON/CSV/MD/SVG出力を試す。

どちらも誰でもURLから利用できる公開設定です。

## 機能デモの範囲

`dist/functional/` は、水噴射・断熱膨張・残留空気のインパルス・重力・抗力・パラシュート降下をブラウザ内で計算します。既存Pythonモデルの名目計算の式を再利用し、海面・無風・鉛直・フィンあり・最高点で開傘に限定しています。水量比較は他の条件を固定し、目標高度との差の小さい順に9案を並べます。

条件判定はガイド離脱、目標高度±10%、既存の降下速度閾値、暫定費用2,300円と予算の比較です。目標に近い候補が必ず見つかるとは限りません。入力変更後の結果は前回の入力と区別し、出力は選択中の計算スナップショットから作ります。

Python本体の7条件と、最高高度・最高点時刻・定常降下速度・飛行時間・離陸質量・ガイド離脱速度・空気インパルスを照合しています。ブラウザ版は固定刻みRK4です。瞬間インパルス直後の最大速度は、Python版の出力サンプリングと異なるため照合対象から除いています。

実機の許容値、姿勢安定性、CFD、材料強度、製造用CAD、印刷、動画生成、Claudeとの対話はこの機能デモの対象外です。表示用SVGは製造用データではありません。入力は外部へ送信せず、サーバー側にAPIキーやローカル機器への接続を置きません。

検証:

```powershell
node --test tests/model.test.mjs
```

Python参照値の再生成はリポジトリの依存環境で `scripts/generate-reference.py` を実行します。参照元のソースハッシュも記録します。

## 確認できること

- 案 A / B の切り替えと、連動する機体・寸法・解析結果。
- 機体のドラッグ回転、拡大縮小、全体表示。方向キー、+ / -、0 でも操作できます。
- 機体、寸法図、飛行結果、結果と出力の表示。
- 高度・費用・降下速度について、保存済み2案を比較する入力欄と質問例。
- 選択案のサンプル SVG / CSV / Markdown / JSON のダウンロード。
- デモのリセット、操作ガイド、狭い画面での構成・相談パネル。

## サンプルの範囲

画面デモの表示値は既存のアマチュア固定シナリオを seed 42 で計算した保存済みデータです。画面デモの入力は保存済みデータの比較だけに使います。別ページの機能デモでは入力条件から簡易計算を実行します。どちらもClaude API や Python バックエンドには接続しません。リロードすると会話と選択状態は初期化されます。

ダウンロードは画面確認用のサンプルです。製作用の寸法確定、機器の許容条件、実機の安全性を保証するものではありません。カタログの仮置き値・計算上の仮定は元データに保持しています。

## ローカルで開く

`dist/index.html` をブラウザで開けます。サーバーで確認する場合は、このディレクトリで次を実行します。

```powershell
node serve.mjs
```

表示された `http://127.0.0.1:4173` を開きます。追加パッケージや API キーは不要です。

## Sites

`.openai/hosting.json` に保存された Site ID を再利用してください。配信対象は `dist/` のみです。初回は非公開で作成し、利用者の依頼で誰でも利用できる公開設定へ変更しています。これは確認用デモの公開であり、アプリの最終提出ではありません。
