## Design

利用者はロケットの専門知識がない一般ユーザー。対話で目的を伝えて候補案を比較する。
黒い画面と実在のCADワークベンチを基準にし、パネルの区切りや機体表示を主役にする。
今回の具体例は卵を回収する教育用の水ロケット。整備員は仮のキャラクター案で、灰色の作業服と黄土色のヘルメットを共通にした。

参照は[Zoo Design Studioの公式公開画面](https://zoo.dev/images/download/start-building-today.webp)。
解析中の画像を先に作り、その画像を残り3画面の機体・キャラクター・画面構成の参照として使用した。
設定画面は入力画面を参照して追加し、上部右から開くパネルの案としている。[機材設定仕様](../equipment-settings-spec.md)と[追加画像の生成プロンプト](05-equipment-settings-prompt.json)を参照。
元サービスのコード・ロゴ・モデルは同梱していない。

追加の解析画面は、ユーザー提供の「写真1.jpg」にある立体的な後流、速度断面、グラフの構成を参考にした。既存の[02-analysis.png](02-analysis.png)の色・機体・整備員を引き継ぎ、背面モニターを主役にするため機体を手前の台に横置きにした。添付写真自体の同梱や、その解析の妥当性の確認は行っていない。
参照画像の右下は格子依存性、この案の右下は反復中の残差で、別の評価を示す。実装では解析が実際に出力した画像・値を表示し、画像生成した図を計算結果の代わりに使わない。[途中画面の仕様](../output-spec.md#解析結果を映す背面スクリーン)を参照。

## Status and interpretation

07〜09は上部の共通工程、選択・下書き・未評価の表示、一つの主要操作をそろえた改訂案。追加3枚のプロンプトと修正内容は[ux-refinement-prompts.json](ux-refinement-prompts.json)に保存している。比較画面の経過時間を未保存変更の表示へ変更し、組立画面の工具を外側の金具へ向け直した。
組立の手・工具・金具は概念描画で、実寸の検証結果や製作手順ではない。実装では採用版のCAD・人体条件・工具形状から生成する。共通の配置・操作・状態・狭い画面での扱いは[UI・UX仕様](../ux-spec.md)、値は[デザイントークン](../design-tokens.json)、操作の説明例は[状態例](../ux-flows.examples.json)で具体化した。
画像と仕様の解釈：保存済みのv12と未保存のv13を分けて表示する。左端の細いアイコン列は全体移動専用に整理し、工程バーの機能を重複させない。09の未選択工具と手の描画は表示例で、実装時は作業条件が未確定の図を評価結果として使わない。画像内の図・文字の配色はトークンどおりの描画を検証したものではない。

- 静止画によるUI提案。画面内の操作、キャラクターアニメーション、動画生成を実装した成果物ではない。
- 数値、寸法、費用、試行成功率、待ち時間、保存時刻と版番号は表示例。解析値や性能の検証結果として使わない。
- 比較画面に含まれる質量表記は実装時に整理し、積載質量と乾燥・総質量を区別する。形状も製造用モデルではない。
- 解析進捗は実際の開始・完了・対象・件数と結び付ける。工程の時間推定は実測に基づき、推定できなければ「見積もり中」とする。
- 動きを止めても工程と数値を確認できるようにする。未達やエラーを完了の演出へ変換しない。
- STL / 3MF の展示用模型、PDF設計図、採用設計からの解説・打ち上げCG生成は将来の機能案。
- 入力、解析、比較、出力という流れは提案。ユーザーによる最終承認はまだ得ていない。

## Generation and verification

組み込みの画像生成ツールを使用した。[prompts.json](prompts.json)に4画面それぞれの生成プロンプトを保存している。
設定画面のプロンプトは別の[05-equipment-settings-prompt.json](05-equipment-settings-prompt.json)に保存している。機材名・寸法は表示例で、登録・保存や設計への適用を実装した画面ではない。
背面スクリーンの生成・修正プロンプトは[06-analysis-backscreen-prompt.json](06-analysis-backscreen-prompt.json)に保存している。残差曲線が反復上限まで伸びないよう修正し、表示中の反復までの例示曲線にした。グラフの数値・経過時間・残り時間は表示例で、CFD実行、画像配信、履歴操作は未実装。
既存の操作試作とは別ファイルで保存し、元の試作を上書きしていない。
基本4枚と追加した設定・背面スクリーンを目視し、共通の画面構成、機体、作業員、工程・時間の表示、動画と出力、機材選択、途中結果と履歴の配置を確認した。
画像ファイルと一覧ページのリンクを検査する。画像をブラウザー画面の実操作や物理検証の結果とは扱わない。
