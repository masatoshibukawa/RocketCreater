# 統合画面から制作した写真調のデモ

既存の2 L完成動画ではなく、製作フローで確認した **1.5 L・D02・carton_wide** の凍結済み寸法と計算軌跡から生成した。ローカルのGemma 4:12bが制約付きの演出案を選び、固定のBlender・合成スクリプトが描画したCG。課金型の生成APIは使用していない。

- [設計説明](design-explanation.mp4)：1920×1080、24 fps、16秒、無音
- [飛行軌跡](launch-cg.mp4)：1920×1080、24 fps、12秒、無音
- [映像の画面](design-film-ui.jpg) / [飛行映像の画面](flight-film-ui.jpg) / [印刷出力の画面](print-exports-ui.jpg)
- [全フレーム検査](verification.json) / [ブラウザー確認とハッシュ](browser-review.json)
- [写真素材の出典](appearance-sources.json)：Poly HavenのCC0素材。照明・地面の処理は既存の写真調作例と共有

両方ともプレーヤーで終了位置まで再生し、メディアエラーなし、保存ファイルと生成元のSHA-256一致を確認。全672フレームのデコード検査が通過した。見た目の点検は代表フレームと画面画像であり、全フレームを連続して人が目視した記録ではない。

この長尺テイクの軌跡検査は、ソルバーから指定した位置の記録と元の補間値の照合。後続コードで追加したBlenderオブジェクト座標の読み返しは、別の低解像度4フレーム試験で確認した。いずれも画像追跡による独立検証ではない。姿勢、PETの細部、材質、装置の見た目は近似で、実機の撮影や飛行実証ではない。回収機構の作動も映像から認定しない。

数値例の圧力325 kPa、探索上限500 kPaは計算の条件であり、実機の許容値ではない。印刷部品への置換後の質量と飛行は別途再評価する。30 m目標のG10/PETG具体案と、この20 m探索例を混同しない。
