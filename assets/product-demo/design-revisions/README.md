# 保存した設計からの制作例

実際のローカルAPIで、2 Lの入力保存 → CAD → 質量を反映した飛行計算 → 採用 → PDF → S5スライス → Gemmaの演出案 → Blender動画 → 一括ZIPを生成した記録です。

- 写真調CG：設計16秒、飛行12秒、1080p・24 fps・無音。672フレームを全デコード済み。実機映像ではありません。
- フィン3枚、胴径110 mm、高さ315 mm、ノーズ95 mm。動画は解析用質量と同じ登録済みCADを使います。
- 乾燥質量178.27 gは一様固体のCAD推定と他部材80 gの合計です。目標高度は未指定。計算高度24.19 mは実飛行の測定値ではありません。
- 組立手順書3ページと設計確認票1ページを全ページ描画して確認しました。固定強度・回収機構・実機試験は未完了です。
- API成果物66個のハッシュ、および展開したZIP内65個のファイル整合を確認済みです。巨大な中間フレーム・Blenderファイル・素材キャッシュはこのフォルダーに含めません。
- `design-input.json`を工房画面で開くと、結果を信用せず新しい未解析の案件として読み込みます。

HDRI・地面素材はPoly HavenのCC0-1.0。個別URLとライセンスを`appearance-sources.json`に保持しています。動画検証の`visual_review`は自動判定せず、画面の再生とフレームを人が確認する項目です。

S5用データ生成と、実機の印刷成功は別です。今回の作業でプリンターへの送信はしていません。
