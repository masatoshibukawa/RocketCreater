# ペトロケ設計ガイド

リポジトリのルートで次のコマンドを実行し、[ガイドを開く](http://127.0.0.1:8765/)。
Pythonの標準機能だけで、このPCのブラウザにガイドを配信できます。

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory UI/bottle-pool
```

候補プール第3版の日本語ガイドです。部品名または変数名で検索し、項目内のリンクから解析手法や文献に移動できます。
ガイドの「探索計画」には、文献から見直したシーケンス図、レイヤー間の依存関係図、評価ハーネスの判断表があります。[探索計画を開く](http://127.0.0.1:8765/plan.html)。
モデル仕様や文献を変更したときは `index.html` の記述も更新してください。サーバーは Ctrl+C で終了します。
