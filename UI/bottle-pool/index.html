現在使える解析

現行モデル

simulate_design

同じ環境で1案ずつ仮想飛行。到達高度、降下速度、着地距離と合否を返します。

現行モデル

estimate_cost

基本機体とパラシュートの概算を比較。個別部品の市場価格は未反映です。

現行モデル

ばらつき試験

run_dispersion

圧力・風速・風向を変えて反復。合格率と結果の分布を比較します。

現在使える8つの評価指標
公称条件の総合合否 nominal_pass
容量・高度・積載・回収・費用など、適用される全条件で判定。
高度の許容範囲からの逸脱 altitude_band_violation
許容帯を外れた距離（m）。範囲内は0。
降下速度の超過 descent_speed_violation
許容降下速度を超えた分（m/s）。発射台を離れた試行で評価。
予算超過額 budget_violation
見積額が予算を上回った分（円）。
概算費用 minimize_cost
合格案同士で比較。現モデルの価格差はパラシュート装着の有無による。

同じシード・試行数・風条件で全条件に合格した試行の割合。

R13
重心と圧力中心の位置関係
自作予定

フィン・積載物・水を組み付けた状態で、小さな迎角のずれに対して機首を戻す向きのモーメントが生じるかを調べます。

座標をそろえる
乾燥機体・積載物・残水などの質量と位置から xCG = Σ(mᵢ xᵢ) / Σmᵢ。xCP は同じ形状・流れでの微小迎角に対する法線力とモーメントの変化から求めます。
位置の差と静安定余裕
Δx = xCP − xCG（m）、SM = Δx / D（胴体径何個分か）。通常の正の法線力傾斜をもつ場合、正なら復元側、0なら一次近似で中立、負なら不安定側です。Dには同じ基準胴体外径を使います。
どの時点で評価するか
発射前は所定充填量で重心を測定。ガイド離脱後は、噴射途中の残水量、水切れ、惰性上昇を追い、有効な自由飛行区間の最小値 minimum_static_margin_cal と、その時刻・CG・CPを返します。
判定を保留する条件
低動圧などでCPを同定できない、評価区間が抜ける、または誤差を含めると符号が決まらない場合です。必要な余裕は機体・ミッション別に検証します。動的な揺れの収束や飛行全体の合否は別項目です。
