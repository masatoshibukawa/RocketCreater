# Webバックエンドの設計・公開と無料枠

調査日: 2026-11-07。Webサイトの裏側で動くAPI、データベース、認証・認可、ファイル保存、長時間ジョブを整理した。[サイト公開の調査](../2026-11-07_web-deployment/README.md) を補う資料である。

## 目的から構成を選ぶ

| 必要なもの | 出発点の候補 | 判断すること |
| --- | --- | --- |
| 静的な紹介、ブラウザ内だけで完結する処理 | バックエンドを追加せず静的配信 | 共有・秘密・永続化が本当に必要か |
| ログイン、データ保存、一覧・編集 | SupabaseやFirebaseなどのBaaS | データモデル、認可、メール、移行・バックアップ |
| 独自の処理を含む短いAPI | 既存Next.jsのサーバー機能、FastAPI、Workers等 | 使用ライブラリ、CPU・メモリ、実行期限、料金 |
| 数分以上の解析、動画、CAD | API + ジョブ管理 + 別worker + 永続保存 | 中断・再試行、資源上限、結果の版、並行数 |
| Postgresを既存APIから使う | NeonやSupabaseのDB | 接続数、pooler、region、計算量、保存容量 |

これは本資料の構成案。最初からマイクロサービスを多数作る必要はない。既存のコードとデータを起点に、小さな一連の操作を動かす構成を選ぶ。
