# コピーの編集例と条件の置き場所

以下は独自の練習例。機能が存在する前提と、実際の状態を確認して使う。

## 書き換え

| 用途 | 直す文 | 書き換え例 | 前提 |
| --- | --- | --- | --- |
| 見出し | あなたの「可能性」を「未来」へ | 設計案をシミュレーションで比較 | 実際に解析と比較ができる |
| 説明 | 想いが軌道を描き、まだ見ぬ世界へ | 目標高度と積載物を入力して設計案を作成 | その入力と作成機能がある |
| ボタン | 新たな可能性を解き放つ | 解析を始める | 次に解析が始まる |
| ボタン | 理想の一台へ | 条件を入力する | 次が入力画面 |
| 留保 | 基本的には、条件によって保存できる場合があります | 保存先を選択してください | 保存が可能で、必要なのは保存先の選択 |
| エラー | 残念ながら処理できませんでした | 接続できません。再試行してください | 接続失敗が原因と確認でき、再試行できる |
| 原因不明のエラー | 接続できませんでした | 処理を完了できませんでした。再試行してください | 原因は確定しておらず、再試行できる |
| 引用の保全 | 田中さんは「比較しやすい」と述べた | 原文を維持 | 実際の発言を正確に引用している |
| UI名の保全 | 「保存」を選択してください | 必要ならUI参照として維持 | 実際のラベルとの対応に役立つ |

悪い例に含まれる引用符は、修正対象を示すためにそのまま掲載している。実行時に例や出典まで機械的に書き換えない。

## 未完成事項と条件の振り分け

| 事実 | 利用者向けにすること | 開発者向けに残すこと |
| --- | --- | --- |
| 今回と無関係な将来機能が未実装 | 紹介や機能一覧へ足さない | 必要な場合に開発タスクへ記録 |
| 解析は使えるが外部比較機能がない | 使える解析を説明し、存在しない比較操作を出さない | 外部比較の実装状況 |
| 入力画面のプレビューで送信は行わない | プレビューと分かる名前・操作にし、入力や送信の判断に必要な表示をその近くへ置く | APIの接続や保存処理の状況 |
| グラフがサンプルデータ | 図の近くにサンプルと分かるラベルを付ける | 実データ連携の状況 |
| 操作に費用・保存・権限の条件がある | 判断する前の場所に具体的な条件を示す | 内部実装の詳細 |
| 端末別の試験が未実施 | 理由なくサイト本文へ転記しない | 実施した確認と未確認の範囲を正確に報告 |

送信しないフォームを、送信できるフォームとして案内する書き換えはしない。警告を目立たなくする前に、現在の機能と利用者の期待が合う画面へ直す。必要な条件を隠すことを簡潔さと呼ばない。

## 編集記録

```text
文章の用途と対象の画面:
実際に確認した機能・状態:
読者が次に行うこと:
元の文 / 書き換え:
削った理由:
残す条件と配置:
新しい事実を追加していないか:
```

読み手に関係しない未完成項目を見つけるために、毎回大きな不足一覧を作る必要はない。依頼された範囲の文章と関連する状態だけ確認する。
