# 書体と文字組みを一緒に整える

## 入力と設計

実際の文章、言語、最長ラベル、数値と単位、対象端末、既存フォントと利用条件を確認する。

- 見出し、本文、ラベル、補足、計測値などの役割を分けて、サイズ・太さ・行間・余白を組にする。
- 日本語の長い本文と欧文を、同じ文字数・字間の規則へ機械的に当てはめない。
- 一つの文章で漢字・仮名・欧文・数字の見かけの大きさと基線を比較する。0/O、1/l/I、負号、括弧も用途に応じて確認する。
- 本文は行長を制限する。比較する数値は桁・単位と整列をそろえ、対応フォントのtabular-numsを必要な場所へ使う。
- 長い見出しや識別子の折り返しを確認する。PC専用の手動改行、本文への一律break-all、情報を切る固定高を避ける。
- フォールバック時と読み込み後の行数・配置を確認し、使用ウェイトと言語範囲を選別する。

Interなどの欧文書体だけで日本語全体を表示できると仮定しない。font-familyに名前を書くだけでは未導入の書体は読み込まれない。公開・再配布には採用ファイルの利用条件を確認する。

## 成果物と確認

役割別の文字体系、書体候補と選定理由、行長・行間・改行の設定、必要ならCSSや画面変更を渡す。推奨初期値を普遍的な最低サイズと表現しない。

文字拡大、狭い画面、実際の長文、フォールバックを確認する。利用者による文字間隔変更への耐性と、サイトの既定の文字設定を混同しない。
