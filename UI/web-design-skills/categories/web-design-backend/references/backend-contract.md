# 構成と確認のメモ

依頼の範囲に合う行だけを埋める。案と、実際に配置・確認した構成を区別する。

```text
利用者と操作:
APIの入力・型・単位・サイズ・成功/失敗:
認証方法・対象の所有者・操作別の認可:
DBとファイルの配置・保存期間・取得方法:
秘密情報の配置・公開/previewの接続先:
処理の時間上限・同時実行数・中断/再試行:
ジョブID・入力版・重複受付・状態取得・成果物の対応:
サービス/プラン・無料枠/周期/共有単位・超過時の挙動:
想定負荷での計算量/DB操作/転送/メール/外部API費用:
正常、別利用者、重複、中断、復旧の確認結果:
```

APIが速く応答することと、ジョブが無事完了することは別。公開URLと実行workerの境界で、同じ利用者が同じ版の結果を確認できることを試す。確認できない結果や速度を記録に補わない。
