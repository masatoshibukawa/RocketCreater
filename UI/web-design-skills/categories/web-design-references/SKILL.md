# 参考を探して制作判断へ変える

## 入力と探索

利用者の目的、サイトの種類、必要な画面・状態、参考にしたい要素を確認する。かっこよさを配色・文字・構図・素材・動きなどの問いへ分ける。

- 実用アプリ、製品紹介、読み物、作品集など、用途に合う実例を探す。
- 必要に応じて日本語以外の検索語を使う。同じ規格の翻訳を独立した証拠のように数えない。
- ギャラリーから実サイトと制作者の説明へ進む。技術仕様や要件は公式資料を優先する。
- URL、発行主体・制作者、言語、確認日、実際に見た範囲を記録する。取得できなかったページは未確認とする。
- 参考にする原理と、採用しない点を選ぶ。見た目のコピーや権利物の転用を成果物にしない。

Siteinspire、SANKOU!、Awwwardsなどは探索の入口である。掲載・受賞・スクリーンショットだけで、アクセシビリティや速度の検証が済んだと判断しない。料金・機能・転送先は必要なときに再確認する。

## 成果物と確認

候補を、用途、確認できた事実、自分の解釈、取り入れる一点、注意点、出典で比較する。少数の主参考へ絞り、ユーザーの内容にどう変換するかを示す。件数や使用言語を満たすために低関連の例を足さない。

本文だけの取得、画像観察、実操作、ログイン後の確認を区別して報告する。

## 作業用テンプレート

候補を比較・保存するときは、[参考カードと多言語検索語](references/research-cards.md) を使う。
