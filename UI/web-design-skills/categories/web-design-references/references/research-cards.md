# 参考カードと多言語探索

複数サイトを比較したり、多言語の資料を整理するときに使う。

## 一件ごとの記録

```text
原題 / URL / 制作者・発行主体:
言語 / 確認日 / 公開・更新日（確認できた場合）:
用途と対象:
確認範囲（検索抜粋 / 本文 / 画像 / 実操作 / ログイン後）:
確認できた事実:
よいと考えた理由（解釈）:
取り入れる原理と自分の内容への変換:
採用しない点と理由:
権利・利用条件と、未確認の点:
```

## 検索語を組み立てる

「目的・媒体」＋「欲しい要素」＋「実例または制作過程」を組み合わせる。

| 言語 | 基礎・文字・配置 | SF・図 |
| --- | --- | --- |
| 日本語 | 文字組み、情報設計、余白、制作事例 | スクリーングラフィックス、計器 |
| English | typographic hierarchy, editorial web design | screen graphics, FUI, telemetry |
| Français | mise en page, hiérarchie visuelle | interface futuriste |
| Deutsch | Raster, Weißraum, Typografie | futuristische Benutzeroberfläche |
| Español | retícula, jerarquía visual, tipografía | interfaz de ciencia ficción |
| 中文 | 版式设计、信息层级、留白 | 科幻界面、数据可视化 |
| 한국어 | 타이포그래피, 여백, 시각적 위계 | SF 인터페이스 |
| Português | hierarquia visual, tipografia | interface futurista |

これは検索語の候補であり、検索を実施したという記録ではない。必要な言語・用途だけ選び、実行した語と確認したページを別に記録する。

## 絞り込む条件

採用理由を説明でき、実際の内容への変換が見えてきたら試作へ進む。件数のノルマのために関連の弱い例を足さない。検索で出た古い版や転送先は区別し、価格・ランキングを固定的な事実として保存しない。
