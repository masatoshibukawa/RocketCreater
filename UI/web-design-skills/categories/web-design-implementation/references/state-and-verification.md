# 状態と確認の契約

入力、通信、解析、検索などを伴う画面の実装で使う。静的な案内ページへ不要な状態管理を追加しない。

## 状態表

| 状態 | 表示する情報 | 許可する操作 | 次の状態 | 確認する異常 |
| --- | --- | --- | --- | --- |
| 初回・空 | 入力内容と例 | 入力、例を使う | 入力済み | 長文、必須項目 |
| 入力不備 | 項目と理由 | 修正 | 入力済み | エラーとの関連 |
| 処理中 | 実際の処理状況 | 必要なら取消 | 完了、失敗 | 重複、遅延、切断 |
| 完了 | 結果と条件 | 比較、保存など | 次の操作 | データ不整合 |
| 結果なし | 条件と不足 | 条件変更 | 入力済み | 空を成功と誤認 |
| 通信失敗 | 未完了の範囲 | 再試行 | 処理中など | 二重処理 |

実際のAPIやデータに合わせて行を追加・削除する。存在しない取消や保存機能を、表にあるだけで実装済みと扱わない。

## 確認の記録

```text
対象URL・起動方法・画面:
実行環境とデータ:
期待した状態:
行った操作:
実際の結果:
修正または未確認の理由:
```

機能がある場合は、ブラウザの操作からAPI・データ・応答まで、変更に関わる範囲を追う。バックエンドがないモックと、実サービスへ接続した状態を区別する。

## 表示と操作

- 狭い幅での読み順、はみ出し、必要な表・図のスクロール。
- キーボードでの操作と見えるフォーカス。
- 拡大、長い文章、動き軽減、画像・フォントの読み込み。
- 処理の開始・完了・失敗と、表示文言の一致。

検証対象は変更に合わせて選ぶ。画面の画像だけで入力・通信・回復を確認したとはしない。公開は、依頼された範囲と利用可能な権限に従って扱う。
