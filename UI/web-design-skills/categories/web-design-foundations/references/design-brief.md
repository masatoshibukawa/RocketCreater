# 設計ブリーフと構図の比較

新規制作や、全体の目的が曖昧な場合に使う。文章はユーザーの内容で埋め、存在しない実績や機能を追加しない。

## 最小ブリーフ

```text
この画面は、誰の:
どんな状況・用事を助ける:
最初に理解してほしいこと:
主操作と完了した状態:
主張を裏付ける実際の内容:
既存のブランド・技術・変更範囲:
未提供の素材や情報:
```

## 内容から構造を選ぶ

| 内容の性質 | 最初に試す構造 | 必要な差 |
| --- | --- | --- |
| 手順 | 工程、番号、時間の流れ | 現在地と次の行動 |
| 比較 | 共通項目の表、対応するグラフ | 同じ単位と条件 |
| 長い説明 | 見出しと本文、図と注釈 | 読む順序と行長 |
| 作品 | 主画像と説明、関連情報 | 主役と補助 |
| 状態の監視 | 主指標、変化、履歴 | 正常・変化・要対応 |

## 案を比較するメモ

```text
案名:
一番大きく見せる情報:
主操作の位置と理由:
補助情報を読む場所:
狭い画面での順序:
この案が合う内容 / 合わない内容:
```

比較案が必要な場合だけ複数作る。色だけを変えた案を、情報設計の異なる案として扱わない。余白の値は関係性から決め、要素同士が同じグループかを確認する。
