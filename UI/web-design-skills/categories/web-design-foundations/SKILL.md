# デザインの基礎を組み立てる

## 入力と進め方

対象の画面・文章・利用者・達成したい用事を確認する。既存サイトがあれば、主操作と迷う箇所を実物から把握する。

- 目的を「誰が、何を理解し、何をするか」にする。サービス名だけ差し替えて成立する説明は具体化する。
- 実際の見出し、説明、図、比較項目を用意し、仮の内容は仮と分かるようにする。
- 読む順序と主役を決める。強調を増やす前に補助情報の位置と密度を整理する。
- 手順は工程、比較は表、説明は本文など、内容に合う形を選ぶ。全要素を同じカードへ押し込まない。
- グリッド、共通の開始位置、近接の余白を決める。非対称な構図でも意味のある読み順を残す。

色・書体の追加で構造の問題を隠さない。単色のワイヤーフレームでも主役と操作が分かるか確認する。4px・8pxなどの刻みや参考サイトの寸法は、目的に応じた運用上の目安として扱う。

## 成果物と確認

依頼に応じて、目的・主操作・情報の順序・ワイヤーフレームまたは実際の変更を渡す。判断理由を内容と結び付け、未確定の文言・素材・データを明示する。

見出しだけで内容が追えるか、関連要素が近くにあるか、狭い画面でも主操作が分かるかを確認する。色だけの相談を全体再設計へ広げない。
