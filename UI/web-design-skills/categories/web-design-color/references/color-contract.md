# 色トークンと検証の作業表

新しいパレットやテーマを決めるときに使う。下の役割名は例であり、既存のトークン名があればそれに合わせる。

## 役割を定める

| 役割 | 値 | 適用箇所 | 組み合わせる相手 |
| --- | --- | --- | --- |
| background | 実際の色 | ページ | text等 |
| surface | 実際の色 | パネル | text、muted、境界 |
| text / muted | 実際の色 | 本文 / 補助文 | 各背景 |
| accent / on-accent | 実際の色 | 主操作 / その文字 | お互い、周囲 |
| focus | 実際の色 | 焦点の表示 | 隣接する各色 |
| 状態色 | 実際の色 | 成功・注意・失敗 | ラベルや図との関係 |
| 系列色 | 実際の色 | データの区別 | 他系列、背景 |

## 色ペアの検証記録

```text
要素と状態:
前景 / 背景 / 透明度・合成の有無:
文字のサイズ・太さ、または意味ある図・操作情報:
適用する条件と原資料:
計算方法・ツール:
丸め前の比率と判定:
表示用の比率:
未確認の状態・端末:
```

通常文字4.5:1、大きな文字3:1、必要な非テキスト情報3:1は、適用対象を確認して使う。見た目の余裕を持たせるための目標値と、規格上の閾値を別に記録する。

## 任意の不透明sRGB二色を計算する例

```python
def luminance(value):
    rgb = [int(value[i:i + 2], 16) / 255 for i in (1, 3, 5)]
    linear = [x / 12.92 if x <= 0.04045
              else ((x + 0.055) / 1.055) ** 2.4 for x in rgb]
    return sum(w * x for w, x in zip((0.2126, 0.7152, 0.0722), linear))

def contrast(first, second):
    dark, light = sorted((luminance(first), luminance(second)))
    return (light + 0.05) / (dark + 0.05)
```

入力は検証済みの `#RRGGBB` 二色に限る。CSSの名前、透明色、写真、グラデーション、Display P3の値をそのまま渡さない。合成がある場合は実表示の条件に合う方法を選ぶ。色ペアの計算から、読み順・状態・操作などの品質は判定できない。

## グラフ

順序のない分類、連続した量、基準からの正負を先に区別する。凡例・直接ラベル・線種・点の形を必要に応じて併用する。見た目の色数を減らすために、重要なデータの区別を失わないようにする。
