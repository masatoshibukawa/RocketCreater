# ペットボトル水ロケットの文献

**原本の公開範囲：** [再配布条件を確認したファイルと除外理由](再配布について.md)を参照。許諾を確認した原本はGitにも収録し、未確認・容量超過のものはこのPCに保存している。

**関連資料：** [モデルロケットの固体・液体・ハイブリッド資料とモデル](モデルロケット/README.md)を別フォルダに収録。

PETボトルに水と圧縮空気を入れるロケットを対象に、24言語の資料98件を集めた。機体寸法、推力の実測、購入できる部品の仕様を別々に引ける。2026年11月4日調査。

[モデルロケットの文献・モデル](モデルロケット/README.md)は、固体・液体・ハイブリッド・共通を区別した別の索引。推進方式・年代・用途が異なる資料を、水ロケットの部品・解析条件へそのまま転用しない。

[年代・言語別ガイド](年代・言語別ガイド.md)では、1956年の水噴射式飛行玩具から2020年代の実験・大会資料までを年代別に比較できる。後半の一覧から本文言語で絞り込める。

## 保存場所と出典

- [原本](原本/)にPDF 66件（923ページ）を保存した。各索引の「保存PDF」から開ける。CADは[専用フォルダ](CAD/README.md)に展開した。オンライン参照の28件には配布元へのリンクを付けた。
- [目録JSON](目録.json)には原題、著者・発行元、確認できた年・版、本文の言語、資料種別、日本語の内容メモ、出典、取得先を収録。保存PDFにはページ数とSHA-256を記録した。言語別件数と新規資料の比較は[年代・言語別ガイド](年代・言語別ガイド.md)を参照。
- 数は資料単位。同じ論文の抄録と本文、CAD一式に含まれる複数部品を別の文献として数えていない。研究資料のうち、大会講演、プレプリント、学校の実験報告は各項目に種別を記した。
- 第三者の原本には各発行元の利用条件が適用される。原本はこのPCに保存し、配布ZIP・FreeCAD・Alibre・STL等のうち許諾確認済みのファイルをGitにも収録した。別のPCでは目録の配布先と[CADファイル別の取得先](CAD/ファイル目録.json)を使える。
