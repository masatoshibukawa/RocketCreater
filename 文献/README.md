## 保存場所と出典

- [原本](原本/)にPDF 44件（667ページ）を保存した。各索引の「保存PDF」から開ける。CADは[専用フォルダ](CAD/README.md)に展開した。オンライン参照の13件には配布元へのリンクを付けた。
- [目録JSON](目録.json)には原題、著者・発行元、確認できた年・版、本文の言語、資料種別、日本語の内容メモ、出典、取得先を収録。保存PDFにはページ数とSHA-256を記録した。言語は日本語・英語・フランス語・ドイツ語・スペイン語・ポルトガル語・イタリア語・韓国語・中国語（繁体字）。
- 数は資料単位。同じ論文の抄録と本文、CAD一式に含まれる複数部品を別の文献として数えていない。研究資料のうち、大会講演、プレプリント、学校の実験報告は各項目に種別を記した。
- 第三者の原本には各発行元の利用条件が適用される。PDF・配布ZIP、利用目的が限定されるFreeCAD一式、追加のSTLリリースと外部ライブラリはこのPCに保存し、Gitの対象外にした。別のPCでは目録の配布先と[CADファイル別の取得先](CAD/ファイル目録.json)を使える。
