## 保存と利用

第三者のPDFとモデル本体は、このPCの各方式フォルダ内の `原本`・`モデル` に保存。Gitには索引・取得先・ハッシュを収録する。別PCでは目録の取得先を参照できる。公開されていることと自由な再配布が可能なことは区別し、原本の著作者・ライセンスを保持した。

資料数は論文・説明書・モデル集単位。同じモデルのSTLとSCAD、補助CSV、ライセンスは独立した文献として数えていない。シミュレーション例の飛行年とソフトウェア保存版の年は別に記載する。
