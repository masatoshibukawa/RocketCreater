## 保存と利用

第三者のPDF・HTMLとモデル本体は各方式フォルダ内の `原本`・`モデル` に保存。Gitには再配布確認済みの原本と、索引・取得先・ハッシュを収録する。ローカル限定資料は別PCでは目録の取得先を参照する。公開されていることと自由な再配布が可能なことは区別し、原本の著作者・ライセンスを保持した。

資料数は論文・説明書・モデル集単位。同じモデルのSTLとSCAD、補助CSV、ライセンスは独立した文献として数えていない。シミュレーション例の飛行年とソフトウェア保存版の年は別に記載する。

保存HTMLは取得時点のページ本体で、外部画像・スタイル・リンク先は同梱しない。言語数には公開抄録や配布ページの原文を含み、機械翻訳ページや単なるサイトの表示言語は別言語資料として数えない。

著者公開の[OpenRocketQD機体4点と解析用ソース](固体/README.md#ms26)も保存した。ORKは既存分と合わせて20ファイル。資料数は集単位で、部品やソースコードのファイル数とは分けて集計する。
