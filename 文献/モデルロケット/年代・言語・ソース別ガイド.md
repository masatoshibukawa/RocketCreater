# モデルロケットの年代・言語・ソース別ガイド

固体・液体・ハイブリッドを横断して、原文の言語と資料の種類から探す。書誌のみ・抄録のみ・目次のみも含むため、全文の保存状況は各項目で確認する。

## 年代の読み方

刊行年、原著年、飛行年、復刻年、ウェブ公開年を区別する。年不明のページはフッターの年で補完しない。過去の説明書・規則はその版の資料として扱う。

| 時期 | 読み始める資料 | 年代の根拠 |
| --- | --- | --- |
| 1900〜1930年代の原著 | [ML15](液体/README.md#ml15) | 1947年論集に1903〜1935年の論考を収録 |
| 1910年代 | [MC07](共通/README.md#mc07) | Goddardの1919年刊行書誌。PDF未取得 |
| 1930年代 | [ML02](液体/README.md#ml02) | Goddardの1936年原報 |
| 1940年代 | [ML15](液体/README.md#ml15) | 1947年版の表紙・図書館書誌 |
| 1950年代 | [MS17](固体/README.md#ms17) | 出願1954年、公報1958年 |
| 1960年代 | [MS04](固体/README.md#ms04)、[MC08](共通/README.md#mc08)、[MC09](共通/README.md#mc09) | 1963年製品カタログ、1964年論文、1967年学位論文 |
| 1970年代 | [MH20](ハイブリッド/README.md#mh20) | 1972年10月の原報表紙 |
| 1980年代 | [MS05](固体/README.md#ms05)、[MH19](ハイブリッド/README.md#mh19) | 1985年カタログ、1989年委託報告 |
| 1990年代 | [MS06](固体/README.md#ms06)、[MC10](共通/README.md#mc10) | 1994年カタログと団体の当時の飛行記録 |
| 2000年代以降 | 各方式の索引 | 論文・大学報告・製品説明書・機体モデル |

## ソースを使い分ける

| 提供元・資料種別 | 例 | 読み取れること |
| --- | --- | --- |
| メーカー | [MS02](固体/README.md#ms02)、[MH06](ハイブリッド/README.md#mh06) | 製品構成・取扱い・当時の仕様 |
| 特許公報 | [MS17](固体/README.md#ms17) | 発明者の構成図と出願・公開の年代 |
| 図書館・原著保存 | [MC07](共通/README.md#mc07)、[ML15](液体/README.md#ml15) | 初期研究の原文と版情報 |
| 学会・研究機関 | [MC08](共通/README.md#mc08)、[ML14](液体/README.md#ml14)、[MH21](ハイブリッド/README.md#mh21) | 実験・解析・著者抄録 |
| 宇宙機関の技術報告 | [MH19](ハイブリッド/README.md#mh19)、[MH20](ハイブリッド/README.md#mh20) | 当時の研究前提・概念設計 |
| 大学・学生チーム | [ML12](液体/README.md#ml12)、[ML16](液体/README.md#ml16)、[MH22](ハイブリッド/README.md#mh22) | 計画、試験、飛行の進捗を区別した報告 |
| 愛好家・競技団体 | [MH17](ハイブリッド/README.md#mh17)、[MC10](共通/README.md#mc10)、[MS20](固体/README.md#ms20) | 活動記録・競技の定義・運用経験 |
| 出版社・原刊行雑誌 | [MS18](固体/README.md#ms18)、[MS21](固体/README.md#ms21) | 書籍の章構成や地域の活動史 |
