## MS15 Rockit — Model Rocket Construction Kit

Vishnu Bob / Rockit contributors · 2014 保存版 · en · OpenSCAD・STLモデル集

対象：市販固体モーター用の模型機体。mini・standard・Dサイズ等の機体、ノーズ、尾翼、モーターマウントのSCAD 26件とSTL 26件。燃焼室・推進剤の製作モデルではなく、市販モーターを収納する機体部品。Eサイズは設定JSONのみ。

[配布元・出典](https://github.com/vishnubob/rockit/tree/cbf10616b0d689cbe364fb4190f6b1e75330298b) · [保存ファイル](モデル/MS15-Rockit)

利用条件：MIT。LICENSE と作者READMEを同梱。

## MS16 RocketPy solid flight examples — Bella Lui, NDRT 2020, Camões

RocketPy Team / 各大学チーム · 2020・2023 飛行、2026 保存版 · en · 飛行計算モデル集

対象：大学・高出力実験機。3つのJupyterノートブックと参照する推力・空力・観測・気象データ。SolidMotorを用いる。各実機の観測結果との比較方法を読める。

[配布元・出典](https://github.com/RocketPy-Team/RocketPy/tree/9bd6ad3af8f97bafa3201d4e70eba2877e66e040/docs/examples/bella_lui_flight_sim.ipynb) · [保存ファイル](モデル/MS16-RocketPy)
