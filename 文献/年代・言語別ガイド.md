# 年代・言語別ガイド

年代が古い資料では、水を噴射した機体の材質と形状に注目したい。初期の特許は専用胴体の構造を示す。1985年の英国公報になると、炭酸飲料用の樹脂ボトルに尾翼とノズルを取り付ける方式が抄録に明記される。[1956年の飛行玩具](歴史・所蔵資料.md#h01) · [1985年の英国公報](歴史・所蔵資料.md#h05)

| 年代 | 比較に使える資料 |
| --- | --- |
| 1950年代 | 1956年の特許図に、圧縮空気で水を噴出する飛行玩具、ポンプ、機体保持具が描かれている。[H01](歴史・所蔵資料.md#h01) |
| 1960年代 | 水を二段に分配する管を持つ1960年の設計と、逆止弁・段間結合を備えた1962年の玩具メーカーの設計を比較できる。[H02](歴史・所蔵資料.md#h02) · [H03](歴史・所蔵資料.md#h03) |
| 1970年代 | 1976年の公報は、注入口を噴出口から分離し、内圧で段間を開放する機構を記載。英国メーカーの後年の回顧には1970年代後半の着想が記される。[H04](歴史・所蔵資料.md#h04) · [H08](歴史・所蔵資料.md#h08) |
| 1980年代 | 1985年の公開公報で、既製ボトル、ねじ付きカラー、翼、柔軟なノズルの取り合いを確認できる。[H05](歴史・所蔵資料.md#h05) |
| 1990年代 | 1995年の2 Lボトル実験はモデル予測を実測と比較する。愛媛県の博物館は同じ1995年の教室で飛ばなかった機体を調べ、翌年に報告した。[R24](論文・研究資料.md#r24) · [R25](論文・研究資料.md#r25) |
| 2000年代 | メルボルンで2007年に寄贈された実物は、付属品と寸法を収蔵台帳で確認できる。同年のポーランドの教育誌には市販部材を使った工作例がある。[H07](歴史・所蔵資料.md#h07) · [D24](設計図・製作資料.md#d24) |
| 2010年代 | カタルーニャ語の斜方投射実験、南アフリカの大学が2015年に報告した競技機の飛行、2019年の米国製発射台CADをたどれる。[R26](論文・研究資料.md#r26) · [R34](論文・研究資料.md#r34) · [D23](CAD/README.md) |
| 2020年代 | タイの2022年の教材評価研究には学習者の結果がある。同年のベトナム大会で風によって軌道が変わったという記述は主催者の観察報告。[R31](論文・研究資料.md#r31) · [D35](設計図・製作資料.md#d35) |

特許は公報日、論文は発行年、所蔵品は学芸員が示した年代と受入年を用いた。ウェブ資料の発行年を確認できなかった場合は目録の年欄を空欄にした。古い公報は図面に記載された設計の証拠として読める。飛行性能の照合には、測定条件が示された実験を参照したい。[日本の風洞試験](論文・研究資料.md#r03) · [スロベニアの推力測定計画](論文・研究資料.md#r30) · [南アフリカの飛行試験報告](論文・研究資料.md#r34)
