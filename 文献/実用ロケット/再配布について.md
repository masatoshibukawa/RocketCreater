# 再配布と保存範囲

2026-11-07確認。全23ファイルのうち6ファイルをGit収録、17ファイルをローカル限定とした。第三者原本は各発行元の条件のままで、リポジトリ本体のライセンスへ変更しない。原本の内容・著作権表示は変更していない。

| 対象 | 根拠・保持する条件 |
| --- | --- |
| LV025 LVM3-M5パンフレット | [ISRO Copyright Policy](https://www.isro.gov.in/Copyright_Policy.html)。出典DOS/ISROを明示し、正確な複製、誤解を招かない文脈。全4ページの第三者表示を点検済み |
| LV028 SLSファクトシート | [NASAメディア利用条件](https://www.nasa.gov/nasa-brand-center/images-and-media/)。出典NASA、教育・情報提供用途。NASAによる推奨を示さず、原本を保持 |
| LV030 Apollo 11技術資料 | [NTRS個別記録](https://ntrs.nasa.gov/citations/19700011707)の「Work of the US Gov. Public Use Permitted」とPublic指定 |
| LV031・LV032 SLS模型 | [NASA 3D Resources](https://science.nasa.gov/3d-resources/)の無料利用表示と[NASAメディア利用条件](https://www.nasa.gov/nasa-brand-center/images-and-media/)。出典NASA。作者のreadmeを保持。NASAが本資料集を公認するものではない |

H3などのJAXA資料は[日本語サイトの利用規程](https://www.jaxa.jp/policy_j.html)を確認し、一般公開リポジトリへの原本再配布に適用できる個別許諾が未確認のためローカル限定。SpaceXはPDF冒頭で事前書面同意を要求する。[Arianespace](https://www.arianespace.com/terms-and-conditions)と[Rocket Lab](https://www.rocketlabcorp.com/terms-and-conditions)も複製・公開に許諾を求める。三菱重工の原本は再配布許諾未確認のため保留した。FAAの資料は第三者図版を含むため原本全体の公開を保留した。

公開対象の最大ファイルは38.09 MiBで、今回100 MiB超過はない。今後、再配布可能な資料が上限を超える場合は、原本をバイナリ分割し、復元方法と原本SHA-256を添える方法も利用できる。容量と許諾は別々に判定する。
