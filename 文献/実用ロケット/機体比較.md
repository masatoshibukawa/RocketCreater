# 機体・推進方式・年代の比較

同じ機体が複数の推進方式を使うことがある。ここでは主段・上段・補助ブースターを分ける。固体と液体を別々の段やブースターで使う機体を、ハイブリッドエンジンとは呼ばない。

| 構成 | 主な収録機体 | 読み分け |
| --- | --- | --- |
| 液体主段、形態により固体補助 | H3、H-IIA、Ariane 6、LVM3、SLS | ブースターの本数と機体形態を記録する |
| 液体 | Falcon 9/Heavy、Electron、長征5号、Saturn V | 液体ブースターや上段も含む。回収条件・軌道条件は別に比較する |
| 固体主段 | イプシロン | 最上段・補助推進系の有無は形態ごとに確認する |
| 固体主段＋液体上段 | Vega-C、SSLV | 固体3段と液体の終端段・モジュールを区別する |
| 固体・液体の交互段構成 | PSLV | 主段の順序を機体全体の単一ラベルで置き換えない |
| ハイブリッド、準軌道 | SpaceShipTwo / RocketMotorTwo | 衛星の軌道投入機と輸送能力を直接比較しない |

以下の各項目から公式の根拠を参照できる。上の分類はその資料に基づく整理であり、全派生型を網羅するものではない。H3の資料は[専用の案内](H3.md)にまとめた。
