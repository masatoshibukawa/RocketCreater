# 実用ロケット・衛星打上げ機の文献

2026-11-07確認。H3を中心に、衛星・探査機を打ち上げるロケットの公式資料を整理した。**36資料・7言語**。同じ文献の日英版は一つの書誌にまとめ、ファイルは別に記録する。

まずは [H3の資料案内](H3.md) から読む。[機械可読の目録](目録.json) と [ファイルごとの容量・SHA-256・保存範囲](ファイル目録.json) も収録した。

PDF **20件・1201ページ**、保存ファイル計 **23件（178.03 MiB）**。このうち **6ファイル**を再配布条件確認済みとしてGitにも収録し、残る **17ファイル**はこのPCのみに保存している。Web参照だけの項目には公式リンクを付けた。

資料は開発計画・旧版マニュアル・飛行結果・広報・所蔵品記録を区別する。収集日が新しくても、文書の内容が最新とは限らない。数値の比較では軌道、高度、傾斜角、機体形態、回収の有無、版を合わせる。
