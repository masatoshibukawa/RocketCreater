# ペトロケの階層型・連成解析

既存の組立案から、熱、推進、姿勢、衝撃、変形、局所安定性までを実行する解析プールです。`Search.integrity()` またはこのディレクトリの CLI から利用できます。実測データのない現在の案を、実機として安全と認定する機能ではありません。

## 実行

Python のプロジェクト依存関係と、別途インストールした CalculiX が必要です。今回の確認には CalculiX 2.23 Windows 版を使用しています。実行ファイルはリポジトリに含めません。

```powershell
python scenarios/bottle_integrity/run.py path/to/assembly-packet output/integrity-run --solver path/to/ccx.exe --cfd-assessment path/to/assessment.json
python scenarios/bottle_integrity/report.py output/integrity-run
```

格子精度だけが不足した場合は、物理モデルが変更されていないことをハッシュで確認したうえで、未収束の部品だけを追加計算できます。元の結果は保持し、別の集約結果を作ります。

```powershell
python scenarios/bottle_integrity/refine.py output/integrity-run --solver path/to/ccx.exe --maximum-level 4
python scenarios/bottle_integrity/report.py output/integrity-run
```

入力パケットは生成済みの `design.json` と `assembly.json` を含むディレクトリです。出力には新しい空ディレクトリを指定します。作図には追加で Matplotlib が必要です。生成された `index.html` は画像を埋め込んだ単体ファイルで、スマートフォン幅にも対応します。

`--config` で `AnalysisConfig` に対応した JSON、`--evidence` で根拠レコードの JSON 配列を指定できます。根拠ファイルのパスはその JSON の親ディレクトリからの相対パスです。範囲外のパス、ハッシュ不一致、仮想データ、適用範囲の未確認は有効な実測根拠になりません。

## 解析と評価

| 層 | 対象 | 実装した手法 | 評価・制限 |
|---|---|---|---|
| 低層 | 寸法、材料、造形・接合、根拠 | 出典・測定条件・ハッシュ照合、曲線当てはめと独立データ誤差 | データの登録だけでは実機適合としない |
| 低〜中層 | 気体、外皮、搭載部、フィン | 熱回路、密閉時の温度・圧力変化、噴出時の熱交換 | 熱容量・接触熱抵抗は仮定。エネルギー収支を確認 |
| 中層 | 水と残留空気の噴出 | 水噴出と圧縮性ノズル流れ、有限時間の空気排出 | 質量・エネルギー収支、チョーク境界、断熱解との比較 |
| 中〜高層 | 機体の姿勢・回転・軌道 | 四元数6自由度、水量による重心・慣性変化、流出角運動量、傘の有限時間展開 | 慣性・空力・傘展開は近似。適用迎角と時間刻みを別に確認 |
| 低〜中層 | 搭載物、緩衝材、支持部 | 2自由度非線形ばね・減衰・片側接触、着地停止距離の感度解析 | 接触後も荷重を求める。破壊荷重と接触面積は未実測 |
| 低〜中層 | フィンと取付部 | 二次三次元要素の大変形、弾性支持、追従圧力、平均ねじれとの反復連成 | 小迎角の空力近似。変位・応力分位値の格子変化を確認 |
| 低〜中層 | カラー、加圧胴体、非加圧搭載筒 | 圧縮側支持、温度依存剛性、圧力・軸力・横力、形状不整、直交異方性・クリープ感度 | 実形状・製造条件・接合強度が必要。応力ピークは強度保証に使わない |
| 中〜高層 | 局所姿勢と弾性振動 | 凍結時刻の固有値、リアプノフ方程式、共通二次形式の標本チェック、曲げねじりと空力遅れ | 凍結時刻の安定性だけでは時変・非線形・全飛行の証明にならない |
| 高層 | 変形を反映した飛行と条件変動 | フィン荷重からの条件付き空力係数・作用点更新、再飛行計算、層化した感度解析 | 仮定した範囲の解析。安全確率や実測フラッター速度ではない |

材料はフィン・胴体・カラーごとに設定できます。直交異方性の軸は部品モデルの固定座標系です。実際の印刷経路、積層、繊維配向と対応していることを別途確認する必要があります。クリープの仮定係数は材料の測定値ではありません。

## ハーネスの契約

`IntegrityHarness.options()` は依存する解析が完了した候補だけを返します。選択側は `step(method_id, reason)` に列挙された ID と理由を渡します。ソルバー実行ファイルや出力先はホストが設定し、選択側から任意のシェル命令を渡しません。通常の全実行は `run_all()` です。既存の画面が自動的にこの全解析を実行するようには変更していません。

各候補は、メイン層・解析カテゴリ・適用フェーズ・解析対象・必要入力・返す出力・評価方法・依存先を持ちます。上流から `observable_relative_tolerance` を指定すると、構造の格子を `maximum_mesh_level` まで増やして評価します。最後まで精度に届かなければ未収束です。基準を緩めて通過させる処理はありません。

実行失敗、数値精度、モデル適用範囲、物理的な適合性は別の状態です。失敗した入力を必要とする解析は停止します。実行が終わったというだけで物理的な適合性を引き上げません。入力・実装のハッシュ、選択履歴、各結果、FEM の入力・ログ・出力を保持します。

## 検証と未解決範囲

数値モデルの確認には、断熱膨張解、質量・エネルギー保存、接触仕事、熱平衡、回転対称性、引張・自由熱膨張・梁・クリープの解析解を使用します。FEM 内部のクリープは m・MPa・MN の整合した単位で計算し、出力を SI に戻します。Pa 単位で極小の Norton 係数を与えたときの数値不良を、係数や荷重そのものの変更で回避しないためです。

まだ測定できていないのは、実ボトルの肉厚・リブ・底部、実際の支持・接合、温度別材料特性、緩衝材・搭載物の破壊特性、重心・慣性、空力、振動減衰、傘の展開・着地です。液面運動、傘布・索の詳細な連成、破壊進展もこのモデルでは解いていません。既存三次元CFDの抗力検証不合格は引き継ぎ、空力係数の根拠に昇格させません。

これらは実物・測定・適用範囲の確定が必要な残件です。シミュレーターの実行完了で代替しません。
