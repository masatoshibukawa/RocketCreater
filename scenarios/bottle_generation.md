# 1.5 Lのペトロケを生成する

日本宇宙少年団の基本型D01に回収モジュールを加えた案が、公称高度29.55 m、
降下速度3.13 m/s、概算2,300円になった。選定用24試行で24件、設計を固定した後の
別の64試行で62件がモデル上の条件を満たした。2件は高度帯を外れた。

## 再実行

リポジトリのルートで次を実行する。出力先には新しいディレクトリを指定する。

```sh
uv run python -m rocketwright.bottle_search --replay scenarios/bottle_hybrid_choices.json --output output/egg-replay
uv run python -m scenarios.bottle_reference_replay
```

各手で新しく数値を計算し、候補IDがその時点で使えるか検査する。
`design.json` が機体のモデル入力、`vehicle.svg` がその模式図。
`run.json` には各手で提示した組、選択理由、結果、前提を、
`choices.json` には再実行用の選択を保存する。

今回の12手は対話中のLLMがそのつど候補と数値を読んで選んだ。
`--interactive` は改行区切りのJSON（`id` と `reason`）を受け付ける。
`--model MODEL_ID` は設定済みのAnthropic APIで次の一手を選ぶ。
どちらも固定要件と合否はハーネスが管理する。
選択方式を省略すれば決定的な比較用ポリシーで走る。
`--starts references|new|mixed` で出発点を切り替えられる。

## 探索で起きたこと

低層でノズルの初期推力と全備重量の比、傘による定常降下、概算費用を評価した。
中層で組立機体の離脱・上昇・降下を時間積分と定常降下モデルで求めた。
高層では圧力・風速・風向を変え、同じ飛行で全条件を満たした件数を比較した。
ノズルの変更時には乾燥質量も更新する。運用条件を変えた案は再び部品評価から通す。

| 初期案 | 公称高度 | 降下速度 | 選定用の同じ24条件 |
|---|---:|---:|---:|
| D02・八角形の傘 | 23.29 m → 30.67 m | 2.84 m/s（調整後） | 23/24（調整後） |
| D01＋回収モジュール | 29.55 m | 3.13 m/s | 24/24 |
| 制約内で独立に生成 | 30.56 m | 3.38 m/s | 24/24 |

D02は初回に高度だけが不足した。同じ9 mmノズル・35%充填で、モデルのゲージ圧入力を
300 kPaから375 kPaに変えると公称高度が帯内に入った。D01の採用理由は、新規案と
選定用の成功件数が並び、降下が遅く、公称高度も30 mに近かったため。
採用案のモデル入力は、容量1.5 L、乾燥質量120 g、搭載60 g、水量525 mL、
ゲージ圧300 kPa、ノズル22 mm、フィンあり、傘径0.50 m。数値はシミュレーション用で、
乾燥質量や傘径は今回の仮定である。

合否の数値条件は高度27–33 m、卵搭載時の降下速度6 m/s以下、回収機構あり、
概算3,000円以下、離脱など既存モデルの判定。選定はseed 71、独立確認はseed 1701。
各群で事前に80%以上を求めた。独立確認の高度の5/50/95パーセンタイルは
27.18 / 29.65 / 31.58 m。独立性は乱数条件についてで、同じ物理モデルを使う。

同じ決定的ポリシー、最大32手、同じ初期運用点と乱数による対照試行では、
文献のみ／新規のみ／混合の順に初の公称合格まで2／1／2回の公称飛行だった。
最終確認は各62/64。混合の自動比較は最初の合格候補を優先したため新規案に到達する前に
終了した。上表の対話試行では3系統すべてを比較した。この1ミッション・1組のシードから
文献スタートの優位性は結論できない。

## 文献との照合と未評価項目

[D01基本型](https://www.yac-j.com/wp-content/uploads/2024/11/1-1.pdf)からは機体構成を、
[D02回収型](https://www.yac-j.com/wp-content/uploads/2024/11/1-2.pdf)からは1辺24 cmの
八角形の傘を採用した。正八角形の布の面積を等面積の円に換算した直径は約0.595 m。
原型の実測飛行性能をそのまま新しい搭載案に割り当ててはいない。

調整に使っていない[Fischerらの1 L実験機、表2](https://arxiv.org/pdf/2001.08828)
の試行1–4を別に計算した。実測高度17.5／17.1／14.1／17.4 mに対し、
予測19.09／19.23／14.03／18.50 m。平均絶対誤差は1.22 m、4件中3件の差が
報告された高度の測定誤差±0.5 mを超える。圧力は表の絶対圧から約1 barを引いて入力。
風は無風、発射ガイドと抗力・外径は現行モデルの近似を用いた。1.5 L機体の予測誤差や
合格率をこの差から直接推定することはできない。

物理モデルは頂点での即時開傘を仮定する。姿勢・ロール、取付部の振動、
開傘失敗、着地衝撃による卵の破損や卵室の実寸適合は未評価。
実機での次の確認は回収装置込みの乾燥質量・搭載スペースの測定と、
同じ荷重・緩衝材での開傘時間・着地衝撃の計測になる。
