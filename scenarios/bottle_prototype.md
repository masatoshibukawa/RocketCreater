# 初めての1機を作る

手持ちゼロを想定し、日本宇宙少年団の回収傘付き機 D02 を土台に、卵と同じ質量の60 gダミーを載せる案を選んだ。購入・手加工・3Dプリントの分担、部材表、非加圧部分の型紙とSTL、確認すべき現物寸法までを一度に生成する。モデルでの目標は高度27–33 m、着地速度6 m/s以下、機体材料3,000円以内。地上機材は別会計。

```sh
uv run python -m rocketwright.bottle_search --workshop scenarios/bottle_empty_workshop.json --replay scenarios/bottle_prototype_choices.json --output output/prototype
```

出力先の `procurement.md` を開いて購入品と見積りを確認してから、`build.md` と `fin-1to1.svg` で仮組みする。ホルダー用カラーは2個、フィンの等配治具は1個印刷する。3Dプリンターを持っていない場合は、同じ部品を手加工するか、STLを造形サービスの見積りに使える。プリンター購入は前提にしていない。

## ハーネスの運用

1. 通常の実行では登録済みの材料構成を探索し、`--interactive` または `--model` で内部の選択者を切り替えられる。上のコマンドはこの対話で選んだ8手を再現する。旧形式の記録は従来のシミュレーション手順で再生する。
2. 個々の試行は機体の出発点・ノズルの方式・フィン／ホルダー構成・水量・計算用圧力で識別する。各部品の搭載質量と重心位置から重心を計算し、フィンを広げると質量・圧力中心・抵抗係数が変わる。低層では搭載室への収まりと自由減衰、中層では乾燥時・注水時の復元方向とピッチの小擾乱、軌道を評価する。広いフィンはまず短いフィンの静安定評価を経て候補に入る。
3. 公称飛行と組立抗力係数±15%の両端を通った構成だけを複数の風・圧力条件へ進める。選定24件、確認64件には異なる乱数を使う。確認は各探索で1回。実機試験に進む判断は、無加圧の嵌合、組立後の質量・重心、実測の減衰、回収試験の記録に基づく。
4. 現物が届いたら `bench-template.json` に個体番号、測定記録、計測値を入力し、`--workshop` に渡して新規出力先で探索をやり直す。入手できない材料は `unavailable`、使用できる噴射方式・充填率は `nozzle_options_mm`・`fill_options_pct` で指定する。`9` は噴射口付き、`22` は首開口の構成キー。噴射口付きの場合、実際の流路径には `insert_bore_mm` を使う。`pressure_ceiling_kpa` は公称シミュレーション設定の上限。発射機材の許容値や運用手順は現物の説明書に従う。

## 今回の試作案

| 確かめたこと | 結果 |
| --- | --- |
| 元のフィン・軽量ホルダー | 注水時重心427.4 mm、圧力中心394.7 mmで復元方向に余裕なし。0.5秒後の振動上界41.8% |
| ホルダーを変更 | 仮定した減衰比6%で上界7.31%。小さいフィンのままでは静安定条件は未達 |
| 板紙のフィンを70 mmから140 mmに延長 | 圧力中心462.5 mm、注水時重心428.3 mm。推定乾燥質量152.8 g。濡れた状態の重心は水の偏りで動くため実測が必要 |
| 運用点を選定 | 公称計算22.16 mの初回を経て、同じ材料・水量で30.55 m、降下2.86 m/s。抗力を振った両端は29.56–31.63 m |
| 選定と固定後の確認 | 22/24、60/64。固定したまま別の128条件（seed 948117）でも121/128。範囲外は高度 |

適用した近似は、乾燥した組立物を棒とみなした慣性、乾燥時の14–16 m/sに対する小角のピッチモデル、フィン付き円筒のBarrowman近似、二つの振動モードに共通の減衰比。静安定は注水時と排水後の2点で評価し、水の重心が想定より15 mm後方に寄る分を見込んだ。濡れた板紙の曲げ剛性、排水途中のスロッシング、翼のばたつき、開傘、卵への衝撃は実測が残っている。湿った状態で翼がたわむ場合は、PP構成で再探索する。

今回の購入案で特に効いたのは外部ガイド。相対風に即時追従する現在の質点モデルでは、設計時に想定した1.5 mの有効行程を0.10 mとすると、他を固定して30.55 mから23.88 mに下がった。市販発射台の単品仕様に1.5 mを割り当てず、別のガイドを含めて無加圧で行程と干渉を測定する。ボトル実寸・市販ノズルの実内径・個体の許容運用条件も現物入手前は未確認。

寸法と組み立ての原資料は [D01](https://www.yac-j.com/wp-content/uploads/2024/11/1-1.pdf)・[D02](https://www.yac-j.com/wp-content/uploads/2024/11/1-2.pdf)。D02の図の全体重量約220 gは原作の値であり、今回の質量は部材別の見積り。卵室・ホルダー・ガイドアイレット・拡大フィンを備えた試作案の実測値は、組立後に記録する。

機体を固定して三次元流れを解き、上記の抗力・圧力中心の仮定と比較する手順は[三次元CFD](cfd/README.md)にまとめた。
