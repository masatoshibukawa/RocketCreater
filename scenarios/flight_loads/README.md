# 数値風洞から設計荷重まで

対象は生成案 `D02/9/carton_wide` の理想化した外形です。実測風洞の工程は数値風洞に
置き換え、CFD → 空力特性 → 飛行経路 → 断面荷重 → 設計荷重を実行します。
添付写真そのもの、写真内の数値、画像の複製はコード・サイト・成果物に含めません。

## 入出力と再現

```powershell
python scenarios/flight_loads/run_tunnel.py path/to/assembly.json output/tunnel
python scenarios/flight_loads/run_tunnel.py path/to/assembly.json output/tunnel --refine-incidence
python scenarios/flight_loads/run.py path/to/integrity/input.json output/tunnel output/flight-loads
python scenarios/flight_loads/report.py output/flight-loads output/tunnel
```

CFD は既存の CuPy / CUDA 環境を使います。Windows の DLL 設定は
[CFD手順](../cfd/README.md)を参照してください。全処理は新しい出力先を使い、
数値風洞の再開時は入力・実装・出力のハッシュを照合します。

| 工程 | シミュレーション | 評価と出力 |
|---|---|---|
| CFD・数値風洞 | D3Q19、速度8/18/30 m/s、迎角0/5/10/15/45/90/135/180° | 壁面隣接圧力、3分力と3モーメント、64区間の分布荷重 |
| 空力特性 | 速度・迎角の双線形補間、対称性による平均ノイズ除去 | 軸力・横力・モーメント係数、作用点、独立条件の補間誤差 |
| 飛行経路 | 熱・密閉圧力、有限時間噴出、質量・重心・慣性が変わる四元数6自由度 | 動圧、加速度、マッハ数、高度、姿勢・回転、開傘荷重 |
| 飛行荷重 | 分布空力、推力、内圧、ガイド反力、開傘力、並進・回転慣性の釣合い | 各時刻・各断面の軸力、せん断力、曲げ・ねじりモーメント |
| 設計荷重 | 風・加熱・空力差・減衰・開傘遅れと仮定着地条件の包絡 | 支配条件、時刻、同時に作用する荷重ベクトル、指定倍率後の値 |

力は N、モーメントは N·m。CFD の基準面積は胴径90 mmの円、モーメント長さは同胴径です。
CFD の +x は先端から尾部、飛行の +z は機首方向。回転行列で力とモーメントを同時に
変換します。区間内の作用点のずれを偶力として保存するため、分布荷重を足し戻して
機体全体の力と任意の基準点まわりのモーメントを復元できます。

断面には機首側部分に機尾側が与える力・モーメントを記録します。軸力は圧縮が正、
引張が負です。内圧は容器端面の自己釣合い力として加えます。重力は一様場とし、
並進慣性との組合せを固有加速度で表現します。回転加速度・遠心力と部品内の局所慣性も
含みます。水の噴出に伴う角運動量移送は飛行モデルと同じ補正をノズルへ集中させます。

## 精度・適用範囲

- 数値風洞の迎角範囲は0〜180°。大迎角では機体を回し、流入・流出は開いた面に保ちます。
- 平底の固定剛体と厚さゼロの4枚フィンを使います。実際のスカート開口、噴流、変形形状は
  含みません。圧力は壁面隣接セル値、力は圧力・粘性を含む運動量交換であり、圧力だけの積分ではありません。
- 16/24/32セル/胴径、領域幅10/14胴径、平均区間、未使用の24 m/s・10°を比較します。
  10°での補間誤差に応じて同迎角の3速度を追加し、未使用の24 m/s・12°で再評価します。
  閾値に届かなければ未収束と記録し、条件付きの計算を実機適合へ昇格させません。
- 速度範囲外では端点の無次元係数と実速度の動圧を使い、範囲外の標本数を記録します。
  同一速度でも流れの方位角による4枚フィンの違いは、単一の子午面で近似します。
- 部材表の質量・位置に局所慣性の仮定を付け、水を16分割したモデルです。水面動揺は含めません。
  回転減衰、傘の膨張、着地停止距離も仮定です。
- 機体断面荷重は準静的な回復です。弾性過渡応答・乱流バフェット・液面との連成を
  解いたものではありません。先行する振動・構造モデルの結果と区別します。
- 着地は衝突速度を機軸方向に5/15/30 mmで停止させる感度条件です。実際の接地姿勢や
  地面・搭載物の破壊を再現した結果ではありません。
- 既定の設計倍率1.5は明示した仮定であり、規格への適合や安全率の認証ではありません。
  各成分の最大値が同時に起こるとは限らないため、その瞬間の6成分も保存します。

断面位置は等間隔の位置に加え、空力区間・部材・支持・圧力端面の位置の両側を含めます。
集中荷重や偶力の直前・直後を粗い断面刻みで飛ばさないためです。

## 根拠

分布空力・表面圧力・空力係数を構造解析と飛行へ渡す考え方は
[NASAの空力データベースの説明](https://www.nas.nasa.gov/SC18/demos/demo9.html)を参照しています。
NASAの大型機の計算値や基準を、このペトロケの荷重や許容値へ流用していません。
CFD の数値手法と独立検証の出典は[CFD手順](../cfd/README.md)、
熱・材料・構造の仮定は[連成解析手順](../bottle_integrity/README.md)に記録しています。
