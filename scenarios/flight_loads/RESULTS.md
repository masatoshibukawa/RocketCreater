# 数値風洞・飛行荷重の実行結果 — 2026-11-05

対象は `D02/9/carton_wide` の理想化した剛体・平底形状です。写真の工程に対応する
数値風洞、空力特性、飛行経路、断面荷重、設計荷重を実行しました。
独立した実物の風洞試験は実施していません。**精度未達のため条件付きの解析値です。**

- 数値風洞：速度3条件×迎角8条件＝24ケース。格子・領域・時間・未使用迎角の比較10ケース。
- 飛行：通常、無風、横風、加熱後、空力増減、減衰小、開傘遅れの8条件。
- 着地：最大衝突速度を機軸方向に5/15/30 mmで止める3条件。
- 低層の部材質量・圧力から、中層の空力・慣性・断面釣合い、高層の荷重包絡へ接続。

## 条件付きの最大荷重

| 成分 | 最大値 | 指定倍率1.5の後 | 支配条件 |
|---|---:|---:|---|
| 圧縮 | 821.17 N | 1231.76 N | 5 mmでの軸方向着地、先端から567 mm |
| 引張 | 2730.89 N | 4096.33 N | 加熱後の容器内圧、先端から約362 mm |
| せん断 | 2.01 N | 3.02 N | 横風、先端から380 mm |
| 曲げ | 0.314 N·m | 0.470 N·m | 横風、先端から380 mm |

ねじりは今回の無カント・対称化モデルで数値ゼロです。実機のねじりを否定しません。
指定倍率は仮定であり、規格の安全率ではありません。成分ごとの最大値は同時発生するとは
限らないため、支配時刻の6成分ベクトルも保存しました。着地条件の速度6.17 m/sは横風ケース
の全速度であり、実際の接地姿勢や地面・搭載物の破壊を解いた結果ではありません。

通常条件の最高高度は21.67 m、最大動圧320.86 Pa。比較した飛行8条件の高度は18.36〜27.30 m。
従来の簡易空力係数による結果とは入力が異なり、実機に対して精度が上がったと断定しません。

格子等の差は6成分係数のノルムです。球の照合、釣合い、補間、格子精度、物理的な妥当性は
別の確認です。迎角を追加しても補間差は解消しませんでした。現在の階段状境界・薄いフィンを
含むCFDから、実機の設計許容荷重を確定することはできません。空力を±約52.6%変化させた
飛行感度を含めましたが、これも保証された誤差境界・安全確率ではありません。
