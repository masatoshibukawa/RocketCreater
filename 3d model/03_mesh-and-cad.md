# メッシュ修復とCAD：Blenderを使う具体的な手順

## 1. 修正前のデータを残す

元のメッシュを複製して、編集用と比較用に分ける。自動修復、再メッシュ、ブーリアン、面数削減は形状を変える処理なので、同じファイルを何度も上書きしない。作業ファイルはネイティブ形式で保存し、STLだけを唯一の原本にしない。

初めて使うBlenderでは、版番号と3D Print Toolboxの版番号を確認する。現在のExtensions掲載と古いBlenderマニュアルでは導入手順が異なる。古い記事の「最初から同梱されている」を全バージョンへ当てはめず、手元の設定画面から公式拡張の対応版を確認する。[S10: 3D Print Toolbox](https://extensions.blender.org/add-ons/print3d-toolbox/)、[S11: Version History](https://extensions.blender.org/add-ons/print3d-toolbox/versions/)

## 2. 何が不良なのかを分ける

| 症状 | 意味 | 直すときの注意 |
| --- | --- | --- |
| 開いた境界 | 表面の端に隣接面がなく、閉じた体積を作らない | 必要な排液口や器の開口との違いを確認 |
| 非多様体の辺・頂点 | 面の接続が通常の閉じた表面として成立しない | 重複面、内部面、接触だけの接合を確認 |
| 自己交差 | 表面が自分自身を横切る | 交差箇所を修正し、断面で内部を確認 |
| 法線の不整合 | 表裏が揃わない | 法線再計算だけでは穴や交差は直らない |
| 重複頂点・ゼロ面積面 | 不要・退化した形状要素 | 小さな結合しきい値で局所処理する |
| 浮遊した小片 | 本体と別の連結成分がある | 意図した別部品なら削除しない |
| 厚みのない面 | 表だけ存在し、材料の体積がない | 表面の閉じ直しやSolidify等で体積を作る |
| 複数の殻が重なる | 本体・目・服が独立して重なる等 | Joinだけでは立体として和集合にならない |

「閉じたメッシュ」と「物理的な水密性能」は別。閉じた容器形状でも、積層の隙間、材料、造形条件、仕上げによって漏れる可能性がある。メッシュ検査に通ったという理由だけで液体や圧力を保持できると判断しない。

また、コップの口が開いていても、内壁・外壁・底・口の縁が連続して材料の体積を囲めば、その材料部分は閉じたメッシュにできる。必要な開口を全部ふさぐことが修復ではない。

## 3. 実寸を設定してから厚みを扱う

1. 元のGLB/OBJ等を読み込み、単色表示にする。
2. シーンの単位系・長さ単位を確認する。表示をmmにしただけで既存の形状が望むサイズへ変わったと考えない。
3. `N`パネル等のDimensionsで外形寸法を読み、目標の高さ・幅へ一様に拡大縮小する。
4. 編集用の複製にScaleを適用する。非一様スケールが残ると、厚みの処理に影響する。
5. 例えば高さ80 mmのモデルなら、書出し後にスライサーでも高さ80 mmになっていることを確認する。

Solidifyの厚みはローカル座標とスケールの影響を受ける。公式マニュアルは非一様スケールと、厚みが完全には一定にならない場合を説明している。数値欄が2 mmだから全箇所で2 mmと断定せず、断面と最小厚みを検査する。[S12: Blender Solidify](https://docs.blender.org/manual/en/5.1/modeling/modifiers/generate/solidify.html)

## 4. 小さい不良から順に修正する

以下は一般的なBlenderの操作例。表示言語や版で位置は変わるため、操作検索で英語名も使う。

| 順序 | 操作例 | 目で見る場所 |
| --- | --- | --- |
| 1 | 不要な独立した破片を選択して削除 | 底面の下、背面、髪や服の周囲 |
| 2 | 編集モードで必要箇所の頂点をMerge by Distance | 指の隙間、狭い溝が消えていないか |
| 3 | 全体または適切な領域の法線をRecalculate Outside | 反転した面、内側面、閉じた殻の関係 |
| 4 | Select Non-Manifold等で不良箇所を特定 | 開口、複数面の交差、辺だけでつながる部分 |
| 5 | 小さい欠損は面を張る、境界同士をつなぐ等で局所修正 | 意図した穴、口、薄い隙間を維持 |
| 6 | 3D Print Toolboxで再検査 | 体積、交差、薄い箇所、独立した殻等 |
| 7 | 必要に応じてブーリアンや再メッシュ | 顔、爪、刻印、穴、接続部の変化 |

結合しきい値は最終実寸で考える。例えば最小の残したい隙間が0.3 mmしかないのに、それに近い距離の頂点を一括結合すると必要な形まで変わる。処理前後を重ねて確認する。

## 5. 自動修復・Voxel Remeshの使いどころ

局所修正が難しい交差や多数の小穴では、別ファイルで体積ベースの再メッシュを試す。Voxel Remeshは新しい表面を作るので、細部、隙間、薄壁、穴が変わり得る。平面だけの入力には先に厚みが必要になる場合がある。[S13: Blender Remesh](https://docs.blender.org/manual/es/4.5/modeling/modifiers/generate/remesh.html)

作業上の目安として、最小の残したい特徴が1 mmなら、例えば0.2 mm程度から試して前後を比べる。この値は保証された最適値ではない。小さいvoxelほど処理量が増え、同じ体積でvoxelの一辺を半分にすると、体積を区切るセル数の目安は8倍になる。必要な細部が残る範囲で調整する。

再メッシュ後は、目標寸法、穴径、最小接続部、表面、独立した殻を再検査する。「Make Manifold」「Make Printable」が成功しても、形状の意味や機能が正しいとは限らない。

ドイツ語のPrusa修復資料も、自動修復の限界と、ソリッド化による解像度低下を説明している。記事中のWindows 10・Netfabb・3D Builder等の案内は古い環境を含むため、現行環境で利用できることの根拠にはしない。[S16: Beschädigte 3D-Modelle](https://help.prusa3d.com/de/article/beschadigte-3d-modelle-zum-drucken_2205)

## 6. 台座・接続・細部を編集する

台座は本体と十分に交差させ、必要ならBoolean Union等で一つの体積にする。オブジェクトをJoinして一覧を一つにまとめても、重なった殻が融合したとは限らない。演算を適用した書出し結果をスライサーへ戻して断面を確認する。

顔の目、服の模様、木目などがテクスチャにしかない場合、STLへ変換しても凹凸にはならない。必要な箇所だけを彫る・盛る、厚みを持った別部品を付ける、高さ情報で変位させる等で実際の形状にする。すべての陰影を凹凸へ変換するとノイズや薄壁を増やすので、最終サイズで見せたい特徴を選ぶ。

細い髪や尾を太くする、腕を胴体につなぐ、小さな空隙を埋めるなど、印刷後に壊れやすい構造を変える。元絵への忠実さと、最終寸法で残る形状の両方を確認する。

## 7. 機能部品は数値を持つCADへ

| 方法 | 長所 | つまずきやすい点 |
| --- | --- | --- |
| メッシュを参照してCADで描き直す | 穴、壁、接合面を寸法で変更できる | 外観の再現に手間がかかる |
| CADの基体に装飾メッシュを組み合わせる | 実寸と装飾を分けて修正できる | 結合部の厚みと演算を検査する必要 |
| メッシュをそのままソリッド変換 | 元の外観を取り込める場合がある | 大量の面で重くなる。元の設計履歴が戻るわけではない |
| AIにOpenSCAD/CadQueryコードを作らせる | 寸法を変数化して反復しやすい | 数値の取り違え、存在しないAPI、演算失敗の確認が必要 |

CadQueryの公式資料は、STEP等で交換しても完全なパラメトリック原本はCadQuery自身のPython形式だと区別している。編集用のコードと、交換用の形状を両方保存する。[S30: CadQuery import/export](https://cadquery.readthedocs.io/en/latest/importexport.html)

寸法拘束が必要な場合は、外形、基準面、穴中心間距離、穴径、最小壁厚を明示して生成させる。画面上の印象ではなく、断面、寸法読み取り、実物のノギス計測で検証する。

## 8. 書出し後の検査

1. 印刷するオブジェクトのみを選び、モディファイアが必要どおり反映された状態で書き出す。
2. 元の作業シーンを一度離れ、書出しファイルをスライサーへ新規読込する。
3. mmでの外形寸法、パーツ数、底面、穴、壁、内側の空洞を確認する。
4. 修復の警告が出たら、どの箇所が変わったか確認する。
5. スライスして、表示された立体と実際の造形経路に差がないか全層を見る。

STLへ変換しただけで修復できたと判断しない。書出しの前後で頂点の扱いが変わっても、意図した材料の体積や強度まで確認できるわけではない。
