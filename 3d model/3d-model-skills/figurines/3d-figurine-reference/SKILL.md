# フィギュアの参照と形状の再現


キャラクター名だけで形状を確定せず、採用する作品/姿・ポーズと参照を選ぶ。頭身、頭/胴の幅、目・口の位置、耳の角度、尻尾と足の接続等、似姿に効く箇所を少数の比較点にする。非対称の模様・ポーズを左右対称化しない。

## 参照の一貫性

正面、側面、背面は同じ形・姿勢・小物・尺度の組で揃える。遠近の強い絵や別のポーズを混ぜて、多視点が多いほど正確になるとはみなさない。不整合があるなら基準の1枚と未確定部を残す。

Meshy等が1枚から作る追加視点は、見えない部分の生成案。別の実測/公式設定資料が増えたものとして扱わない。[Meshy英語ガイド](https://help.meshy.ai/en/articles/16102789-meshy-multi-view-best-practices-angles-and-images)と[中国語ガイド](https://help.meshy.ai/zh-CN/articles/16102789-meshy-multi-view-best-practices-angles-and-images)は、姿勢・光・対象が一致しない入力を避けるよう案内する。UIとAPIで枚数/対応モデルが異なり得るため、使う[API版](https://docs.meshy.ai/en/api/multi-image-to-3d)を照合する。

## 色を外して形を確認する

単色材質、正面/側面/背面、斜光と断面で、輪郭・頭身・目口の凹凸、薄部・浮遊片を確認する。色付きプレビューだけでは顔の立体と塗り絵を区別できない。瞳や模様を塗装するか実際の凹凸にするかを決め、色だけでよい箇所まで彫り直さない。

顔が違うなら参照/形状を局所修正する。テクスチャ解像度だけ上げて凹凸の不足を補おうとしない。再生成・Remesh・自動修復の前後は同じカメラとサイズで比較し、表情・隙間・接続の変化を見る。

[Meshy Repair](https://docs.meshy.ai/en/api/repair-printability)は形状変更によりテクスチャを除く仕様がある。元データを保存し、後で塗る/再テクスチャ化/凹凸へ変換する経路を選ぶ。表情の合意前に細部の研磨や一体化を確定しない。採用モデルと不一致、変更してよい箇所を[分割と接合](../3d-figurine-split-fit/SKILL.md)へ渡す。
