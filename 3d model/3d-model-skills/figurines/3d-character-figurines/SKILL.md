# キャラクターフィギュアの制作


ユーザーが選んだキャラクター・姿勢・表情と到達点を保持する。既存チャット・画像・ファイルから、全高（台座を含むか）、重要な見え方、単色/塗装/多色、実機・材料を確認する。ポケモンの依頼を汎用の動物へ置き換えない。未指定の種やポーズを確定して生成しない。

| 今の作業 | 読むスキル | 残す成果物 |
| --- | --- | --- |
| 参照画像、AI生成、顔や輪郭の再現 | [参照と形状](../3d-figurine-reference/SKILL.md) | 採用参照・比率、元モデル、修正版と不一致 |
| 細い耳/尻尾、分割、ダボ、台座と転倒 | [分割・接合・安定](../3d-figurine-split-fit/SKILL.md) | 実寸の部品・接合・台座、原寸試験箇所 |
| FDM/光造形、支持・中空・色の印刷 | [印刷前の確認](../3d-figurine-print-review/SKILL.md) | スライサープロジェクト、全層/色の確認と試作計画 |
| 支持除去、表面、仮組み、接着、塗装 | [仕上げと配色](../3d-figurine-finishing/SKILL.md) | 材料に合う仕上げ工程、色見本、組立と検査 |

新たな知見と版の制限は[追加調査](../../../12_キャラクターフィギュア/findings.md)、症状からの戻り先は[確認表](../../../12_キャラクターフィギュア/checks.md)を必要な範囲だけ読む。

## 工程をつなぐ

参照の合意→単色の形状比較→最終サイズの薄部・接合設計→顔/耳/ダボの原寸部分試作→全形状の印刷と仕上げへ進む。安定した既存条件は維持し、失敗した箇所に必要な試験だけを選ぶ。顔の似せ込みと、壊れず製作できることを別に確認する。

現在のS5/Tough PLA Gray/AA0.4は単色FDMの出発点にできる。別機種の多色機能や光造形の露光・最小壁を移さない。S5の過去のフィン再試行のブリム/速度はフィギュアの既定値ではない。

保存するのは、[制作記録](../../../12_キャラクターフィギュア/figurine-record.example.json)、参照と元のGLB/OBJ等、編集原本、部品ごとの印刷データ、ソフト/プロファイルの版、部分試作・完成の写真と残る不明点。スキルを読んだことや自動修復の成功を、印刷・塗装の完成として報告しない。今回が調査だけなら、モデル生成・実機試験をしたと主張しない。
