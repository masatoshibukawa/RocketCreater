# フィギュアの表面・組立・塗装


完成目標を、見せる面・色・艶・継ぎ目・部品保持と台座の安定へ分ける。元の色付きモデルは塗装の参照にも残す。樹脂・接着剤・パテ・プライマー・塗料/クリアの製品を一組で記録し、目立たない試片で相性を試す。

## 印刷後から仮組み

FDMは指定の冷却と支持除去、光造形は材料指定の洗浄・乾燥・硬化と、指定時点の支持除去を行う。全樹脂へ同じ順・時間を配らず、顔と細い耳を引っ張って外さない。中空部の未硬化液・洗浄液を残して塗装や封止へ進めない。

仮組みでダボ/穴、継ぎ目、台座のがたつき・転倒、塗装の届き方を確認する。継ぎ目を消してから塗る部分と、色別に塗ってから組む部分を決める。接着/嵌合面を塗膜で埋めないようマスクする。[Prusa後処理](https://blog.prusa3d.com/postprocessing-of-3d-prints-step-by-step_29270/)は、塗装前の仮組みと接着工程を説明している。

## 表面と配色

支持痕と継ぎ目を局所的に直し、目・口の縁や模様を削り落とさない。FDMの層段差を厚塗りだけで隠す前に、残す細部を確認する。必要な表面処理の後は粉/油分を除き、材料に合う薄い下地で傷を再確認する。

[タミヤの下地説明](https://tamiya.com/japan/scale/technique/87160/index.html)は、厚いサーフェイサーが細部を埋める点を指摘する。[Mr.HobbyのFAQ](https://www.mr-hobby.com/ja/qa)も材質別の密着を扱う。射出成形PSやレジンキャスト用の説明を、PLA/光硬化樹脂の全製品へ無条件に適用しない。

色と艶を試片で決め、薄い層を重ね、乾燥・再塗装・マスキング・接着は塗料製品指定の時間で行う。目や頬等は塗る位置を参照へ照合する。塗料の表面が乾いたことと、十分な硬化を分ける。強い溶剤や混用・加熱で乾燥を早める手順を即興で追加しない。[下地と塗装の工程例](https://formlabs.com/blog/how-to-prime-and-paint-3d-prints)の距離/時間も、その製品条件へ読み替える。

## 完成の確認

指定した正面/側面の写真で表情・色境界・支持痕・継ぎ目・艶を確認し、ダボが底まで入り、本体や台座ががたつかず、細部が欠けていないか見る。接着後の保持と展示時の安定を実物で確認する。見た目の完成を玩具としての適合や強度試験の代わりにしない。

使用製品・仕上げ順序・試片・写真・不良と修正・未確認の耐久を[制作記録](../../../12_キャラクターフィギュア/figurine-record.example.json)へ残す。調査だけなら塗装済みと報告しない。
