# 全体工程と制作経路

[全体工程の調査](../../../01_全体工程/01_workflow-and-choices.md)を読み、依頼に必要な[共通の作業条件](../../references/task-contract.md)を整理する。計画が既にあり局所修正だけが必要なら、担当カテゴリーから進める。

## 方法を選ぶ

| 要件 | 起点 | 判断すること |
| --- | --- | --- |
| 置物や有機的な外観 | 画像・文章からの生成 | 輪郭、見えない面、細い接続、修正工数 |
| 穴・接合面・正確な寸法 | パラメトリックCAD | 基準面、寸法拘束、隙間、原寸試験 |
| 装飾のある実用品 | CAD基体＋装飾メッシュ | 接合、内側の空間、演算後の断面 |
| ロゴ・浮き彫り | 輪郭の押出しや高さの設計 | 線幅、文字、底の厚み、実形状の凹凸 |
| 実物と同じ形 | 実測・スキャン等 | 基準寸法、背面、穴。単眼生成の推定との違い |

ユーザーが指定した方法を起点にし、不適合があれば影響と代案を示す。AI生成や特定ブランドを全案件に強制しない。

## 工程を具体化する

1. 到達点と重要な寸法・面・機能を特定する。
2. 外観、寸法、材料特性、造形範囲、修正工数、後処理設備から経路を選ぶ。購入や最新仕様が判断を左右する場合は[調査](../3d-model-research/SKILL.md)で確認する。
3. 入力→形状→印刷設計→スライス→原寸試作→本出力→後処理から、必要な工程と成果物を並べる。
4. 各工程の合格条件を、何を観察・測定するかまで具体化する。全高の再読込確認や穴周辺の原寸試作等を使う。
5. 未定の機種・材料・承認がどの工程を止めるか明記し、独立して進められる部分を実行する。

方式選びではFDMの線幅・層方向・反りと、光造形の支持・剥離・空洞・洗浄硬化を比較する。積層ピッチや画素サイズだけを完成寸法の精度としない。

## 渡すものと確認

仕様、選んだ経路と理由、工程ごとの成果物・合格条件、最初の原寸部分試作を残す。調査・計画だけならその範囲で完結させる。制作依頼なら[AI生成](../3d-model-ai-generation/SKILL.md)または[モデル修正と設計](../3d-model-preparation/SKILL.md)へ進み、計画だけを完成品としない。
