# モデル修正と印刷設計

メッシュ修正は[Blender/CADの調査](../../../03_モデル修正と設計/03_mesh-and-cad.md)、厚み・嵌合・方向は[印刷設計の調査](../../../03_モデル修正と設計/04_design-for-print.md)を参照する。[共通の作業条件](../../references/task-contract.md)から必要な寸法と検査条件を引き継ぐ。

## 元データと実寸を保つ

元ファイルを残し、編集原本と印刷用メッシュを分ける。単位、座標、基準面、外形寸法を読み取ってから厚みや距離しきい値を操作する。単位表示だけで実寸になったと考えず、スケールの適用がモディファイアへ与える影響を確認する。

## メッシュを修正する

1. 単色表示と断面で、破片、開いた境界、重複・退化面、法線、自己交差、内部の殻を調べる。
2. 局所修正から試す。頂点結合の距離は残すべき隙間より十分小さくし、必要な穴や別部品を保持する。
3. Joinでオブジェクトが一つになったことと、材料の体積が和集合になったことを区別する。必要ならブーリアンを使い、適用後の断面を確認する。
4. 自動修復やVoxel Remeshは別版で試し、穴径、薄壁、接続、顔や刻印の変化を比較する。設定値を入れただけで厚みの成立を断定しない。
5. 目や模様がテクスチャだけなら、要求される部分を実際の凹凸へ編集する。

器の口や排液口を保ちながら、その周囲の材料を閉じた体積にできる。全開口をふさぐ修復を行わず、閉じたメッシュを実物の水密・耐圧の証明にしない。

## CADと印刷設計

- 寸法が重要な部分は基準面、原点、穴中心、穴径、厚みを数値で持つCADを使う。メッシュからSTEPへ変換しても設計履歴が戻るとは考えない。
- CADコードを生成したら実際の形状構築を実行し、演算結果と寸法を確認する。コードだけをモデル完成としない。
- 壁、細い突起、接続部、広い薄板を別々に評価する。縮尺変更は壁厚と隙間も変えるため再検査する。
- 嵌合は片側隙間と直径差を区別し、材料・方向・後処理を固定した原寸部分試作で合わせる。
- 荷重、化粧面、穴、支持、接地から向きを選ぶ。インフィルだけで強度を解決しない。
- 接地が細い場合は[造形中の安定](../3d-print-bed-stability/SKILL.md)も検討する。CAD外接面積と初層の材料領域を分け、必要なら取り外せる足・タブや分割を比較する。機能寸法を無断で拡大しない。
- 分割では位置決め、接着面、組立順、支持を外す経路を設計する。光造形の空洞は排液・通気・洗浄できる構造を確保する。

## 書出しと確認

形状を書き出して新規読込し、外形寸法、穴、壁、部品数を確認する。機種が決まっていれば[印刷と後処理](../3d-model-printing/SKILL.md)で層・経路まで確認する。

編集原本、印刷用メッシュ、変更点、確認した寸法・断面、残る試験を渡す。メッシュ検査の合格と、指定材料での強度・完成寸法を分けて報告する。
