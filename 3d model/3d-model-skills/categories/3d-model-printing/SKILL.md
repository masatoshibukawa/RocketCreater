# 方式別の印刷と後処理

方式に合わせて[FDM/FFF](../../../04_印刷と後処理/05_fdm-printing.md)または[光造形](../../../04_印刷と後処理/06_resin-printing.md)の調査を読む。比較が必要な場合を除き、両方の設定手順を読み込まない。到達点と実機操作の範囲は[共通の作業条件](../../references/task-contract.md)を使う。

## スライス前

実機・ファームウェア、材料製品・色、スライサーと版、ノズルとプレートまたはレジン、モデルの寸法と版を確認する。対応する検証済みプロファイルを起点にし、他人の3MFの機種設定をそのまま採用しない。

形状や嵌合が不十分なら[モデル修正と設計](../3d-model-preparation/SKILL.md)へ戻る。プリンター未定なら機種別G-codeや露光データを推測で作らず、印刷用メッシュまでの確認を進める。

## FDM/FFF

1. 材料の状態、供給経路、残量、プレートとノズルの準備、必要な校正を確認する。乾燥条件は材料とスプールの仕様に合わせる。
2. 実寸と方向、層高・線幅、外壁と上下の総厚、インフィル、支持・接地・seamを設定する。層高変更による総厚も確認する。
3. 全層プレビューで初層、細い接続、橋、支持から本体への移行、穴、上面を見る。速度だけでなく体積流量と機械・材料の制限を確認する。
4. 不良があるときはメーカーや使用版の手順に合う校正を追加する。安定した設定を毎回全面的に変えない。
5. 実機運転まで行う場合は初層とモデル固有の難所を確認し、異常時は停止して原因を直す。指定の冷却・取り外し後に支持除去と仕上げを行う。

## 光造形：SLA・MSLA・DLP

1. レジン・層高・温度・対応プロファイルを揃える。通常層、底層、剥離・待機を区別し、別機種の露光秒数を移さない。
2. 向きと全層画像で初期接点、island、急な大断面、吸盤状の空洞を確認する。固定の傾斜角だけで合格としない。
3. 自動支持後に、重量と剥離、細部、重要面、取り外す経路を確認する。
4. 中空部ごとに排液・通気・洗浄・乾燥・必要な硬化ができるか見る。穴の数だけで合格とせず、処理できない内部は開口・分割を見直す。
5. タンク等を機種の手順で点検し、失敗後の硬化片を残して再出力しない。
6. 材料SDSとメーカー手順に合わせて洗浄、十分な乾燥、必要な二次硬化、指定時点の支持除去を行う。レジンを含む洗浄水や溶剤は地域の処理方法を確認し、排水へ流さない。

## 次工程へ渡す条件

スライサープロジェクトと対象構成用の機械データを分けて保存する。プロファイル、向き、支持、全層で確認した点、未解決箇所を記録する。画像プレビューだけと実際のスライスを区別する。

実機・後処理まで行ったら、完成後の寸法、外観、嵌合を確認して[記録](../3d-model-records/SKILL.md)へ残す。不良があれば[トラブル対処](../3d-model-troubleshooting/SKILL.md)を使う。実機を操作していなければ出力成功や完成精度を主張しない。
