# 症状からのトラブル対処

[26症状の対処表](../../../05_トラブル対処/07_troubleshooting.md)から近い症状を選び、[共通の作業条件](../../references/task-contract.md)に沿って証拠と再試作の条件を揃える。一つの症状を一つの原因へ即断しない。

## 最初に差が現れる工程を探す

| 最初の差 | 確認するもの | 戻る先 |
| --- | --- | --- |
| モデルの単色表示や断面で既に違う | 実寸、凹凸、開口、交差、薄壁、殻 | [修正と設計](../3d-model-preparation/SKILL.md) |
| 立体表示は正しいがスライスで消える | 線幅、層高、壁・穴、支持、修復された箇所 | [修正と設計](../3d-model-preparation/SKILL.md)と[印刷](../3d-model-printing/SKILL.md) |
| 経路・層画像は正しいが実物が違う | 機種設定、材料状態、温度、初層、露光、支持、機械状態 | [方式別の印刷](../3d-model-printing/SKILL.md) |
| 洗浄・硬化・研磨・組立の後で違う | 各処理の時点、条件、測定値、接点と保持方法 | [後処理](../3d-model-printing/SKILL.md)と[記録](../3d-model-records/SKILL.md) |

元形状と書出し形状、スライス、実物の写真や測定、処理時点を照合する。機種・材料・プロファイル・モデル版のうち、診断を左右する不足だけを確認する。未観察の破断面や内部を見たものとして説明しない。

## 一度の再試作で調べることを絞る

1. 症状、位置、現れる層/時点と、仮説を支持・反証する証拠を記録する。
2. 単位・プロファイル不一致や、原本に存在する欠損等から先に確認する。修正できる箇所は局所的に直す。
3. 調べる仮説に対応する変更を一つ選び、材料、向き、層高、後処理等の固定条件を明記する。
4. 原寸の対象部分または既知の試験モデルで比較し、合格条件と測定時点を先に決める。
5. 結果で仮説を採用・棄却し、次の変更を選ぶ。同条件の失敗を根拠なく繰り返さない。

形状・向き・材料・露光等をまとめて変えた比較で、特定の一項目が原因だったと断言しない。複数変更が必要なら、どの効果を分離できないか記録する。

## 戻す判断

- 必要な形がテクスチャにしかないなら幾何形状を作る。テクスチャ解像度だけを上げない。
- 折れる接続は断面、根元、方向、層間を見て、インフィルや露光だけで解決しようとしない。
- 光造形の脱落は重量・支持・断面・空洞・露光を切り分ける。失敗後の硬化片や未処理の空洞を残して同じ出力を再開しない。
- 背面やポーズ自体が違う場合は[生成](../3d-model-ai-generation/SKILL.md)へ戻す。小さな局所不良で全体の再生成を強制しない。

## 渡すもの

観察事実、候補原因と確からしさ、修正した版、次の一試行、合否または未検証の状態を返す。[比較試験CSV](../../../07_チェックと記録/templates/experiment-log.csv)は必要なら作業先へコピーして使い、提案を実測結果として埋めない。
