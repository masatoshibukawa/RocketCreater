# 速度・流量・冷却を合わせる

[実機失敗からの対処](../../../09_実機トラブルと機種別対策/fdm-reliability.md)の速度・流量・冷却を読む。レジンの露光・剥離速度へFDMのmm/sを転用しない。

## 条件を固定する

機種・ファームウェア、ソフトと版、ノズル、材料製品・色・径、プレート、層高と線幅、良好だったプロファイルを引き継ぐ。不明なら既存記録を探す。広告の最高速度や別機種の設定を初回値にしない。

## 症状に合う制限を選ぶ

- 初層、本体外壁・内壁・充填・表皮、ブリム・支持、橋、移動を別々に見る。Print Speedだけを下げて個別の高速上書きを残さない。
- 速度mm/sと加速度mm/s²、方向転換、本体の速度倍率を分ける。揺れには動作と向きも比較する。
- `Q ≈ 線幅 × 層高 × 速度`で必要流量の目安を出す。最大流量、押出し倍率、PA／フローダイナミクスは別の校正。流量不足を倍率増加だけで隠さない。
- 短い層は最小層時間、最低速度、ファンを確認する。全層低速や全機種ファン最大を一律に適用しない。
- スライス後に速度・流量表示と難所を確認する。G-codeの指令送り速度と実機の測定速度を区別し、校正用の特殊上書きを通常プロファイルへ持ち込まない。

## 比較して渡す

観察で候補を絞り、機種用の既知良好設定から一つの変更を比較する。終盤の揺れには全高に近い試験、流量には材料・ノズル・温度を揃えた試験を選ぶ。実施していない校正値を確定値にしない。

基準と変更後の特徴別速度、加速度、流量上限、冷却、測定箇所、採否・未確認を保存する。S5フィンの35 mm/sは今回の局所的な再試行上限で、全プリンターの推奨値ではない。
