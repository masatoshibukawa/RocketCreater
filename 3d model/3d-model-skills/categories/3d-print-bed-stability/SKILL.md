# 接地と造形中の安定を確かめる

[実機失敗からの対処](../../../09_実機トラブルと機種別対策/fdm-reliability.md)の接地・途中転倒の節を読む。レジンの剥離や露光は[光造形](../3d-model-printing/SKILL.md)で扱う。

## 観察から判断する

1. 「土台」が製品の基体、モデル接地、ブリム／ラフト、サポートのどれかを特定する。保存済みのチャット・実物記録を先に調べ、既知の機種を聞き直さない。
2. 原寸で初層の材料領域と接続を見る。外接長方形、パージ線、離れた島の凸包を、そのまま有効な支持面に数えない。
3. 初層から不良か、付いた後に反る／揺れる／接触するかを分ける。接地面積や固体CADの重心投影だけで転倒しないと判定しない。
4. 向き、除去できる足／タブ、ブリムの幅と接続、支持の根元を比較する。機能寸法を勝手に拡大しない。補助部分の除去性と嵌合面も確認する。
5. ベッドの運動、方向転換、ノズル接触、冷却も調べる。速度に関係するなら[速度校正](../3d-print-speed-calibration/SKILL.md)へ進む。

## 確認して渡す

初層の拡大図と接続、候補の向き、ブリム込みのベッド範囲、原寸を保つ部分試験を返す。終盤転倒には、元の高さ・薄さに近い1個で検証する案を含める。初層成功を全高成功へ読み替えない。

S5フィンの20～35 mmブリムは局所的な未検証の再試行案。他機種の標準値にしない。観察していない接着強度・転倒原因は未確定とし、実機を動かさなければ印刷成功と報告しない。
