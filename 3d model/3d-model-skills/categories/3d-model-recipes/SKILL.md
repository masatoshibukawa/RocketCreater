# 条件に合わせる制作レシピ

[制作レシピと指示文](../../../06_制作レシピ/08_recipes-and-prompts.md)から近い作り方を選ぶ。例のフクロウ、サイズ、穴径をユーザーの要件に置き換え、[共通の作業条件](../../references/task-contract.md)で到達点と合格条件を揃える。

キャラクターのプラスチックフィギュアは[専用スキル](../../figurines/3d-character-figurines/SKILL.md)を使い、参照の一貫性・顔の形状、耳/尻尾、分割・ダボと台座、印刷/配色/塗装を詰める。

## レシピを選ぶ

| 作るもの | 具体化すること | 実作業へつなぐ先 |
| --- | --- | --- |
| 置物・マスコット | つながる手足、底面、背面、残す凹凸、最終サイズ | [生成](../3d-model-ai-generation/SKILL.md)→[修正](../3d-model-preparation/SKILL.md) |
| 寸法付きプレート・ケース・治具 | 原点、基準面、外形、穴中心・径、壁、嵌合 | [CADと印刷設計](../3d-model-preparation/SKILL.md) |
| ロゴ・浮き彫り | 閉じた輪郭、底の厚み、凹凸の高さ、文字の綴り | [形状と寸法の編集](../3d-model-preparation/SKILL.md) |
| プリンターがなく外注する | 単位、数量、材料、重要面、嵌合、仕上げ、合格条件 | [受け渡しと記録](../3d-model-records/SKILL.md) |

見た目だけの入力と寸法を合わせる部分を分ける。浮き彫りが必要なだけなら、全方向のメッシュ生成を必須にしない。実物の複製には、見えない形と寸法の実測が必要か確認する。

## 指示文を作る

画像/3D向けは、被写体→大きな形→姿勢と接続→底面→必要な細部を具体的に書く。入力言語と形式はサービスに合わせる。印刷条件の記述だけで幾何形状が保証されたとは扱わない。

CAD向けは単位、座標、基準面、穴位置・径、厚み、変更可能な変数、出力形式を示す。寸法表と実際に作られた形状を照合し、コードの完成と形状構築の成功を区別する。

例の数値を変更したら、接続の最小断面、隙間、穴、支持、造形範囲まで再確認する。全体の縮小率だけで印刷可能性を引き継がない。

## 作って確かめる

依頼が手順・指示文なら、それを成果物として具体化する。モデル作成まで含まれる場合は、利用できるツールで生成/形状構築、編集原本と印刷メッシュの書出し、再読込での実寸確認まで進める。ツールがない場合は実行可能な入力・コードと未実施部分を区別して渡す。

方式と機種が決まったら[印刷と後処理](../3d-model-printing/SKILL.md)へつなぎ、最初に試す原寸部分を決める。手順を書いたことを実機の成功として報告しない。
