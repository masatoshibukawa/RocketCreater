# Raise3D E2CF

方式は[短繊維入り材料](../../../materials/3d-material-fiber-filled/SKILL.md)を使う。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

E2CFは短繊維入りフィラメント向けFFF/IDEX。E2用のプロファイルや、連続繊維の敷設手順をそのまま使わない。

ideaMakerで正確な製品（PA12 CF/CF+等）とノズル構成を選び、耐摩耗部品と給材抵抗、ドライボックス・材料の乾燥を確認する。防湿箱に入れたことだけで既に湿った材料が乾いたと判断しない。

PA12 CF Supportは剥離用の別製品。水溶性として扱わず、対応する本体製品・界面と取り外す経路を確認する。IDEXの高さ/位置・待機滴下・衝突と初層を小片で評価し、長い薄い部品は全高の安定も試す。

根拠：[E2CFの仕様と材料例](https://www.raise3d.com/E2CF)、[PA12 CF Support](https://www.raise3d.com/materials/pa12-cf-support)。OFP対応も実際の製品・版のプロファイルまで照合する。
