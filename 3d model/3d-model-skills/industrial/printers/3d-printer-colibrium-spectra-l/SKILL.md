# Colibrium Additive Spectra L

方式は[工程スキル](../../3d-print-metal-eb-pbf/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

Spectra Lの本体/ソフト版とPoint Melt等のパラメーターを識別し、Grade5/23とP-Material等の表示を資料の範囲で照合する。Spectra HやQ10plusの対応材・性能を本機へ追加しない。

真空・予熱・冷却と半焼結粉末ケーキの回収/再使用を工程に含める。粉末が支えることと熱の均一化の支持を分け、細部・内部流路の除粉と検査経路を確認する。

Grade23/v1.2資料の試験状態、方向、表面と必要な熱処理/HIPを用途へ照合する。造形直後のカタログ寸法と、支持/加工後の最終寸法を分けて見積もる。

根拠：[機種資料](https://www.colibriumadditive.com/printers/eb-pbf-printers/spectra-l)、[ドイツ語版](https://www.colibriumadditive.com/de/printers/eb-pbf-printers/spectra-l)、[v1.2/Grade23資料](https://www.colibriumadditive.com/sites/default/files/SpectraLv1.2_Ti6Al4V-Gr23_CMDS_20240709_RevB.pdf)。
