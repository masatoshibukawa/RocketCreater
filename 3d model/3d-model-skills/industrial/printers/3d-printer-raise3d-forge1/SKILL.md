# Raise3D Forge1 / MetalFuse

方式は[工程スキル](../../3d-print-metal-bound/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

本体だけで最終金属が得られる構成とみなさない。金属/セラミック等の契約構成、材料、ideaMaker Metalの版とプロファイル、脱脂・焼結の受入先を確認する。

MetalFuse掲載例はUltrafuse316L/17-4PH、D200-E触媒脱脂とS200-C焼結。Markforgedの溶剤脱脂を同じ工程へ移さない。Forge1の造形域、グリーン品、炉に入る寸法、焼結/加工後の寸法は別に管理する。

Forward AMのガイドにはMetal Solution終了表示があるため、掲載された材料とサービスが現在も調達/受入可能かを確定してから出力計画を作る。既存在庫だけで後工程が成立すると判断しない。焼結倍率とセッター、脱脂経路は処理先指定の原寸試験で確認する。

根拠：[MetalFuseの工程構成](https://www.raise3d.com/metalfuse)、[Forge1](https://www.raise3d.com/raise3d-forge1-a-metal-fff-3d-printer)、[Ultrafuseの終了表示がある公式ガイド](https://forward-am.com/gain-knowledge/ultrafuse-metal-solution-quick-start-guide)。
