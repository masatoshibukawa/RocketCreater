# DMG MORI LASERTEC 65 DED hybrid 2nd Generation

方式は[工程スキル](../../3d-print-metal-ded/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

LASERTEC 65 DED hybrid 2nd Generationを識別し、他サイズのLASERTECや粉末床方式の機械と区別する。DED用粉末、母材、ノズルと粉末送り、検証された材質/パラメーターを確認する。

補修では母材の組成・熱処理/損傷・表面準備、溶け込みと希釈、残留応力・割れを確認する。材料一覧から任意の母材へ健全に接合すると推定しない。

5軸溶着と切削を、クランプ/座標基準、途中で加工可能な面、ノズル/工具の衝突と到達性、熱履歴を含む一つの工程として設計する。内製機能に含まれない熱処理や検査は別に計画する。

根拠：[DMG MORIの粉末DEDとハイブリッド機](https://us.dmgmori.com/products/machines/additive-manufacturing/powder-nozzle)。メーカーが提示する最大性能を全合金/形状に適用しない。
