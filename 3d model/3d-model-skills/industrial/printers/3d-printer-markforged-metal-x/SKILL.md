# Markforged Metal X

方式は[工程スキル](../../3d-print-metal-bound/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

Gen1/2、金属製品の世代とEiger/プロファイル、Wash-1・Sinter-1/2構成を確認する。現行表では316LはMetal X非対応でFX10対応。将来材の脚注がある古いPDFを現在の対応表にしない。

金属の本体/支持とセラミックの離型界面を区別する。支持の除去は焼結後の経路と加工代まで設計する。脱脂は指定の減量と十分な乾燥を確認し、外観や固定時間だけでブラウン品を炉へ移さない。

同材をまとめて処理する条件、トレー/炉の制約、収縮と垂れ、後熱処理・機械加工を確認する。閉じたインフィルがある部品を無制限に切削せず、外壁と空洞を把握する。

根拠：[材料/設備対応表](https://support.markforged.com/portal/s/article/Material-Compatibility-Matrix)、[脱脂と乾燥](https://support.markforged.com/portal/s/article/Understanding-the-Wash-Process)、[工程と後加工](https://markforged.com/resources/learn/design-for-additive-manufacturing-metals/metal-additive-manufacturing-introduction/metal-additive-manufacturing-process)。
