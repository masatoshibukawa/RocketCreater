# HP Metal Jet S100 / S100P / S100D

方式は[工程スキル](../../3d-print-metal-binder-jet/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

S100/S100P/S100Dの構成を特定する。現行ページは構成別に硬化方法と有効高さを分けており、旧ホワイトペーパーの高さを一律に設定しない。

材料はHPのQualified/Certified/Open development等、供給元・検証段階と構成を照合する。開放材料開発が可能という説明を、未検証粉末の完成品性能の保証にしない。

プリンターだけでなくビルドユニット、硬化、粉末管理/除粉、焼結炉の実構成と能力を確認する。支持不要の造形説明から焼結治具不要を導かず、グリーン品の取り出しと収縮・垂れを試験する。

根拠：[現行構成](https://www.hp.com/us-en/printers/3d-printers/products/metal-jet.html)、[材料と検証区分](https://www.hp.com/us-en/printers/3d-printers/materials/metals.html)、[旧版工程資料](https://h20195.www2.hp.com/v2/GetDocument.aspx?docname=4AA7-3333ENW)。
