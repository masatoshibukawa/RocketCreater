# EOS M 290

方式は[工程スキル](../../3d-print-metal-lpbf/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

材料はMDSの合金名だけでなく、M 290用PDSの層厚、プロセス名/ID、ソフト条件まで照合する。EOS全体の材料一覧を本機の無条件対応へ置き換えない。

Ti64 Grade23/40µm等の工程ごとの成熟度・試験状態を読み、別の層厚/グレードやマルチレーザー機のスループット・物性を移さない。原料の再使用/混合・装置清浄度とガスは製品と実設備の手順を使う。

熱の逃げる支持、反り/リコーター、下向き面、粉抜きと加工代をプレビュー/設計レビューする。造形板からの切離しと熱処理の順を材料指定へ合わせ、切離し後の寸法と必要な密度/欠陥・表面を確認する。

根拠：[M 290製品](https://www.eos.info/metal-solutions/metal-printers/eos-m-290)、[Ti64の機種用PDS例](https://www.eos.info/metal-solutions/data-sheets/titanium/pds-eos-titanium-ti64-grade23-eos-m-290-40um)。
