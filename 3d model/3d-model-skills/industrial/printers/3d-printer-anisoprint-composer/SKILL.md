# Anisoprint Composer A4/A3

方式は[工程スキル](../../3d-print-continuous-fiber/SKILL.md)を併用する。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

A4/A3の実機・ヘッド/改訂とAURA等の対応ソフトを確認する。専用連続繊維、マトリックス用樹脂、樹脂だけの領域/外周用材料を別の役割として記録する。Markforgedのスプールやノズル条件へ置き換えない。

メーカー手順でロード/アンロード、カッター、コンポジット経路、Zオフセットを確認する。繊維の残り・詰まり・引きずりは、普通の樹脂リトラクション増加だけで追い込まない。

繊維を通せる幅と曲がり、配置層、樹脂との境界をプレビューし、根元/穴周囲を含む原寸片で荷重方向と層間を試す。汎用樹脂が使えるという説明から、任意の樹脂と繊維の含浸・接着を保証しない。

根拠：[Composerマニュアル](https://support.anisoprint.com/composer/manual)、[給材と調整のガイド](https://support.anisoprint.com/composer/guide)。
