# UltiMaker Factor 4 / Factor 4+

方式は[短繊維入り材料](../../../materials/3d-material-fiber-filled/SKILL.md)を使う。[機器・材料表](../../../../11_カーボンと金属/equipment-and-materials.md)から必要な資料だけ読み、公式対応・実機設定・実物の成功を別に記録する。

この機器は短繊維入り樹脂のFFF。連続カーボンの敷設機や金属粉末床機として扱わない。最初にFactor 4かFactor 4+かを識別する。

現行PPS CF表ではFactor 4はHT0.6、Factor 4+はCC+0.6優先、4+のHT0.6は実験扱い。PET CFの表は別のコア組を持つ。S5へ耐摩耗コアを付けたことからPPS CF対応を導かない。

実機のコア、Cura/FW、2.85mm製品、庫内・プレート/接着剤、乾燥と給材を合わせる。PPS CFの熱性能は指定の試験状態と方向で読み、根元/Zの実部品を評価する。支持材もPVAの実験扱い等を製品別に確認する。

根拠：[PPS CFの世代別表](https://support.ultimaker.com/s/article/How-to-print-with-UltiMaker-PPS-CF)、[PET CFの世代別表](https://support.ultimaker.com/s/article/pet-cf-instructions)。
