# 金属DED・ワイヤー・粉末・WAAM


ワイヤー/粉末の供給と、レーザー/アークの熱源を先に特定する。MeltioのワイヤーレーザーDED、DMG MORIの粉末ノズルDED、WAAM3Dのアーク方式で材料と制御を共有できるとはみなさない。

造形基板または補修母材の合金・状態、溶け込み/希釈、形状・固定、熱履歴を記録する。工具経路はビード幅、高さ、交差/角の熱だまり、層間温度と待機、衝突・ノズルの到達を含め、機種で検証された条件から作る。

薄いフィンや微細流路へ粉末床方式の最小肉厚を移さない。ニアネット形状と仕上げ加工代を分け、基準・つかみ代と加工経路を確保する。ハイブリッド機は途中で加工できる面も活用するが、すべての検査/熱処理が省けるとはみなさない。

複数ワイヤー/粉末の切替機能は、任意の異種金属が健全に接合できることを意味しない。組成の遷移、割れ、界面の脆化、熱膨張差と用途の必要性能を製品・組別に評価する。

MeltioのFAQでは銅・アルミ系に開発/パラメーター化の記載がある。WAAM3Dも材料ごとのパラメーター成熟度を分ける。掲載された金属名と量産用に検証済みの条件を区別する。
