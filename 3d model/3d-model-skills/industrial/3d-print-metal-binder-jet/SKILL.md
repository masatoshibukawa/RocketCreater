# 金属バインダージェット


レーザー溶融ではなく、粉末とバインダーからグリーン品を作って焼結する方式として扱う。粉末製品、バインダー、機種構成、硬化・粉抜き・炉と処理条件を一組で確認する。

造形中に粉末で支えられることと、取り出すグリーン品の強度・焼結中の垂れを分ける。積層配置は取り出し時の壊れやすさ、粉抜き経路、分離とトレー載せ、セッター/焼結治具まで含めて比較する。

縮みは軸・形状・密度・炉の工程で校正する。自動スケール補正の有無を確認し、別製品の固定倍率を追加しない。粉末が残る空洞や仕上げ加工面には、排出・加工・検査の経路を設計する。

HP S100/S100P/S100Dは硬化の構成と有効造形域が同じとは限らない。旧ホワイトペーパーだけで現在の構成を確定しない。粉末のQualified/Certified/Open development等の区分も、当該供給元・構成の範囲で照合する。

出力直後を金属完成品とせず、焼結・必要な熱処理/加工後に寸法・密度/空隙・必要な強度/耐食を評価する。造形速度の比較には硬化、粉抜き、炉の処理能力と歩留まりを含める。
