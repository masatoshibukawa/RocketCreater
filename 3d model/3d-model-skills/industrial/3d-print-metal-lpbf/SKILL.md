# 金属レーザー粉末床溶融・LPBF


装置、レーザー/光学系、粉末製品とロット/再使用、層厚、承認パラメーター、ソフト版を一組で記録する。合金名が一致しても別機種や層厚の設定を移さない。炉で大きく収縮する金属FFFの倍率を適用しない。

## 熱と支持を含む設計

姿勢は表面品質だけでなく熱の流れ、反り、支持の拘束と除去、リコーターへ突き出す変形を比較する。粉末床に埋まるから支持不要とはみなさない。張り出し、薄肉、厚薄差、下向き面、加工基準とクランプ面を確認する。

内部流路・格子は粉末を取り出し検査できる開口と経路を用意する。通路がCAD上でつながっていることだけを粉抜きの証明にしない。試験片や造形位置、必要な密度/CT・組成/寸法等の合格条件を受託先と決める。

粉抜き・必要な応力除去・造形板からの切離し・支持除去・熱処理/HIP・加工・表面仕上げの順を、材料と設備の指定へ合わせる。切離し前後の変形を測る。すべての合金へ同じ熱処理/HIPを義務付けたり省略したりしない。

根拠：[EOS M 290](https://www.eos.info/metal-solutions/metal-printers/eos-m-290)、[Ti64の機種・層厚別PDS例](https://www.eos.info/metal-solutions/data-sheets/titanium/pds-eos-titanium-ti64-grade23-eos-m-290-40um)。取り扱いは[施設と品質](../../../11_カーボンと金属/facility-and-quality.md)を確認し、未承認の粉末・開放作業やレーザー条件を推測で確定しない。
