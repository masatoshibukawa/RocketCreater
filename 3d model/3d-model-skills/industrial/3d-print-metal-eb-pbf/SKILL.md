# 金属電子ビーム粉末床溶融・EB-PBF


電子ビーム、真空・高温環境、粉末床の予熱/半焼結は、レーザーLPBFと異なる工程条件。機種・ソフト/戦略・グレードに対応する資料を選ぶ。Spectra LのTi6Al4V Grade 5/23の掲載を、全金属や他Spectra機へ広げない。

半焼結粉末による保持と、熱の均一化等に必要な支持を分ける。「浮かせて造形可能」という説明だけで、今回の形状の支持・拘束をなくさない。

冷却から粉末ケーキの取り出し・回収、内側の粉抜きと確認、切離し/支持除去・加工までの経路を設計する。細い内部流路が取り出せるかを受託先の実績/試験片で確認する。LPBFの表面粗さや小穴の最小値をそのまま使わない。

必要な熱処理/HIP、最終組成・密度/欠陥・表面と疲労は、当該PDSと用途の条件で判断する。真空で造形することだけで酸素汚染や全欠陥が解消されるとはみなさない。

根拠：[Spectra L英語版](https://www.colibriumadditive.com/printers/eb-pbf-printers/spectra-l)、[ドイツ語版](https://www.colibriumadditive.com/de/printers/eb-pbf-printers/spectra-l)、[v1.2/Grade 23の資料](https://www.colibriumadditive.com/sites/default/files/SpectraLv1.2_Ti6Al4V-Gr23_CMDS_20240709_RevB.pdf)。この資料の試験状態を今回の部品の認証に置き換えない。
