# UltiMaker S5

確認日：2026-11-06。この機種の条件差を判断する。[機種条件の受け渡し](../3d-printer-profiles/references/profile-contract.md)と[方式別の確認](../../../09_実機トラブルと機種別対策/fdm-reliability.md)から必要な項目を使う。

## この機種で変わる判断

- 実機は2.85 mm系。材料の製品・色、AAの径、左右の構成をCuraと本体で照合する。単材の片側使用と、両コアが装着されていることを区別する。AAは造形材、BBはPVA用等、該当版の材料互換表を優先する。
- ガラス面の残渣とノズルの付着物を確認し、材料指定の薄い接着剤を使う。active levelingの範囲外なら機種手順で手動調整する。S7のフレキシブル表面の手順へ置き換えない。
- 保存3MFを再読込すると既定値が再解決され得る。機種・材料だけでなく、最終UFPの温度、使用押出機、特徴別速度と初層を再確認する。CuraのFastを既知良好な基準とみなさない。
- 今回のフィンは初層後に終盤で転倒した。広いブリムと35 mm/s以下は未検証の局所再試行案であり、S5標準値ではない。ノズル接触、反り、揺れも調べる。

## 最小限の比較試行

同じ材料・高さ・姿勢のフィンをまず1枚で比較し、初層、失敗していた高さ、終盤を観察する。既存のscripts/check_ultimaker_slice.pyは該当構成の経路確認用で、実物成功の判定器ではない。

## 接続

Curaから同一LANのS5を検出し、必要なら本体で確認したIPで追加する。クラウドはDigital Factory経由。オフラインは対応UFP等をUSBメモリーで渡す。USBメモリーとPC直結ケーブルを混同しない。 OSとソフトの組合せは[接続表](../../../09_実機トラブルと機種別対策/connections.md)を使う。認証情報や機器固有番号を公開記録へ書かない。
