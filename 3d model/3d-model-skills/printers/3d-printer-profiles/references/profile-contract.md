# 機種条件と比較試行の受け渡し

メーカー名だけで判断せず、型番・世代、後付け構成、ファーム、スライサーと版、OSとCPU、材料、ノズル／コア、プレート／タンクを引き継ぐ。既存の機材記録・チャットにある値を先に使い、測定や現物確認が必要な点だけ残す。

FDMでは層高・線幅、向き、本体と補助接地の実接続、特徴別速度、加速度、本体倍率、流量上限、冷却を確認する。レジンでは樹脂製品・色、温度、層高、底／通常露光、剥離方式、支持とカップを確認する。両方式の数値を移し替えない。

接続は実機登録、認証、ファイル転送、印刷開始、実物の合格を分ける。IP・アクセスコード・APIキー・機器固有番号は個別環境で扱い、公開する試験記録に埋め込まない。既存の研究室ネットワークの設定を推測で変更しない。

返す内容は、確定した構成、参照した公式ページと適用版、変更前後の設定、観察した事実、次の比較試行、未確認事項。スライス成功、プログラム完了、写真だけの推測を、実印刷・強度の合格へ読み替えない。

既知良好な標準プロファイルを保ち、症状に対応する変更を比較する。温度・加速度・速度・接地を同時に変えたら、原因を分離できないことを残す。部品を変えたら公差・荷重方向・除去性も確認し直す。
