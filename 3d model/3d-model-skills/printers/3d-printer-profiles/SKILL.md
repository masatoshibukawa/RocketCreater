# 3Dプリンター機種別の選択

ラベル・機材記録から型番と世代を確認し、該当する1機種のスキルを読む。似た名前の機種、後付け機器、ファームの機能を一括りにしない。今回の実機事例はS5で、他の機種は公式資料を調べた参照用である。

未掲載でもメーカー・型番・構成を調べ、近い機種の数値を借用せず、対応マニュアルと検証済みプロファイルを使う。機種未定なら共通の接地・速度の検討を進め、機械用データを確定しない。

接続は[ソフト・PC別の接続表](../../../09_実機トラブルと機種別対策/connections.md)と[接続スキル索引](../../connections/3d-printer-connection/SKILL.md)を併用する。接続、ファイル転送、印刷開始、造形成功を別の状態として扱う。
