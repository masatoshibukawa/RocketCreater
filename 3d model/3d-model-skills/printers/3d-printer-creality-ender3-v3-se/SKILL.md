# Creality Ender-3 V3 SE

確認日：2026-11-06。この機種の条件差を判断する。[機種条件の受け渡し](../3d-printer-profiles/references/profile-contract.md)と[方式別の確認](../../../09_実機トラブルと機種別対策/fdm-reliability.md)から必要な項目を使う。

## この機種で変わる判断

- SE専用の機種・ノズル設定を使う。KEや無印V3の速度・開始コード・造形域を流用しない。
- 本体の自動レベリング後も初層の実物を見る。ガントリー、ベッド、ベルトや車輪の緩み、ノズル残渣が疑われる場合は該当手順で確認する。
- 可動ベッド上の細い根元では加速度と向きも検討する。設定の最高速度を薄い部品の初回に採用しない。
- 表面の残渣と材料指定の接着条件を確認する。初層の擦れを接着剤や押出し量だけで隠さない。

## 最小限の比較試行

既知良好なSEプロファイルで接地の小さい原寸部を試し、全高の1個へ進む。初層不良と終盤の揺れを別の結果にする。

## 接続

公式手順に対応するメモリーカード等の媒体を基準にする。SEにKEと同じ標準LAN機能があると仮定しない。USB直結を使うなら用途・ファーム・ソフトの対応を別確認する。 OSとソフトの組合せは[接続表](../../../09_実機トラブルと機種別対策/connections.md)を使う。認証情報や機器固有番号を公開記録へ書かない。
