# 設定と実際の造形経路を照合する

対象モデル・スライサープロジェクト・スライス済みファイルをハッシュと版で結ぶ。[機種別スキル](../../printers/3d-printer-profiles/SKILL.md)と[接続手順](../../connections/3d-printer-connection/SKILL.md)を使い、準備・転送・実機開始を区別する。今回の検証依頼だけで実機開始へ進めない。

## プロファイルを確かめる

機種名の表示だけでなく、実際に読み込んだ機械/ノズル/材料/プレート/工程のプロファイルと版、継承後の有効値を記録する。別機種の登録情報へ、初期機種の温度・開始コード・可動範囲が残っていないか確認する。メーカー固有の開始/終了コードを汎用の短いコードへ置換しない。

材料スロット・支持界面・工具番号の割当ても実構成と照合する。3MFがモデルのみか、設定付きプロジェクトか、G-code入りかを区別し、必要なプレートの経路が実際に含まれることを確認する。

## 見るのは生成された層と経路

全層を通して確認し、特に初層、接続/薄部の開始、断面が急変する層、背の高い部分、終盤を拡大する。

| 確認対象 | 見る証拠と判断 |
| --- | --- |
| 接地 | 初層のモデル・ブリム・ラフトの実線と接続。CAD外接面積、設定幅、完成品の台座を実接地面積と扱わない |
| 支持 | 支持が実際に生成された範囲、土台からの連続、モデルとの接点、除去できる方向。「支持ON」だけでは成立しない |
| 薄部・穴・文字 | 最終サイズで線/島/穴が残るか。警告数が少なくても、顔や嵌合の局所欠損を見落とさない |
| 速度と移動 | 特徴別の押出速度、加速度、流量、最小層時間、移動/衝突の懸念。背が高い層の横力と冷却も比較する |
| 配色と給材 | 実工具/色の遷移、パージと配置、薄い明色面への内部色の透け。表示色だけでは適合を認めない |

FDMの移動経路を読むときは、単位、絶対/相対XYZ、絶対/相対E、G92、モーダルなF、送り倍率、工具変更、弧移動等の使用命令を識別する。押出のない移動を造形線・支持量へ数えず、絶対E値の単純合計を使用量にしない。コメントの機能名・層表記はスライサー/版で異なる。

解析器が未対応の命令・圧縮形式・バイナリG-codeを含む場合は、その検査を`partial`/未確認とし、対応するスライサーの再生へ戻る。0件と測定不能を分ける。Fの上限は指令上の上限で、実速度・加速度・機械の追従を保証しない。

光造形では当該機種の最終層画像で島、空洞の開閉、排液/通気、支持接点を確認する。FDMのG-code解析を流用しない。金属/連続繊維の経路・処理条件は[専用方式](../../industrial/3d-carbon-metal-printing/SKILL.md)で扱う。

## 次工程へ渡す

層番号とZ高さ、対象プレート、画像/ログ、実際に使った設定、未確認項目を[検証記録](../../../13_公開スキル比較と検証改善/verification-record.example.json)へ残す。経路確認の合格から全高の物理安定・支持除去・完成寸法へ合格を引き継がない。[接地](../../categories/3d-print-bed-stability/SKILL.md)と[速度校正](../../categories/3d-print-speed-calibration/SKILL.md)は当該部品の条件に合わせて併用する。
