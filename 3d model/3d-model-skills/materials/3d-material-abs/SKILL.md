# ABS

製品・実機・根拠の確認は[材料条件](../3d-print-materials/references/material-contract.md)を使う。今回の用途と症状に必要な確認だけを選び、設定の差分・実測・未検証点を記録する。

反りと層割れは、接地不足だけでなく温度差と収縮を確認する。ブリムを大きくするだけで熱環境の不足を解決しようとしない。ABS-like光硬化樹脂を熱可塑性ABSとして扱わない。

## 構成と試作

1. 対象製品に必要なノズル・ベッド・囲い/庫内条件を、実機と周辺部品の許容範囲へ照合する。開放機を囲えば十分とはみなさず、機種が許可した運用を選ぶ。
2. 排気と室内の換気を確保しつつ、造形に当たるドラフトを避ける。フィルターや囲いの存在だけで排出管理完了としない。材料SDSと施設の方法を使う。
3. 広い平面・角の反り、層方向と冷却、取り外し後の収縮を確認する。まず原寸の嵌合箇所を測定し、固定の収縮率をモデル全体へ先に適用しない。
4. 本出力では全高・長時間での層割れと接地を別に確認する。小片の成功だけでは大きい薄肉を承認しない。

支持材は当該製品の対応表を使う。UltiMaker PVA/ABSの実験扱い等を、PLA/PVAの正式対応から推定しない。溶剤平滑化を通常の初層不良対策として追加しない。

根拠：[Prusa ABS](https://help.prusa3d.com/article/abs_2058)、[UltiMaker PVAの組み合わせ](https://support.ultimaker.com/s/article/1667337600656)。
