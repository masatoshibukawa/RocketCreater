# 材料条件と確認の範囲

## 最初に確定するもの

既存ファイル・写真・スライサープロジェクト・実機ログから確認する。分からない値は不明のまま残し、一般的な材料表で穴埋めしない。[記入例](../../../../10_材料と組み合わせ/material-record.example.json)を必要な範囲で使う。

| 対象 | 記録する条件 |
| --- | --- |
| 用途 | 荷重方向、剛性・衝撃・繰返し、最高使用温度、日射、水分、必要寿命、許容寸法差 |
| FDM製品 | メーカー、正確な商品名・改質・充填材、色、径、ロット、開封・保管・乾燥履歴 |
| レジン製品 | 商品・世代・色・ロット、有効期限、攪拌、液温、メーカー承認の混合か |
| 機械 | 型番・世代・FW、コア/ノズル径と材質、フィラメント径、送り経路・装置、許容温度、囲い・排気 |
| 接地 | プレート商品・コーティング、のりの製品と目的（接着/離型）、初層・ブリムの接続 |
| 根拠 | 機種の対応表、材料TDS/SDSと改訂、スライサー/プロファイルの版、公式/試作/非対応/不明 |

設定は「機械と周辺品の許容範囲」と「当該材料製品の指定条件」の両方を満たす必要がある。温度上限だけ合っても、熱環境・流量・送り・摩耗・プレートが合うとは限らない。別機種・色・製品の数字を移さない。

## 数値の扱い

- 乾燥は材料とスプール、乾燥機の仕様を照合する。保管用乾燥剤と加熱乾燥を区別する。家庭用オーブンや加熱ベッドの温度精度・許可を推測しない。
- FDM速度は外壁・初層・小形状・移動と加速度、最大体積流量を併記する。同じmm/sでも線幅×層高で必要流量が変わる。以前のS5フィン再試行の上限・大きいブリムは、その部品の試行条件。
- レジンは機種の光学系、材料世代・色、層高・温度、剥離方式、洗浄機・硬化機を揃える。405nm表記だけで対応や同じ露光を決めない。
- TDSの射出試験片と積層試験片、XYとZ、乾燥時と吸湿後、熱処理の有無を区別する。HDTや軟化温度を連続使用温度・許容応力へ変換しない。

## 試作で確かめるもの

1. 症状や用途に合う小試験を選ぶ。接地/取り外し、壁・流量、橋・支持、嵌合、同じ層方向の曲げ等。試験が不要な安定条件まで毎回全面校正しない。
2. 変更点と不変条件、測定方法、許容値、停止条件を先に書く。メーカーの対応外条件は、通常の印刷手順に紛れ込ませない。
3. 部分試作では確認できない全高の揺れ、長時間の吸湿、反り、樹脂の排液等を本形状で別に確認する。
4. 破損・給材不良・異常な摩耗・プレート損傷・漏れが見えたら止め、原因が直るまで同じ出力を繰り返さない。

引き渡しは、選択した製品と構成、根拠URL/版、設定の差分、実測値、写真、残る不明点。資料を読んだこと、スライスできたこと、出力・後処理できたこと、用途を満たしたことを別々に記録する。

乾燥の製品差・スプール差は[Prusa公式](https://help.prusa3d.com/article/drying-filament_332086)、機械・ノズル・送り・プレートの照合例は[Bambu公式対応表](https://wiki.bambulab.com/en/general/filament-guide-material-table)を参照する。ここに記載した照合手順は複数資料を踏まえた運用上の提案で、全製品共通の検証済み設定ではない。
