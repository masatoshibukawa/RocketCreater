# 銅・Cu/CuCrZr等

[方式索引](../../industrial/3d-carbon-metal-printing/SKILL.md)で供給形態と造形方式を選び、[施設・品質の記録](../../../11_カーボンと金属/facility-and-quality.md)へ製品・機種・完成状態を残す。必要な項目だけ読み、実物の性能が未検証なら未検証と返す。

純銅とCuCrZr等の合金を区別し、熱/電気伝導、必要な強度、温度・環境から選ぶ。銅を含む金属風樹脂を、金属銅の導電/熱伝導値で設計しない。

反射・熱の逃げ方に合う機種/光源・パラメーター、粉末またはワイヤーの製品を確認する。赤外/緑/青の光源や波長の説明だけで、どの銅系も造形可能と判断しない。Meltioの[FAQ](https://meltio3d.com/faqs)にある開発途上の材料説明を量産用プロファイルへ読み替えない。

密度/気孔、酸化/汚染、熱処理で最終の伝導性と強度が変わる。[EOS CuCrZr資料](https://www.eos.info/metal-solutions/data-sheets/all-processes-and-materials?id=eos-copperalloy-cucrzr)は伝導性重視と強度重視の処理を区別する。両方の最大値が同時に得られると仮定しない。

流路・熱交換器は残粉除去と内部の検査、伝導/抵抗と接触面の仕上げを計画する。材料名や高密度の表示だけで気密・圧力保持を認定しない。[現行Markforged表](https://support.markforged.com/portal/s/article/Material-Compatibility-Matrix)ではCopperはMetal X対応・FX10非対応なので、同社の金属機間でも流用しない。
