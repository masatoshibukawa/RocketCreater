# TPU・TPEの柔軟材

製品・実機・根拠の確認は[材料条件](../3d-print-materials/references/material-contract.md)を使う。今回の用途と症状に必要な確認だけを選び、設定の差分・実測・未検証点を記録する。

TPU/TPEの製品名とShore硬度・尺度を確認する。AとDを同じ数字で比較しない。同じ95Aでも流量・送り・乾燥条件が共通とは限らない。

## 送りが詰まるとき

柔らかい材料は押し込み時に座屈・巻き付きし得る。スプール抵抗、チューブの曲がり、ギヤとノズル間の拘束、メーカー指定の押付け・リトラクションを確認する。速度だけ落として、巻き付いたまま再ロードを続けない。

Bowden構成でも製品と機種で可否が変わるため一律に禁止しない。直接給材でも、最も柔らかい材が使えると断定しない。普通のTPU95AはAMS liteの非対応材料として扱い、接続を進めない。[Bambu公式表](https://wiki.bambulab.com/en/general/filament-guide-material-table)のTPU非対応と専用対応製品を区別し、専用品もAMSとAMS liteそれぞれの可否を確認する。今回の一般的なTPUなら、許可された外部給材での単材試作を検討する。

## 造形と取り外し

吸湿と糸引きを先に切り分け、乾燥した同製品から低い体積流量の試験を始める。長いリトラクションや剛体用高速プロファイルを移さない。橋・支持の除去と、プレートへの過剰密着を小片で確認する。

柔軟さは材料の硬度と部品の肉厚・壁数・内部構造の両方で変わる。完成後の押し込み量/復元・保持、繰返し、使用温度で確かめる。TPUだから柔らかい密閉容器やシールとして合格とはしない。
