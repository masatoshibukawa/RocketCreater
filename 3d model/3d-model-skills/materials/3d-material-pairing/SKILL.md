# 複数材料・支持材・レジン混合の判断


最初に、同系材料の色替え、異種材料の接合、支持材の離型、レジン液の混合のどれかを決める。必要な部分だけ[組み合わせ表](../../../10_材料と組み合わせ/compatibility.md)と各材料スキルを読む。

## FDMの同時造形

1. 両製品の温度・ベッド・囲い・冷却条件が両立するか、[機械との適合](../3d-material-machine-match/SKILL.md)を確認する。ノズルごとに温度を変えられても、共通のベッドと庫内は一つ。
2. 接合部に必要な強度と、支持部に必要な剥がしやすさを区別する。PLA/PETGの支持への利用例は、荷重を受ける接合の証明にならない。必要なら分割造形・機械的なかみ合わせ等も比較する。
3. 単一ノズルでは色の抜けだけでなく異材残留による弱化を確認する。メーカーのパージ条件を起点に小試験し、固定のパージ量を全製品へ配らない。強度が必要な壁やインフィルへ支持材を流して節約しない。
4. 複数ノズル/ツールでは高さ・オフセット、待機温度、滴下・衝突、プライム塔の接地と異材間剥離を見る。色替えだけの成功を異材対応の根拠にしない。
5. 原寸の支持界面試験では支持が持つこと、除去できること、重要面の欠損・汚染を確認する。接合試験では荷重方向・層方向・反復・温湿度を用途に合わせて確認する。

XLのPLA/PETG支持と塔の対策は[Prusa公式](https://help.prusa3d.com/article/combining-materials-xl_498103)の機種・版の範囲で使う。S5では[PVA](https://support.ultimaker.com/s/article/1667337600656)はBBコア、[Breakaway](https://support.ultimaker.com/s/article/1667337600384)は対応0.4コアの条件を確認する。支持界面の距離0を、同材支持や全製品の既定値へ広げない。

## レジン液の混合

ブランド、世代、色、波長が近いだけでは混合レシピを作らない。メーカーが認める組み合わせ・比率の基準（質量/体積）・装置と後処理条件がある場合に限って、その範囲で扱う。記載がなければ別々に造形する案を返し、実験が目的なら未検証の試験計画として区別する。

[Siraya Tenacious 65D](https://siraya.tech/products/tenacious-resin-flexible-resin)には混合用途の説明、[Formlabs Color Kit](https://formlabs.com/support/Using-Color-Kit/)には専用の基材・顔料とレシピがある。これらは他製品同士の任意の50/50混合を認める資料ではない。Form 3/4等の世代も照合する。

承認された混合でも元の露光・洗浄・硬化・強度値を引き継がない。混合物を識別し、比率・ロット・設定・残液の扱いを記録する。異材を混ぜた液を未混合のボトルへ戻さない。

返すものは、目的に対する適合判定、両製品と機械条件、パージ/待機/支持の差分、比較試験と未検証点。実機運転なしで接合強度や支持除去成功を宣言しない。
