# 3Dプリント材料の置き換え


元の材料・設計・設定・試験結果と、変更する理由を[材料記録](../3d-print-materials/references/material-contract.md)へ残す。Tough PLA→PETG、PLA→LW-PLA、PA→PA-CF、標準→ABS-like等は、新しい製品条件として扱う。

## 変化を評価する

| 要件 | 確認と次の作業 |
| --- | --- |
| 形と接合 | 収縮・反り・象の足・吸湿/熱処理後の寸法を原寸の嵌合片で測る。別材料の収縮率をCAD全体へ即適用しない |
| 剛性と破壊 | ヤング率、破断伸び、衝撃、クリープ、XY/Z、使用温湿度を見る。同じ引張強さだけで同等としない |
| 薄いフィンや留め具 | 最小厚さと層方向、根元・角、繰返し、押し込み/保持を確認する。柔らかい材へ変えて厚さを据え置けるとは限らない |
| 熱と日射 | 用途の温度/荷重/時間に照合する。Tough/CF/高温の販売名やHDTだけで屋外長期・耐熱の合格を決めない |
| 質量と重心 | 新製品の密度と実際の壁・インフィル・空洞・支持残りを使って再見積し、完成後に実測する。発泡材は印刷条件で有効密度が変わる |

[Tough PLAの積層方向別TDS](https://um-support-files.ultimaker.com/materials/2.85mm/tds/TOUGH-PLA/UM220509-Tough-PLA-TDS-RB-v2.10.pdf)と[発泡PLAの校正例](https://support.colorfabb.com/hc/en-150/articles/360003022978-How-to-print-with-LW-PLA)のように、製品と製法に合う資料を優先する。TDSの数値は今回の形状を実証した値ではない。

## 再出力へ進む

[機械との適合](../3d-material-machine-match/SKILL.md)を確認し、新製品の公式プロファイルから再スライスする。流量・冷却・接地・支持・後処理に影響する差分を示し、必要な小試作から始める。CAD/STLが共通でも以前のG-codeや露光データを再利用しない。

ペットボトルロケットでは、部品の質量変化が全体の重心・安定性に影響する。旧試作のPLA密度仮定を新材料へ移さず、完成した部品・組立状態で質量と重心を確認する。印刷成功と強度・飛行確認は別の記録。材料の検討だけで加圧されるボトルや圧力保持部を設計変更しない。

設計が変わった場合は[モデル修正](../../categories/3d-model-preparation/SKILL.md)、後処理を含む実行は[印刷](../../categories/3d-model-printing/SKILL.md)へつなぐ。返すものは選定理由、元/新の製品、再検証が必要な項目と完了した範囲。
