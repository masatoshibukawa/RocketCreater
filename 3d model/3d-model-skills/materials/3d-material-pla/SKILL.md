# PLA

製品・実機・根拠の確認は[材料条件](../3d-print-materials/references/material-contract.md)を使う。今回の用途と症状に必要な確認だけを選び、設定の差分・実測・未検証点を記録する。

PLAは寸法確認・外観試作の出発点になるが、薄い爪・フィンの破壊や温まる場所での保持を、印刷の容易さから合格にしない。透明・マット・シルク・高速用等の改質品を、同一プロファイルの色違いとみなさない。

## この材料で調べる順番

1. 小さい接地はプレート商品と清掃、初層の本体・ブリムの実接続を確認する。高い薄いモデルは[接地と転倒](../../categories/3d-print-bed-stability/SKILL.md)も読む。材料がPLAだから細い縁だけで安定するとは限らない。
2. 閉じた高温環境で給材が不安定なら、ノズル温度を上げる前に機種指定の庫内条件とヒートクリープ、ファン・送り経路を確認する。
3. 先端の溶け・反りは最小層時間と冷却、垂れは橋と支持を確認する。全体を極端に遅くすると熱が集中する場合があるため、[速度・流量校正](../../categories/3d-print-speed-calibration/SKILL.md)で特徴別に扱う。
4. 脆い/層で割れる場合は保管状態、押出不足、層方向・根元形状を切り分ける。PLA+へ変える前に、同じ向きの原寸根元や嵌合片で原因を確認する。

用途の温度と荷重時間、衝撃を記録し、車内・日射等へは製品資料に合う確認を追加する。一般的な軟化温度を連続使用温度として採用しない。

根拠：[Prusa PLAガイド](https://help.prusa3d.com/article/pla_2062)、[UltiMaker 2.85mm PLAの機種/コア条件](https://support.ultimaker.com/s/article/1667337611872)。
