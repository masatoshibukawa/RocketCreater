# キャラクターのプラスチックフィギュア

追加調査日：2026-11-07。ポケモン等のキャラクターを、参照・AI/形状編集から、分割、印刷、配色/塗装、組立と完成確認へつなぐ。本文は日本語。英語・日本語・中国語の一次資料を照合した。

入口は[フィギュア制作スキル](../3d-model-skills/figurines/3d-character-figurines/SKILL.md)。今回の成果物は調査とスキルで、ポケモンのモデルを生成・印刷・塗装した実績ではない。

| 目的 | 読む資料 |
| --- | --- |
| 新たな機能と注意点を知る | [調査結果と版の制限](findings.md) |
| 顔・薄部・接合・配色の失敗から戻る | [工程別確認表](checks.md) |
| 原寸の部分試作を計画する | [試作例](trial-plan.md) |
| 条件と結果を保存する | [制作記録JSON](figurine-record.example.json)、[一次資料CSV](sources.csv) |
| スキルの確認範囲と残る制限を知る | [6ケースの評価記録](validation.md) |

既存の全体工程・材料・機種・接続スキルを必要な範囲だけ併用する。自動生成、メッシュ検査、スライス、実際の製作、表情/仕上げの合格は分けて記録する。特定の材料表の最小値や、別部品のブリム/速度をフィギュアの万能設定にしない。
