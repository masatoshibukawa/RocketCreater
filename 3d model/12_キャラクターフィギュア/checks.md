# 症状から確認する場所

| 症状 | 最初に切り分けること | 戻る工程 |
| --- | --- | --- |
| 色付き画像は似るが印刷すると顔が違う | 単色で目口の凹凸・位置と輪郭、テクスチャだけの表現を見る | 参照・形状 |
| 多視点で耳/尻尾が二重、背面が別物 | 同じ姿勢・尺度か、推定された追加視点かを確認 | 参照 |
| 自動修復後に顔/穴/模様が変わる | 修復の対象サイズ・薄壁補強・テクスチャ除去、元データとの差分 | 形状・配色 |
| 耳は印刷できたが支持除去で折れた | 根元、層方向、支持位置、除去力と材料、後処理の時点 | 分割・支持 |
| ダボが入らない/継ぎ目が閉じない | 縮小、直径差/片側隙間、深さ、変形、塗膜・接着剤の逃げ | 接合の原寸片 |
| 台座があるのに途中/完成後に倒れる | 印刷の接地と、完成品の質量配分・接触位置・がたつきを分ける | 接地/展示台座 |
| 自動分割で色が消えた | 元データ、対象版、テクスチャ保持設定と書出し形式を確認 | 配色・書出し |
| 顔の淡色が濁る/色境界が潰れる | フィラメント割当て、濃淡遷移のパージ、薄い外壁と内部色、微細な領域 | 多色プレビュー/試片 |
| 中空体が剥がれる/後で液が残る | 各空洞の吸盤・排液/洗浄/乾燥経路と最終スライスの穴 | 中空設計 |
| 塗装が剥がれる/目の溝が消える | 材料適合、表面汚れ/未硬化液、厚い下地、乾燥/再塗装条件 | 仕上げ試片 |

同じ症状でも機種/材料が違えば、温度・露光・速度・接点の値は引き継がない。完成した顔や細部の比較には同じ視点・照明・スケールの写真を使う。各確認の詳しい手順は[フィギュア索引](../3d-model-skills/figurines/3d-character-figurines/SKILL.md)から選ぶ。
