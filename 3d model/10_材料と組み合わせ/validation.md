# 材料スキルの確認記録

確認日：2026-11-07。対象は材料別16スキル、組み合わせ判断3スキル、材料索引1スキルと、その調査資料・既存索引への統合。

## ファイルと出典

- 既存分を含む全59個の`SKILL.md`をスキル用バリデーターで確認した。名前・frontmatter・未完成ひな型に問題はなかった。
- 各スキルのUIメタデータを解析し、説明長と、そのスキル名を明示する起動文を確認した。
- `3d model`内のMarkdownのローカル参照先を確認し、リンク切れはなかった。材料記録JSONも解析できた。
- 材料の出典CSVには34件の公式URLを記録した。英語・日本語・中国語・ドイツ語の確認範囲と参照先を保存し、すべての参照先ファイルの存在を確認した。翻訳・地域版は独立した実験と数えない。
- 今回の変更ファイルの名前・本文・リンク・UIメタデータ、追加コミットの本文とPRの記載を点検した。スキル形式に必要なUIメタデータのファイル名を保持し、不要な作業用表記や個人の絶対パスは含めていない。

## 独立した読み手による5例の確認

想定回答や修正案を先に渡さず、入口スキルと次の依頼で、必要なスキルの選択と回答を試した。原本・Git・実機の変更は許可せず、評価用の回答は提出対象外の一時出力へ保存した。

| 依頼 | 観察した判断 |
| --- | --- |
| S5/Tough PLA/AA0.4からPA-CF＋PVAへ変更 | 既存AAを複合材へ流用せず、PA-CFの正確な製品・径・耐摩耗構成と支持の適合を確認。PVAはBBを使う |
| A1 mini＋AMS lite＋普通のTPU95Aの多色 | 非対応を確認して外部給材の単材試作等へ振り分け。専用品を同じ95Aとはみなさない |
| PLA/PETGの支持と荷重接合 | 剥がしやすい支持と強い構造接合を別の目的・試験として扱う |
| 水洗い＋ABS-likeレジンを50/50混合 | 製品別承認と比率の基準がなければ不明とし、元の露光・水洗い・強度を引き継がない |
| PLAのロケットフィンをLW-PLAへ変更 | CAD原本は保持しつつ、発泡方式、壁厚・流量・実効密度、根元性能と組立重心を再評価 |

TPUの本文が非対応という判定を公式サイトの再閲覧へ委ねすぎる点を指摘された。機械照合スキル・TPUスキル・適合表の3箇所へ通常TPU95AのAMS lite非対応を明記し、専用AMS対応製品とAMS liteを分けた。ほかの4例では、この評価の範囲で危険な固定レシピや判断を妨げる不具合は見つからなかった。

修正後は同じ読み手が外部サイトを使わずに3資料を再読し、判定と外部給材の単材試作という代替案がローカル本文だけで一致して読めることを確認した。この範囲で残る不具合は見つからなかった。

評価側の閲覧環境では一部公式ページが402や表示エラーになり、別の同一メーカー資料で照合した。作成側では取得できた公式表の本文も確認している。これを恒久的なリンク切れや実機非対応と混同しない。

## 確認していないこと

この確認はスキルの構造・参照と、文章による判断例の評価。実際の材料乾燥・給材・プリント・混合・後処理、機械設定の変更、寸法・強度・耐熱・寿命・飛行の試験は行っていない。公式対応やスキルの検証を、実物の合格へ読み替えない。

利用時には[材料条件](../3d-model-skills/materials/3d-print-materials/references/material-contract.md)と[組み合わせ表](compatibility.md)を、対象の製品・機種・版へ照合する。
