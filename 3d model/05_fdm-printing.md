# FDM/FFF：材料準備からスライス、出力、仕上げまで

## 1. 材料を選ぶ

| 材料の候補 | 検討する用途 | 準備・設計で確認すること |
| --- | --- | --- |
| PLA | 室内の置物、形状確認、最初の試作 | 高温の場所や継続荷重で使えるかは製品TDSで確認 |
| PETG | 実用品、ケース、ある程度の靭性がほしい部品 | 糸引き、プレートへの強い接着、細部と支持除去 |
| ASA / ABS | 屋外や耐熱性を検討する部品 | 材料ごとの耐候性、反り、筐体、設置と換気の条件 |
| TPU等 | 柔らかい足、保護部品 | フィーダー適合、経路抵抗、吸湿、速度、硬さ |
| PA / PC等 | 条件を定めた機能部品 | 乾燥、筐体、温度、収縮、機械の対応範囲 |
| 繊維・粒子入り | 意匠や材料特性を狙う部品 | ノズルの耐摩耗性と径、目詰まり、方向依存、仕上げ |

同じ材料名でも配合により温度と特性が異なる。機種・メーカー・製品に合ったプロファイルとTDSを優先する。例えば「PLAだから屋外でも永久に持つ」「CF入りだから全方向で強い」とは判断しない。[S28: Prusa Filament Material Guide](https://help.prusa3d.com/filament-material-guide)

## 2. 造形前の準備

1. 実機の機種、造形範囲、装着ノズル径、プレート種を確認する。
2. ノズル周辺の付着物、プレートの汚れ、フィラメントのもつれと残量を見る。
3. 材料に吸湿の疑いがあれば、メーカーの温度・時間・スプール耐熱条件に従って乾燥する。
4. 乾燥後は密閉・乾燥保管し、必要なら乾燥環境から供給する。
5. メーカーの自己診断、ベッド調整、ノズル交換後の校正など、該当する手順を実施する。
6. 既知の小さなテストモデルで、基本的な押出しと初層が安定しているか見る。

湿った材料は表面荒れ、泡、押出しの不安定、層の結合不良等につながる場合がある。密閉箱と乾燥剤は再吸湿を抑えるものと、積極的に水分を抜く乾燥装置とで役割が異なる。乾燥温度は他社の同名材料やスプールへそのまま移さない。[S29: Drying filament](https://help.prusa3d.com/article/drying-filament_332086)

## 3. スライサーの基本設定

Bambu Studio、OrcaSlicer、PrusaSlicer、Cura等から、実機のプロファイルが適切に使えるものを選ぶ。インストール元はメーカーまたは開発元を確認する。今回細かい校正手順を確認したのは、OrcaSlicerの公式GitHub WikiとPrusa公式ナレッジベース。

最初は次の順で設定する。

| 順序 | 設定・作業 | 確認する目的 |
| --- | --- | --- |
| 1 | プリンターとノズル径 | 造形範囲、経路、開始・終了動作を一致させる |
| 2 | フィラメントとプレート | 温度、冷却、接着、最大流量の前提を揃える |
| 3 | モデル寸法と向き | サイズ、荷重、見せたい面、安定性を決める |
| 4 | 層高と線幅 | 必要な細部と時間を調整 |
| 5 | 壁と上下の厚み | 薄い壁、上面、底面を成立させる |
| 6 | インフィル | 上面の支持、剛性、重量、時間を調整 |
| 7 | 支持・brim・seam | 張り出し、接地、表面痕を管理 |
| 8 | スライスと全層プレビュー | 意図した形を経路として作れるか確認 |

他人の3MFプロジェクトを読み込んだ場合は、配置だけでなく機種・材料・ノズル等の設定まで変わっていないか確認する。作成済みG-codeは機械と構成に依存するため、自分のプロファイルで再スライスできる元データを入手する。

## 4. 初回の試作設定の例

以下は、標準0.4 mmノズルでPLAの小さな一体の置物を試すための提案。対応するメーカーの標準プロファイルを先に読み込み、そこで異なる設定が必要ならメーカー側を優先する。万能の推奨値や検証済みの実機プロファイルではない。

| 項目 | 試作の出発点の例 | 判断方法 |
| --- | --- | --- |
| 層高 | 0.20 mm | 曲面や顔の段差が目立てば必要箇所だけ細かくする |
| 外壁 | 3周程度 | 薄部と接続部が実際に何本の経路になるか見る |
| 上下面の総厚 | 各0.8〜1.0 mm程度 | 穴やたわみ、上面を支える内部を確認 |
| インフィル | 15%程度 | 上面と剛性が成立するかで調整 |
| 温度・速度・初層・冷却 | 実機と材料の標準プロファイル | 他の数値を変える前に初層と押出しの安定を確認 |
| 支持 | 自動生成を起点に必要箇所を編集 | 接触場所、取り外す道、先端と根元を確認 |

層高を0.20 mmから0.10 mmへ下げて上面層数を据え置くと、上面の厚みは半分になる。層数だけで設定を比較しない。強度を上げたい場合も、まず外壁と形状を検討する。[S15: Infill](https://help.prusa3d.com/de/article/infill_42)

## 5. 支持、接地、seamを整える

有機的なモデルでは樹状・Organic支持を候補にする。小さな先端だけに接触させると外しやすいが、枝が細すぎると途中で不安定になる。広い平らな下面では、別の支持形状や支持インターフェースが適切な場合もある。

自動支持後に、顔、刻印、嵌合面、薄い指へ触れていないかを確認する。見せたくない面へ支持痕とseamを逃がす。支持が内部に閉じ込められ、工具も入らないなら分割を検討する。支持密度をむやみに増やす前に、向きと接触配置を直す。[S39: Organic Supports](https://help.prusa3d.com/article/organic-supports_480131)

細い足や背の高いモデルではbrim等で接地を補えるか検討する。brimを追加した場合は、除去後の底面や嵌合への影響も見る。モデルの足がベッドに付いていても、その横にある支持の初層が小さすぎないか確認する。

## 6. スライス後は経路を見る

最低限、最初の数層、底が閉じる層、細い接続、目や文字、支持から本体へ移る層、上面が閉じる層を見る。さらに層スライダーで全高を通して確認する。

- 消えた壁、浮いた経路、空中から始まる部位がないか。
- 細い突起が一本の経路だけになっていないか。
- 重要な穴が埋まる、底が開く、閉じた空洞ができる等の変化がないか。
- 外壁・インフィル・支持・移動の色分けが想定どおりか。
- 速度と体積流量の表示に、不意に大きな値がないか。
- 造形時間、使用量、残量、プレート外周との距離に無理がないか。

体積流量の概算は`Q ≈ 線幅(mm) × 層高(mm) × 速度(mm/s)`。0.45 × 0.20 × 100なら約9 mm³/sになる。実際の断面形状による差はあるが、速度だけでは必要な押出し量を判断できないことが分かる。許容流量はホットエンド・材料・温度・設定で変わる。

## 7. 問題があるときの校正

標準プロファイルで安定しているなら、毎回すべての校正をやり直す必要はない。新しい材料や問題がある場合に、症状に必要な試験を行う。

今回確認したOrcaSlicerの公式Calibration Guideでは、材料の温度→最大体積流量→Pressure Advance→Flow Ratio→Retractionの順を示し、公差確認を最後にしている。PAと流量は相互に少し影響するため、流量の修正が大きい場合はPAを再確認する説明もある。手元の自動校正やメーカーの検証済み手順があれば、そちらの適用範囲を確認する。[S27: OrcaSlicer Calibration Guide](https://github.com/OrcaSlicer/OrcaSlicer/wiki/calibration_guide)

| 症状 | 優先する確認 |
| --- | --- |
| 材料が安定して溶けない、層の結合が弱い | 乾燥、温度、流量上限、冷却、機械状態 |
| 高速部分だけ痩せる | 体積流量と温度。単に押出し倍率を増やさない |
| 角が膨らむ、線の終端が乱れる | PAと速度・加速度、機種の対応 |
| 上面が過剰に盛り上がる、均一に隙間が出る | Flow Ratio、ノズル・フィラメント状態 |
| 糸が出る | 吸湿、温度、移動、最後に必要なリトラクション調整 |

試験モデルや開始コードに特有の設定を使ったら、通常のプロジェクトへ戻してから本番モデルをスライスし直す。いくつもの値を同時に変えず、変更した値と結果を記録する。

## 8. 実機で出力する

1. 書出しファイル名と、今回のモデル・機種・材料を確認する。
2. プレートと材料を準備し、必要なメーカーの校正を行う。
3. パージ、最初の輪郭、支持の初層を確認する。
4. 線が丸く浮いて付かない、強く押しつぶされる、ノズルが引きずるなどの異常があれば止めて原因を直す。
5. 初層だけでなく、最初の細い支持や大きな橋など、モデル固有の難所でも確認する。
6. 完了後は、プレートと材料に指定された取り外し方で冷却・取り外しを行う。

スペイン語のPrusa初層資料は、表面の種類に合わせた清掃と、ノズルが近すぎる／遠すぎる場合の症状を説明している。記載される旧機種のLive Z値を、荷重センサー等で自動調整する機種へコピーしない。[S19: Problemas en la primera capa](https://help.prusa3d.com/es/article/problemas-en-la-primera-capa_1804)

## 9. 後処理と検収

支持は薄い指や突起を引っ張らず、必要なら小さく切り分けて外す。目を保護し、刃を体や指へ向けない。外観を整える研磨では粉じんを管理し、嵌合部を削り過ぎないようにする。塗装や接着は使用材料に適合する製品の手順に従う。

完成後に外寸、穴、接続、底面の平らさ、支持痕、機能を確認する。外観の合格と部品としての合格を別々に記録し、材料ロット、プロファイル、向き、変更点、写真を保存する。
