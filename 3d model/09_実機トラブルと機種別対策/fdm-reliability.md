# 接地不足と速度に起因する失敗を減らす

調査日：2026-11-06。メーカー・公式スライサーの説明と、今回の実機失敗記録を分けて整理する。ここにある試行案は、全機種で成功する設定ではない。

## 今回、実物で起きたこと

[保存した試行記録](../../assets/print-trials/2026-11-06-fin-retry02/README.md)はUltiMaker S5／Tough PLA Gray／AA 0.4のフィン。初層は密着し、速度を抑えて再開したが、利用者は終盤の転倒を報告した。完了表示と造形成功は別だった。元の外側ブリムは7 mm。汚れ、反り、衝突、揺れ、接地不足のどれが支配的だったかは確定していない。

別工程の[次回案](../../docs/printable-design-exports.md)では、ブリム20～35 mm・隙間0、押出経路の指令送り速度35 mm/s以下、形状に応じた向きと重心投影の確認を採用した。これは**そのS5フィンの未検証の再試行条件**である。メーカー標準でも、別機種の万能値でもない。今回の調査で再印刷は行っていない。

## 1. 「土台」を区別する

| 意味 | 調べること | 対応 |
| --- | --- | --- |
| 製品本来の基体 | CADの実寸・機能・取付寸法 | 意図した寸法を保って設計し直す |
| モデルの接地面 | 初層の材料領域・つながり・細い方向 | 向き変更、分割、除去可能な足／タブを比較 |
| ブリム | 本体への実際の接続、幅、隙間、方向 | 増幅しても本体から離れていれば保持に寄与しない |
| ラフト | ラフト自体の接着、本体との界面 | 下面精度・除去・時間の変化も評価 |
| サポートの根元 | 支持の接地、本体との接点、途中の枝 | 枝と根元の両方、支持の速度・冷却を確認 |

スカートは通常、本体から離れた線であり、ブリムと同じ保持効果を前提にしない。Prusaは小さい底面の高い物体にブリムを検討し、幅と分離隙間を別の設定として説明する。[Prusa：Skirt and Brim](https://help.prusa3d.com/article/skirt-and-brim_133969)

## 2. 接地の確認を面積の数字だけで終えない

スライサーの初層を上面から拡大し、実際に押し出される領域を調べる。モデルの外接長方形、CADのZ=0断面、ブリムを含む領域はそれぞれ異なる。パージ線を本体の支持面に数えない。

- 本体の細い接地が連続し、ブリム／除去用土台へ実際につながるか。点や短線だけの接触ではないか。
- 分離隙間、象の足補正、初層線幅によって、意図した接続が消えていないか。
- 検討する重心はどの高さの時点か。固体CAD重心と、インフィル・支持を含む造形中の重心は同じではない。
- 重心投影が接地領域の凸包内でも、穴をまたぐ凸包や離れた島だけでは保持を保証できない。接続と狭い方向の幅も確認する。
- ベッドが前後に動く機種では、モデルに作用する慣性力も考える。高さが増すほど揺れと接触の影響を確認する。CoreXYも反り・ノズル衝突には別対策が必要。

これらは設計上のスクリーニングで、接着強度の実測ではない。姿勢を変えたら、層方向の強度、穴、支持痕、ブリム除去、ベッド内への収まりも再確認する。

## 3. 速度を一つの数値として扱わない

| 設定 | 主な確認点 |
| --- | --- |
| 初層の押出し・移動 | 線や小島を引きずらないか。初層だけの低速で終盤まで保証しない |
| ブリム・支持 | 本体の速度設定と別の上書きがないか |
| 外壁・内壁・充填・上下面 | 一般のPrint Speedを下げても、個別値が高速のままになっていないか |
| 橋・張り出し・細部 | 局所的な速度とファン、短い層の冷却待ち |
| 加速度・方向転換 | 薄く高い部品が揺れるか。速度だけ下げても急な反転が残らないか |
| 本体の速度倍率 | 通常／静音／高速モード等による上書きを記録 |

スライス後の速度・流量表示で難所を確認する。必要なら機種対応の検査器で、G-code中の押出経路の指令送り速度を調べる。一般的なmmモードの`F`はmm/minなのでmm/sには60で割るが、座標・押出しモードや本体の倍率を扱えない簡易読み取りで実測速度を主張しない。加速度制限下の実運動は指令値とも異なる。[UltiMaker Cura：Speed settings](https://support.ultimaker.com/s/article/1667411313568)

## 4. 流量と冷却を合わせて見る

おおまかな流量は`Q ≈ 線幅 × 層高 × 速度`（mm³/s）。0.45 mm × 0.20 mm × 35 mm/sなら約3.15 mm³/sである。ビード形状を単純化した計算例で、35 mm/sを推奨する意味はない。ノズル・層高・線幅を変えたら同じ速度でも必要流量は変わる。

実際の上限は材料製品・色、温度、ホットエンド、ノズルで変わる。押出し倍率、PA／フローダイナミクス、最大体積流量を混同しない。高速部分だけ痩せる場合に、倍率だけを増やして隠さない。[Prusa：Max volumetric speed](https://help.prusa3d.com/article/max-volumetric-speed_127176)、[OrcaSlicer開発元：最大流量校正](https://github.com/OrcaSlicer/OrcaSlicer/wiki/volumetric-speed-calib)

先端など短い層は十分に冷える前に次層へ進む。最小層時間と最低印刷速度の両方を見る。最低速度の下限が高いと層時間を確保できず、極端に遅くすれば熱だまりが解消するとも限らない。初層の接着と上部の細部では必要な冷却が異なる。[Prusa：Cooling](https://help.prusa3d.com/article/cooling_127569)

## 5. 途中で倒れた場合の切り分け

| 観察 | 確認する候補 | 次の比較試行 |
| --- | --- | --- |
| 最初から線が離れる | 表面、材料／プレート選択、初層、ノズル付着 | 清掃と該当機種の校正後に同じ位置の初層 |
| 角が徐々に上がる | 冷却収縮、風、プレート、接地 | 冷却条件または接地の一方を変えて比較 |
| 底は付いたまま上部が揺れる | 薄い断面、加速度、向き | 同じ高さを保って加速度または方向を比較 |
| 接触音の後に倒れる | 反った上面、過剰押出し、充填交差、移動 | 接触した経路を特定。根因を直し、Z-hopだけで隠さない |
| 高速部だけ欠ける・押出しが途切れる | 流量、材料供給、温度、詰まり | その特徴の速度／流量を抑えて比較 |
| 上部が軟らかく変形する | 短い層、冷却、熱だまり | 最小層時間とファンの適用を確認 |
| ブリムだけ残る | ブリム接続、本体の細い根元、破断 | 接続と破断面を確認。幅だけ増やさない |

ガラス、PEI等の洗剤・溶剤・接着剤は表面と材料に合わせる。UltiMakerのガラス向け薄い接着剤の説明を、別のPEI表面へ無条件に移さない。[UltiMaker：接着不良の対処](https://support.ultimaker.com/s/article/1662338049466)

## 6. 失敗を短い試作で減らす手順

1. 既知の良好な機種・ノズル・材料・プレート用プロファイルを基準にする。今回の目的に合わないFastや高速倍率を既定にしない。
2. 初層と最初の数層を小試験で確認する。原寸の接触域と線幅を維持する。
3. 終盤の転倒を調べる試験は、元の高さ・薄さ・向きに近い1個で行う。低く切った試験が成功しても、全高の成功にはしない。
4. 接地、速度・加速度、冷却、押出しのうち、観察に対応する仮説を一つ選ぶ。複数を変える緊急の再試行なら原因を分離できないと記録する。
5. 初層、最初の難所、失敗していた高さ、終盤、取り外し後を観察する。`Finished`だけで合格にしない。
6. 観察・計測が合格した構成を基準として保存する。別機種・材料・個数・配置に変えたら該当条件を再確認する。

モデル版／ハッシュ、機種・ソフト・版、材料・径、ノズル・プレート、向き、接地とブリム、特徴別速度、加速度、最大流量、冷却、変更した一項目、失敗層／時刻、実物の結果を残す。未測定を0や合格で埋めない。
