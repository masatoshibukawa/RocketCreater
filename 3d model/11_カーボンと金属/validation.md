確認日：2026-11-07。追加範囲は方式6スキルと索引、代表12機器のスキル、金属6合金系のスキル、PET/PPSの2材料スキル。材料索引と既存の短繊維入り材料からつないだ。

## 構造・参照・出典

既存分を含む全86個の`SKILL.md`を付属のスキル用バリデーターで確認し、名前・frontmatterと未完成ひな型を点検した。UIメタデータは解析し、説明長と、スキル名を明示する起動文を確認した。Markdownのローカル参照先517件と工程記録JSONも検証した。

追加カテゴリーの出典CSVは42件の公式メーカー・公的研究機関のURLについて、英語・日本語・ドイツ語の確認範囲と利用先を記録する。機器の現行紹介、旧版資料、発表記事、供給終了表示、開発段階のパラメーターを区別した。地域サイトの英文をその地域の言語で確認したものとは数えない。

変更ファイルの名前・本文・リンク・メタデータと追加コミット・PRの記載を点検した。スキル形式に必要なメタデータのファイル名と正当なメーカー・商標・出典を保持し、不要な作業用表記や個人の絶対パスは含めていない。

## 独立した読み手の6例

想定回答を渡さず、入口と依頼だけで必要な資料を選び、外部サイトを使わず回答を作った。原本・Git・実機・設備設定・購入は許可せず、一時出力だけを保存した。

| 依頼 | 観察した判断 |
| --- | --- |
| S5のコア交換でPPS CF/PET CFのフィン | 耐摩耗化と熱環境/材料対応を区別。PPS CFをS5へ流用せず、PET CFは製品とコアを照合 |
| FX10で金属とカーボンを混在、Copper/H13 v1/316Lを所有 | 構成切替と同一部品の任意混在を区別。機種と製品世代で割当てを分ける |
| ブロンズPLA/古いUltrafuse在庫から実金属へ | 装飾樹脂・グリーン品・最終金属を分け、現行の脱脂/焼結受入を確認 |
| M 290のアルミ部品へ6061の物性と焼結FFFの20%拡大 | 合金/製法の性能を継承せず、LPBFに焼結用倍率を適用しない |
| Mark Twoの細く急に曲がるフィン根元 | 実際の配置可能幅・曲率・層と経路を確認し、アルミ並みという比較だけで合格にしない |
| M600でAl/Ti切替、加工なしの大型部品 | 多線材機能と健全な異材接合を分け、パラメーター成熟度・加工代・完成公差を評価 |

初回の読み取りでは、PET/PPSの基材スキルへの経路が欠け、S5 PET CFのコア径とH13 v1の機種別判定が外部資料なしでは確定しにくいと指摘された。PET/PPSスキルを新設して索引と繊維入りから接続し、S5用CC0.4/0.6と、Metal X/FX10の製品世代別対応をローカル本文へ追加した。

修正後に同じ読み手が外部閲覧をせず対象を再読し、PET/PPSへの実際のリンク到達、S5の製品/コア条件、H13 v1の割当てを明確に判断できることを確認した。再読した範囲で新しい矛盾や回答を妨げる不具合は見つからなかった。

この6例で危険な固定レシピや、未確認の設備へ無条件に実行を進める指示は見つからなかった。Mark Twoの具体的な経路制約、M600の対象ワイヤーとパラメーター、古い材料の受入可否など、実機/製品未特定の項目は不明のまま残す。

## 確認の限界

構造と参照、文章による判断例の確認であり、材料試験や装置の操作検証ではない。新しい印刷、繊維配置の実スライス、金属粉末取り扱い、脱脂・焼結・熱処理、機械加工、寸法・密度・強度・疲労・耐食・伝導・飛行の試験は行っていない。価格・在庫・地域の保守・現行サービス受入も見積/契約で別途確認する。

実行前は[機器・材料表](equipment-and-materials.md)と[施設・品質の条件](facility-and-quality.md)を対象構成へ照合し、[工程記録](industrial-record.example.json)へ完成状態と未確認点を残す。
