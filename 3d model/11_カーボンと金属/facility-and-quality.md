# 施設・設計・後処理・品質の条件

## 最初に揃える記録

[記録JSON](industrial-record.example.json)を必要な方式だけ使う。材料メーカーと製品/世代・ロット、供給形態（樹脂フィラメント/連続繊維/結合材入り金属/粉末/ワイヤー）、機種と構成、ソフトとパラメーターID、後処理先、完成状態を記録する。一般の[材料条件](../3d-model-skills/materials/3d-print-materials/references/material-contract.md)へ追加する項目。

| 判断 | 確認内容 |
| --- | --- |
| 材料適合 | 正確な合金/樹脂・規格と供給形態、径/粒度、酸素等の管理、同一製品でも世代別の対応、再使用履歴 |
| 設計 | 最終寸法と公差、荷重/寿命、繊維方向、熱と支持、排液/粉抜き、収縮、セッター、加工代と基準 |
| 施設 | 本体と補助機の電源・荷重/搬入・排熱、給排気、ガス/真空/冷却、対象粉末・溶剤に合う作業区域と回収設備 |
| 検査 | 試験片の方向/位置、完成寸法・変形・質量、密度/内部欠陥、成分・硬度、必要な引張/疲労/耐食/伝導性、判定者と許容値 |
| 引き渡し | 生材/グリーン/ブラウン/焼結/熱処理/加工/検査の状態、処理履歴、残る制限と証明書 |

## 材料の扱いは供給形態で変わる

連続繊維・CF樹脂は乾燥と摩耗、切断/研磨時の粉じんを製品SDSへ照合する。金属結合材方式はばら粉末を減らせても、溶剤・脱脂排ガス・高温炉の設備要件は残る。金属粉末では投入/回収/ふるい/清掃/フィルター交換等も工程として評価する。

粉末の反応性・可燃性と吸入/皮膚ばく露は、合金、粒度、状態、作業で異なる。密閉/局所排気等の工学的対策を先に設計し、SDS・メーカー手順と施設管理者が指定する保護具を使う。家庭用掃除機・圧縮空気・任意の消火/洗浄方法を代用手順として配布しない。ガスは酸素濃度と供給/排出・漏れ対応も設備条件へ含める。

根拠：[NIOSHの金属粉末AMの確認項目](https://www.cdc.gov/niosh/docs/2020-114/pdfs/2020-114.pdf?id=10.26616%2FNIOSHPUB2020114)、[2025年の実施設ばく露評価](https://stacks.cdc.gov/view/cdc/232219/cdc_232219_DS1.pdf)、[NISTの施設構築事例](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=913441)。これらは施設と作業に応じた対策を組む根拠で、米国の特定施設の保護具・法令やガス選択を日本の全設備へ一律に移すものではない。

## 材料表を読むとき

鋳造/鍛造材とAM試験片、造形方向、as-built/as-sintered、熱処理/時効、HIP、表面加工の有無を分ける。密度が高いという一つの値から疲労・気密・耐食を認定しない。機種・材料・パラメーター・後処理と用途が一致する資料を選ぶ。

金属でも支持接続、気孔、内部残粉、表面の切欠きや熱処理による変形が生じ得る。用途で必要な確認を小試験と最終部品に分け、合格条件を出力前に書く。危険な荷重/圧力/飛行の用途は、材料名やカタログ値だけで使用可能としない。

外注ならCAD/メッシュ・最終寸法・許容差・重要面・指定材と代替可否・完成状態・必要な検査/証明・個数を渡し、業者側の設計レビューと受入条件を確認する。機械用データや稼働条件は、実設備と担当者の確認前に確定しない。
