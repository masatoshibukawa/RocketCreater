全件がベッド内、途中欠層0、支持材経路0。初層以降で前層と全く重ならない連続押出経路は、サンプリング検査では0だった。検査は0.4 mm以下の間隔で推定ビード半幅の和＋0.08 mmの範囲を調べる。微細な浮島や垂れを完全に証明する検査ではなく、接地・冷却・反り・層間強度は実機確認が必要である。

## 残る具体的な確認点

- **フィン**：局所的な前層非重複サンプル比率は最大1.701%（0始まり273層、Z54.8 mm）。根元立上りと穴上縁に集中する。第3層Z0.8 mmで非重複経路長6.237 mm、非重複80%超の単一線分は最長1.006 mm。穴2個は経路上で開いている。根元ウェブは20%インフィルの空隙を含み、締結・曲げ・衝撃強度は未検証。
- **コーン**：頂部まで環状壁が続き、開口を塞ぐ表皮・橋はない。最終層のビード内縁による開口推定は約16.50 mm。設計16 mmとの差は層の離散化等によるので、キャップは印刷後の実寸に合わせる。法線肉厚1.6 mm、入口縁1.2 mmは経路に残る。
- **リング**：最終層の推定内径110.79 mm。設計110.8 mmに近いが、真円度・ラベル・実径は別途確認する。外側ブリムは内径を埋めていない。初層の広がりで嵌合が変わる点は[Prusaの象の足補正資料](https://help.prusa3d.com/article/elephant-foot-compensation_114487)も参照する。
- **サドルゲージ**：宣言102層のうち最後の101番にはモデル経路がない。上端の細い部分が線幅未満となり、実経路はZ20.2 mm、STL高さ20.310625 mmから約0.111 mm短くなる。途中欠層ではない。接触用の円弧端にバリや欠けがないか実物で確認する。

## 再現

リポジトリのルートで実行する。Pythonは標準ライブラリのみを使う。CuraEngineとその同梱定義が必要。`--out`は検証結果の出力先で、同名ファイルを上書きする。

```powershell
python "3d model/prototypes/pet-rocket-coke-2l/slice_check.py" --engine "$env:ProgramFiles/UltiMaker Cura 5.12.0/CuraEngine.exe" --out "output/pet-rocket-slice-check"
```

[slice_check.py](../../slice_check.py)は測定JSON、経路SVG、ログを出力し、正常終了時に一時G-codeを削除する。実機送信用G-codeは収録していない。エンジン・定義・入力STL・解析器のハッシュを記録する。今回の出力にはCura CLIのTIME=6666／Filament used=0mの仮値があるため、これらを時間・材料量の見積りに使っていない。
