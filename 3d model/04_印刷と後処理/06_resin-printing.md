# 光造形：向き、支持、中空化、出力、洗浄・硬化

[全体の目次へ](../README.md)

## 1. 機種とレジンの組合せを固定する

[材料別スキル](../3d-model-skills/materials/3d-print-materials/SKILL.md)から標準・工学用・水洗いの条件を選ぶ。混合を考える場合は[複数材料の判断](../3d-model-skills/materials/3d-material-pairing/SKILL.md)を使い、単品の露光・洗浄・硬化を混合後へ引き継がない。

SLA、MSLA、DLPはいずれも光でレジンを硬化するが、光学系、剥離動作、出力ファイル、露光制御が異なる。別機種の「標準露光2秒」等の値を移すより、対象機種とレジンに対応するプロファイルを起点にする。

記録する条件は、機種・ファームウェア、スライサー版、レジン製品・色・ロット、層高、室温または指定されたレジン温度、通常層・底層、剥離・待機等の設定。メーカーが内部管理する値は、対応するプロファイル名を保存する。

## 2. 作業場所と道具を準備する

造形、洗浄、乾燥、硬化、支持除去、完成品を置く位置を先に決める。未洗浄のものを扱う場所と、洗浄後のものを置く場所を分ける。必要な容器、トレイ、吸収材、洗浄液、手袋、保護眼鏡、廃液用容器を用意する。

レジンと洗浄剤のSDSを読み、適合する耐薬品手袋、目の保護、換気・保管・廃棄方法を確認する。Formlabsの資料はニトリル／ネオプレン手袋、後処理時の眼の保護、空気が循環する作業場所を説明しているが、その製品向け説明を全メーカーのレジンへ一般化しない。[S25: Safety with Formlabs SLA products](https://formlabs.com/support/Safety-Formlabs-SLA-printers/)

## 3. 向きは複数の条件で決める

1. 正面、顔、刻印、接合面など、支持痕を避けたい面を決める。
2. 層スライダーで、最初に現れる箇所と、そこから成長する順番を見る。
3. 大きな平面が一度に現れる向きを避けられるか検討する。
4. 支持のない孤立領域（island）をなくす。
5. 空洞が剥離面に対して吸盤のように閉じる箇所を探す。
6. 最大高さ、断面の変化、支持痕、排液を比較して採用する。

よく使われる傾斜角は目安であり、すべてを45°にすれば成功するわけではない。薄い板、胸像、穴のある部品では適切な向きが違う。Prusaの光造形向け説明も、断面とislandを減らす向きを重視している。[S20: オブジェクトの方向](https://help.prusa3d.com/ja/article/オブジェクトの方向_1658)

MSLA/DLP等の一層をまとめて硬化する方式では、同じ高さの部品を並べると有利な場合があるが、実時間は剥離、待機、材料供給、断面にも左右される。単純に「同時に何個置いても時間・成功率は同じ」とは扱わない。

## 4. 支持を作る

自動支持を生成してから、最初に現れる点、重い部分の下、長い張り出し、薄い端を重点的に見る。最初の支持は、後の造形を支える土台になる。先端が小さければ痕は減らせるが、保持力との調整が必要になる。

| 見る箇所 | 確認すること |
| --- | --- |
| 最初に現れる領域 | 支持が実際につながり、十分に保持できるか |
| 大断面の直前 | 剥離力と重量に対して支持が偏っていないか |
| 手、耳、髪、縁 | 空中から始まる小領域を取りこぼしていないか |
| 支持の枝 | 本体や隣の支持に不用意に干渉していないか |
| 内側 | 取り外せない支持を閉じ込めないか |
| 化粧面と接合面 | 痕を許せる位置か、仕上げで寸法が変わらないか |

支持が外れて落ちたときは、支持数だけを増やす前に向き、断面、重量、露光、空洞を調べる。必要なら本体を分割する。形状を変更したら支持とスライスを作り直す。

## 5. 中空化は排液・通気・洗浄まで設計する

光造形はFDMのインフィル率を下げるのと同じ方法では中空にならない。内側の殻を作り、空洞の液体が出入りできる経路を用意する。小さな部品では、中空化による管理の手間が材料節約を上回ることもある。

フランス語のPrusa公式解説は、少なくとも二つの排液穴と断面プレビューを勧めている。ただし、穴の個数だけでは十分ではない。複数の独立した空洞があるなら、それぞれが排液・通気できるか確認する。[S17: Évidement](https://help.prusa3d.com/fr/article/evidement_117285)

1. 中空化前に、不要な内部面や独立した殻を修正する。
2. 外壁と内壁の断面を見て、最も薄い場所、指や耳のような細い箇所を確認する。
3. 印刷中、最初に閉じた空洞が現れる層を見る。吸盤状に閉じる前に圧力を逃がせる経路があるか確認する。
4. 排液時に液体が溜まる低い場所と、空気が入る経路を用意する。
5. 洗浄液が入り、内部のレジンを洗い出し、再び十分に排出できるか考える。
6. 内部の洗浄・乾燥・必要な硬化ができないなら、開口を大きくするか、開いた部品へ分割する。
7. 穴と空洞を含む書出し結果を再読込し、スライスの層画像で確認する。

メーカーの最小排液穴は、実際の大きな中空像に十分な清掃口の大きさとは限らない。Formlabsの最小形状値も機種・レジン・層高付きのものなので、そのまま他機種へ使わない。[S32: Form 4 design specifications](https://formlabs.com/support/Design-specifications-for-3D-models-Form-4-generation/)

## 6. 露光を確認する試作

対応プロファイルで既知の小さな校正モデルを出力する。機種・レジンに合った試験方法を使い、通常層の細部・穴・接合と、底層のプレートへの接着を別々に見る。レジンの攪拌、温度、層高、剥離フィルム等の条件を揃えて比較する。

通常露光を変えると、細い突起と穴の開き方の両方が変わり得る。片方の見た目だけで決めず、指定の後処理後に細部と寸法を確認する。底層の露光を上げて本体の支持不足まで解決しようとしない。

同じレジンでも色・ロット、経年、温度、装置の状態が違えば再確認する理由になる。一度の設定探索で多くの変数を一緒に変えず、採用条件の再現性を見る。

## 7. 出力時の流れ

1. タンク、フィルム、ビルドプラットフォームに異物や損傷がないか、機種の手順で点検する。
2. 材料の攪拌、温度、残量を指定どおりにする。露光系や機構へレジンをこぼさない配置にする。
3. 正しい機種・材料・層高のファイルを転送し、名前とプレビューを確認する。
4. カバーを閉じ、メーカーの運用方法で開始する。
5. 造形の脱落などで失敗したら、再開前にタンク内の硬化片を機種の手順で除去する。異物を残したまま次の動作を始めない。
6. 完了後は、材料が滴下する場所を管理しながら取り外す。

## 8. 洗浄、乾燥、硬化、支持除去

| 工程 | やること | 避けたい失敗 |
| --- | --- | --- |
| 洗浄 | 指定された液・時間・攪拌で、表面と必要な内部を洗う | 長く浸しすぎる、飽和した汚い洗浄液で仕上げる |
| 乾燥 | 表面だけでなく開口・空洞の液を排出して十分に乾燥 | 液が残る状態で硬化や接着へ進む |
| 二次硬化 | 材料と装置に指定された波長・時間・温度・配置 | 全レジンへ同じ時間を使う、光が当たらない内部を放置 |
| 支持除去 | 指定された順序で保持しながら切り分ける | 細部を引きちぎる、接合面を大きく欠けさせる |
| 仕上げ | 必要に応じて研磨、充填、塗装、仮組立 | 未硬化レジンを残したまま塗装・封止する |

二次硬化の必要性と条件は製品で違う。支持除去も「常に硬化前」「常に硬化後」とは決めない。今回確認したFormlabsの基本手順では、変形を避けるため硬化後の支持除去を推奨している。別材料・別機種へはそのまま移さず、材料の手順を優先する。[S21: SLA basic finishing](https://formlabs.com/jp/support/SLA-basic-finishing/)

韓国語のFormlabs資料でも、造形後の洗浄と硬化を独立した工程として説明している。ページに示す短い処理時間は、全機種・全レジンの万能な時間ではない。[S23: モデルと小物の工程](https://formlabs.com/kr/applications/models-and-props/)、[S24: 洗浄・硬化](https://formlabs.com/kr/post-processing/wash-cure/)

## 9. 完成判定と廃液管理

外観、表面の残留、反り、欠損、穴、嵌合を、指定の後処理後に確認する。ベタつきは単にUV照射を長くする前に、洗浄液の汚れ、乾燥、材料指定、硬化条件を確認する。接合する前に空洞と開口を確認し、完成寸法を記録する。[S36: SLA寸法精度](https://formlabs.com/jp/support/Dimensional-inaccuracy-SLA/)

未硬化レジンやレジンを含む洗浄液を排水へ流さない。「水洗いレジン」の洗浄水も、汚染された液体として扱い、SDSと地域の収集・処理方法を確認する。メーカーの他国向け家庭ごみの記述だけで、日本の自治体での処理可否を判断しない。[S37: Disposing of resin](https://formlabs.com/support/Disposing-of-resin/)
