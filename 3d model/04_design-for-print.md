# 印刷を前提とした設計：肉厚、公差、方向、分割

## 1. 最終サイズを先に固定する

一様な縮小率を`s`とすると、長さ・壁厚・隙間は`s`倍、面積は`s²`倍、体積は`s³`倍になる。80 mmの人形を40 mmへ縮小すると、2 mmの手首は1 mmになり、0.4 mmの溝は0.2 mmになる。形の比率が保たれても、同じ方式で同じように印刷できるとは限らない。

寸法合わせが必要な部分だけを試すときは、その部分を原寸で切り出す。全体を縮小した試作は、シルエットの確認には使えるが、元の公差や肉厚の検証を代替しない。

## 2. 壁厚と細い突起は別々に検討する

壁は面として支えられるが、指、角、髪、ピンは細い梁のように曲げや支持除去の力を受ける。同じ厚さでも壊れやすさが違う。最小造形値で出せることと、取り扱えることを分ける。

| 対象 | 最初に見るもの | 改善方法 |
| --- | --- | --- |
| FDMの縦壁 | 押出し線が何本入るか | 壁厚と実際の線幅を対応させ、プレビューで確認 |
| 上下面 | 総厚みと、その下の支持 | 上下面の層数だけでなくmm換算で判断 |
| 指・角・髪 | 最小径、長さ、根元 | 太く短くする、根元を丸める、本体へ接続 |
| 広い薄板 | 反り、たわみ、支持 | リブ、厚み、分割、向きを変更 |
| 中空の光造形 | 殻の最小厚、空洞の接続、排液 | 断面で内壁を確認し、洗える構造へ変更 |
| 文字・彫刻 | 線幅、深さ、向き | 図案を単純化し、実寸の試験片を出す |

試作の例として、0.4 mmノズル・実線幅0.45 mmのFDMで、3本程度の壁を考えるなら厚み1.35 mm前後が計算の出発点になる。ただし可変線幅や重なりにより単純な積と一致しないので、成立は経路で確認する。実用部品や台座では、さらに厚み・外壁・補強を設けるかを荷重と試験で決める。

Meshyの総合ガイドはFDM 1.2 mm、SLA/DLP 0.5 mm等を案内する。一方、Formlabsの特定条件では0.2 mmの壁の例がある。後者はForm 4・Grey Resin V5・50 µm等の条件付きで、一般的な家庭用レジン機の耐久壁厚を示してはいない。薄壁の値だけを抜き出して使わない。[S01: Meshy印刷設計](https://docs.meshy.ai/en/webapp/guides/use-cases/3d-printing)、[S32: Form 4 design specifications](https://formlabs.com/support/Design-specifications-for-3D-models-Form-4-generation/)

## 3. 公差、隙間、精度を区別する

設計寸法の許容範囲を表す公差と、部品間に設ける隙間、印刷された寸法の誤差は別。試験記録に「公差0.2」とだけ書くと、片側の隙間なのか、直径差なのか、測定誤差なのかが分からなくなる。

丸いピンなら、穴径を`D_hole`、ピン径を`D_pin`として、直径差`c = D_hole - D_pin`、片側の半径方向隙間は`c/2`と定義する。例えばピン10.00 mm、穴10.40 mmなら、直径差は0.40 mm、理想的に中心が揃ったときの片側隙間は0.20 mmになる。

原寸の試験片で、例えば直径差0.10 / 0.20 / 0.30 / 0.40 / 0.50 mmを比較する。これは探索用に提案する範囲であり、全方式に推奨される隙間ではない。ピン径・穴径、向き、材料、プロファイル、後処理、組立時の感触を記録する。

Prusaは可動部の初期検討値として0.3 mm以上の例を示すが、形状・方向・校正・材料に依存すると説明する。この値を、上の式の直径差へ無条件に読み替えない。[S14: Tolerances](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)

## 4. 寸法の問題は順序を決めて直す

1. STLやCADの単位とスライサー上の外形寸法が正しいか確認する。
2. 機械の校正、押出し量、初層、材料と基本設定を確認する。
3. 同じ方向・材料の試験片で、外寸、穴、嵌合を別々に測る。
4. 収縮の傾向と、初層だけの膨らみを区別する。
5. 必要な箇所へ穴径補正や設計変更を行う。全体のスケール変更で重要寸法を同時に動かさない。
6. 後処理後に測り直す。

Formlabsの資料は、研磨や二次硬化でも完成寸法が変わると説明する。組立を保証したい場合、造形直後と完成後のどちらを測ったか明記する。[S22: 精度・公差](https://formlabs.com/jp/blog/understanding-accuracy-precision-tolerance-in-3d-printing/)、[S36: SLA dimensional inaccuracy](https://formlabs.com/jp/support/Dimensional-inaccuracy-SLA/)

## 5. 造形方向を決める

| 優先すること | 検討する向き | 注意点 |
| --- | --- | --- |
| FDMの強度 | 主な引張・曲げに対し、層間で割れにくい向き | 荷重の方向を図にして、根元の断面も見る |
| 表面 | 見せたい面を支持が触れにくい方向へ | 積層痕・縫い目・支持痕は別々に考える |
| 寸法 | 嵌合面や穴の向きを試験片と合わせる | 横穴と縦穴は同じ誤差にならないことがある |
| 初層の接地 | 安定した底面を用意 | 支持の底面、brim、他の部品との距離も必要 |
| 光造形の安定 | 急に大断面が現れず、島と吸盤状の空洞が少ない向き | 単に45°へ傾けるだけでは解決しない |

FDMの層方向による強度と、支持上の面の仕上がりの違いは、Prusa設計資料でも扱われている。荷重方向を優先すると支持が増える場合があるため、強度、表面、時間のどれを優先したか記録する。[S14: Orientation on the print bed](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)

## 6. オーバーハングの角度を読む

「45°までなら支持不要」は簡便な目安で、普遍的な限界ではない。ノズル、材料、冷却、層高、幅、速度、形状によって変わる。資料とスライサーで、角度をベッドの水平面から測るのか、垂直から測るのかも確認する。

FDMでは短い橋と、片持ちの張り出しを区別する。橋は両端を支えられるが、長さや冷却次第でたわむ。支持を追加する前に、向きを変える、角を面取りする、アーチにする、分割する等を検討する。[S18: Material de soporte](https://help.prusa3d.com/es/article/material-de-soporte_1698)

## 7. 分割と接合

| 分割する理由 | 分割位置の候補 | 追加で設計するもの |
| --- | --- | --- |
| 造形範囲に入らない | 段差、服の境界、自然な継ぎ目 | 位置決め、接着面、組立順 |
| 支持を減らす | 下向き面や大きな張り出しの付け根 | 別部品の底面と方向 |
| 強度を変える | 荷重が集中する箇所を避けた位置 | リブ、ねじ、ピン、接合面積 |
| 色や材料を変える | 塗り分けの境界 | 差込み、固定、後処理の逃げ |
| 細部を交換したい | 手、道具、台座など | 誤組立しにくいキー付き接続 |

PrusaSlicerのCut toolは、切断とプラグ・ダボ・スナップ等の位置決めを作れる。コネクターを作れたというだけで嵌合が成立したとは考えず、少なくとも一組は原寸で試す。[S38: Cut tool](https://help.prusa3d.com/article/cut-tool_1779)

接合の穴を深くしすぎると、接着剤や空気の逃げがなく、最後まで挿入できない場合がある。接着面と位置決めの役割を分け、仮組立してから接着する。組立後に見えない箇所へサポートや合わせ目を逃がせると、仕上げがしやすい。

## 8. 強度はインフィルだけで決めない

外壁、層間の結合、形状、根元の丸み、穴位置、荷重方向を先に見る。内部を100%にしても、細い接続や悪い向きが自動で解消するわけではない。ドイツ語のPrusa資料も、強度を増したい場合は外周数の増加を重視している。[S15: Infill](https://help.prusa3d.com/de/article/infill_42)

このリポジトリでの応用なら、展示用模型、取り付け位置の確認用モデル、非加圧の外装などから始める。飛行・圧力・人の安全に関わる部品は、この資料の一般的な試作値だけで適合を判断できない。必要荷重、材料仕様、製造条件と別途の検証を設計要件にする。
