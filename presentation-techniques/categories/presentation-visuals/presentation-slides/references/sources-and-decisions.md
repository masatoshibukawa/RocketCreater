# 元メモの採用判断と補足出典

確認日: 2026年11月7日。出発点は、このチャットでユーザーが提示した「スライド作成のコツ」。下記の進め方や数値例は、実務上の選択と、外部資料で確認した根拠を区別して使う。

## 元メモをどう取り入れたか

| 元メモの着眼点 | スキルへの取り込み方 |
| --- | --- |
| 聴衆・経緯・ゴールから考える | 初めに相手の理解、関心、懸念と、終了後の判断・行動を整理する |
| コアを5行以内、文章で骨子を書く | 初期の要約と主張アウトラインとして採用。根拠のない結論へ書き切らない |
| 思考と作業を分け、手描きしてから清書 | テキスト・ラフ・清書を分ける進め方にする。途中で論点が変われば戻れるようにする |
| 大事なスライドから作り議論する | 中心の証拠から制作し、意味と根拠を先にレビューする |
| 1スライド1メッセージ | 一つの判断を助ける原則にする。比較のための複数図や定義・演習にも対応する |
| 全体の枠から詳細へ進む | 全体像と詳細の往復を示す。特定企業の用語や成果としての帰属は追加しない |
| MECE、軸は独立 | 分類の粒度と重複を点検する。散布図の統計的独立性を要求する規則にはしない |
| 二軸まで、立体表現を避ける | 定量比較の装飾的な3Dを避け、形状・空間が内容である場合は3Dを使えるようにする |
| 色2系統、文字10〜18pt、線3段階 | 共通設定を少数に絞る考えを採用。数値例は用途・テンプレート・表示条件に応じて調整する |
| 余白、整列、マスタ、ツールバー | 反復作業を減らす操作として整理。読み順、代替テキスト、書き出し後の確認を補足する |

## 一次資料と適用範囲

- **P1 Microsoft**: [PowerPointのアクセシビリティ](https://support.microsoft.com/en-us/office/make-your-powerpoint-presentations-accessible-to-people-with-disabilities-6f7772b2-2f33-4bd2-8ca7-dae3b2b3ef25)。18pt以上の推奨、タイトル、読み順、代替テキスト、コントラストの確認。フォント値だけで会場の可読性を保証する資料ではない。
- **P2 Microsoft**: [PowerPointの作成用ショートカット](https://support.microsoft.com/en-us/accessibility/powerpoint/use-keyboard-shortcuts-to-create-powerpoint-presentations)。Windows、Mac、Web等を分けた操作一覧。OS・版・配列・選択状態を確かめる。
- **P3 Microsoft**: [スライドのレイアウト](https://support.microsoft.com/en-us/powerpoint/what-is-a-slide-layout)。書式、配置、プレースホルダーとマスタの関係。マスタを使うだけでメッセージが決まるわけではない。
- **P4 Microsoft**: [クイックアクセスツールバーの設定](https://support.microsoft.com/en-us/office/customize-the-quick-access-toolbar-43fff1c9-ebc4-4963-bdbd-c2b6b0739e52)、[キーボードでの利用](https://support.microsoft.com/en-us/office/use-a-keyboard-to-customize-the-quick-access-toolbar-caba65f5-c6d7-43ab-a1ee-5275423b2ad0)。登録順とキーヒントを確認するために使う。
- **P5 Michael Alleyら**: [Assertion–Evidenceの手順](https://www.assertion-evidence.com/tutorial-642629.html)、[Alley and Neeleyによる設計論](https://writing.engr.psu.edu/ae_rethinking.pdf)。主張を文で書き、視覚的根拠で支え、制作前にメッセージを並べる方法。目的や媒体にかかわらず、全スライドを同じ形へ固定する根拠にはしない。
- **P6 UK Government Analysis Function**: [図表の実務ガイド](https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/)。直接ラベル、軸、読みやすい図、不要な立体化の削減に使う。Web向けアクセシビリティの制度説明を、すべての発表への法的義務として転用しない。

32／24／18pt、色2系統程度、線0.75／1.5／3ptは本スキルの作業開始例であり、上記資料が一律に定めた規格ではない。PowerPointのマウス操作はこのチャットで実機確認していない。取得資料の操作一覧と元メモを踏まえ、対象版で確かめて使う。
