# PowerPointと図表を仕上げる

## 表示条件から共通設定を決める

既存のテンプレートとブランドがあればそれを起点にする。投影、配布PDF、画面共有で同じ密度を強制しない。

| 設定 | 作業の出発点 | 確認すること |
| --- | --- | --- |
| 色 | 基調と強調の2系統程度に、背景と本文の中立色を加える | 同じ役割はページをまたいで同じ色。必要な分類色は追加し、ラベルや線種も併用する |
| 文字 | 見出し・本文・補助情報の少数の階層 | 投影なら32／24／18ptなどを開始例にし、会場と画面で調整する。固定の規格ではない |
| 線 | 細線0.75、通常1.5、強調3ptなどの少数の役割 | 縮小や投影で細線が消えないか。線の強さが重要度を誤解させないか |
| 余白 | 外周に一定の安全域、関連要素をまとめる間隔 | 見出し、本文、出典が端へ詰まらず、要素間の関係が分かるか |
| 配置 | ガイドと整列・等間隔配置 | スライドに揃えるのか、選択要素同士に揃えるのかを確認する |

元メモの10、12、14、16、18ptは、使うサイズを絞る例として受け取る。投影用本文を10〜14ptへ固定しない。Microsoftは読みやすさのため18pt以上を推奨するが、その値だけで可読性は保証されない。配布資料で小さい文字が必要なら、実寸のPDFや印刷物で確認し、細部を補足へ分ける。[P1](sources-and-decisions.md)

色だけで合否や系列を表さず、文字、記号、線種、直接ラベルを添える。コントラストと日本語を含む字体の読みやすさを確認する。余白を残すことを、根拠のない大きな空白で内容を薄くすることと混同しない。

## 図表の信頼性を保つ

- 軸、単位、期間、比較条件、標本・試行の単位と出典を示す。予測・実測・計算を区別する。
- 棒の長さを比較させる図ではゼロ始点を基本にする。折線や散布図の表示範囲は目的に合わせ、範囲や省略を読めるようにする。
- 凡例を往復させず、可能なら系列の近くへラベルを置く。注釈は対応する箇所へ寄せる。
- 効果を大きく見せるための軸変更や、値を読み取りにくくする立体化を避ける。実物の3D表現とは使う目的を分ける。[P6](sources-and-decisions.md)

## マスタと編集可能性を整える

清書前にアスペクト比、テーマの色・フォント、スライドマスタと必要なレイアウトを確認する。タイトル、本文、図、ページ番号・出典の置き場を揃え、反復する部品を毎ページ別々に直さなくて済む構成にする。[P3](sources-and-decisions.md)

タイトルなどはレイアウトのプレースホルダーを使えるか検討する。文字とグラフは編集可能な形を保ち、重要な内容をスクリーンショットだけに閉じ込めない。図の一部を見せるときは、不要な範囲を切り取り、必要な条件と出典は残す。

重ね合わせは、注釈や段階表示に必要なものへ絞る。意味のある単位でグループ化し、選択ウィンドウで名前と前後関係を整える。読み順を変更すると見た目の重なりも変わる場合があるため、再表示して確かめる。[P1](sources-and-decisions.md)

## よく使う操作を短くする

クイックアクセスツールバーには、実際に繰り返す整列、等間隔配置、グループ、前後関係などを選んで登録する。頻度の高い順に並べ、WindowsではAltを押して、その環境に表示されたキーヒントで呼び出す。登録順や言語で変わる番号・文字を固定しない。[P4](sources-and-decisions.md)

次はWindows版の代表例。選択対象と編集中の場所により動作が変わるため、対象版の公式一覧で確認する。Mac・Webへ同じキーを当てはめない。[P2](sources-and-decisions.md)

| 操作 | キー・操作例 |
| --- | --- |
| 選んだオブジェクトを複製 | Ctrl+D、またはCtrlを押しながらドラッグ |
| グループ化／解除 | Ctrl+G／Ctrl+Shift+G |
| オブジェクトを順に選択 | オブジェクト選択中にTab／Shift+Tab |
| スライドショー開始／終了 | F5／Esc |

元メモのCtrl+Shift+ドラッグによる複製と方向制限の併用は、利用版で一度確認してから使う。位置を確実に揃えたいときは、複製後に整列・等間隔配置や位置・寸法の数値指定を使う。書式コピーはボタンやキーヒントを確認し、版で異なるショートカットを決め打ちしない。

## 完成時の確認

1. **論理**: 見出しだけで筋が通り、各ページの根拠が主張を支える。未確認の倍率や実績を作っていない。
2. **表示**: 実スライドと書き出したPDF・画像を開き、改行、はみ出し、文字化け、フォント置換、重なり、軸と出典の可読性を確かめる。
3. **アクセス**: 固有のタイトル、読み順、意味のある代替テキスト、リンク表示名、色以外の区別を確認する。PowerPointのアクセシビリティチェックも使う。[P1](sources-and-decisions.md)
4. **再生**: リンク先、動画、音声、アニメーションを提出・上映環境で確認する。PDFでは段階表示や動画が同じように動く前提にしない。
5. **理解と尺**: 声を出して計時し、初見の人が中心のメッセージと次の判断を説明できるか確かめる。

ここでの手順は確認対象であり、ファイルを作っただけで実施済みとはしない。出力形式の制作スキルにレンダリング等の要件があれば併せて実施する。
