# スライド設計

利用時は [共通の判断](../../../SKILL.md) を確認する。

投影しながら話す資料と、後から単独で読むデックを区別する。投影の簡潔さを読み物へ機械的に当てはめない。ファイル制作の依頼なら対応する制作手段を使い、構成案だけで終えない。

- 一つのページで助ける判断を定め、見出しをその主張や問いにする。未確定なら結論を作らない。
- 図、説明、直接ラベルを近づけ、注目点を強調する。動きや装飾は理解への役割を確認する。
- 箇条書きを消すこと自体を目的にしない。全文と複雑な図を同時に追わせる負荷を調整しつつ、字幕・用語表示は維持する。
- 主張見出しと視覚的根拠の実験は、110人の技術学習など対象と結果指標に限定する。見出しだけの効果や投資・受賞への効果を証明したとはしない。
- 後方席、画面共有、動画プレイヤーの大きさで軸・字幕・出典を読めるか確かめる。フォントの数値だけで合格にしない。

「元の判断しにくい点→変更→残す根拠」を示して改稿する。反例やスケールを落として主張を強めていないかも確認する。
