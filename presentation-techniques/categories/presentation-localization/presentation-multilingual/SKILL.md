# 多言語・文化・伝達条件

利用時は [共通の判断](../../../SKILL.md) を確認する。

相手の役割・制度・共有知識・言語習熟度・字幕や通訳の条件を確認する。国籍だけで結論の順序、自信、ユーモア、望ましい話し方を固定しない。

- 短い文、一貫した用語、明示的な移行を使う。日本語でも主語や対象を省略し過ぎず、英語でも慣用句や長い従属節に依存しない。
- 金額、通貨、万/億/million等、日付、時間帯、数値の定義、機能名を照合する。翻訳で性能や完成範囲を増やさない。
- 同言語字幕と翻訳字幕を区別し、専門語・数字・否定・必要な音情報を同期して伝える。キーワードだけへの短縮を常に良いとしない。
- 字幕はUIを隠さず読める時間を確保する。日英の長文を同時表示する前に、選べる字幕を検討する。
- 色だけに意味を持たせず記号・ラベルも使う。重要な視覚情報は口頭でも説明する。
- 訛りの印象と実際の理解を分ける。機能名・数字・比較対象を相手に言い直してもらう。
- 地域の材料・制度・業務知識が違う場合は、翻訳に加えて評価条件も見直す。原語ガイドの違いを国民性の実証にしない。

成果物は対象条件を反映した原稿・用語表・字幕案と、意味・単位・主張の照合結果。訳が完成しても聴衆の理解や大会の言語条件を満たしたと自動判定しない。
