# 構成・物語・根拠

利用時は [共通の判断](../../../SKILL.md) を確認する。

中心のメッセージを、聴衆が判断できる主張へ具体化する。課題解決の型に合わない作品では遊び・表現・発見の体験をそのまま扱う。

- 主張ごとに画面・図・測定・証明・出典を対応させ、事実、解釈、仮説、計画を分ける。
- 「速い」は開始・終了と比較条件、「正確」は正解と評価対象、「AIが判断」は入力・ツール結果に応じた変化を示す。
- 「なぜ自分たちか」は経験→気付いた制約→変えた設計・評価→確認できた結果で示す。肩書や唯一性の宣言で補わない。
- 物語を理解しやすい順に変えても、事前の予想と事後の解釈を混同しない。逸話を集団の効果の証明にしない。
- 短時間では主要な論証を本編、詳細を補足へ置く。質疑を誘うために必要な説明を隠さない。

「主張／根拠／比較条件／言える範囲／未確認／本編・補足」の表を作り、筋の通る台本へ変換する。未計測の倍率・人数は仮置きとして明記する。
