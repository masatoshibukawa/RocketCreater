# 目的・構成・時間

[共通の判断](../../SKILL.md)を確認し、このカテゴリで必要なものだけを読む。

発表後に必要な判断を決めてから構成を選ぶ。既に台本や図がある依頼なら、その内容と指定条件を読み、作り直す必要のある部分に絞る。

目的が曖昧なら聴衆と目的、筋が追えないなら論証、尺が決まっているなら時間設計を読む。研究・投資家・デモのどれにするかを、時間の長さだけで決めない。

| サブカテゴリ | 選ぶ目的 |
| --- | --- |
| [聴衆と目的](presentation-audience-goals/SKILL.md) | 誰のどの判断を助ける発表かを定める |
| [構成・物語・根拠](presentation-argument-evidence/SKILL.md) | 主張、比較、経験、証拠を結び付ける |
| [時間別の設計](presentation-duration/SKILL.md) | 1・2・3・5・10・15・30分と質疑枠を設計する |

目的と関係しない資料は追加しない。分類の背景や元文書の網羅性を調べる場合は [分類表](../../taxonomy.md) を参照する。
