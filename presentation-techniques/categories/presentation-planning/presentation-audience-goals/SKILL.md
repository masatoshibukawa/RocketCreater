# 聴衆と目的

利用時は [共通の判断](../../../SKILL.md) を確認する。

依頼と既存資料から相手、発表後の判断、媒体、時間を取り出す。既に明示された条件を再質問しない。重要な条件が未定なら仮定を示し、独立に進められる原稿は作る。

- 投資家は次の面談・投資、顧客は自分の作業への導入、社内は予算・担当・試行、研究者は主張の根拠、審査員は採点項目に対応する動作を知りたい。
- 専門用語の共有が少なければ一人の場面と具体的な入力・結果で入口を作る。専門家同士でも隣接分野の前提は確認する。
- 冒頭は製品の一文説明、利用場面、条件付きの結果、研究の問いから選ぶ。長い課題説明やWhyから始める型に固定しない。
- 結びは最初の判断へ戻す。投資の依頼、試行の承認、研究の答えなどを場に合わせる。

「聴衆／求める判断／一文の説明／必要な根拠／媒体と本編時間」の設計メモと、それを反映した冒頭・結びを作る。目的が既定なら確認だけで終えず依頼された原稿へ反映する。
