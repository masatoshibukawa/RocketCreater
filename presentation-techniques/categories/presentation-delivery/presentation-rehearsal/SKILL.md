# 理解確認とリハーサル

利用時は [共通の判断](../../../SKILL.md) を確認する。

練習回数より検出した問題と修正結果を残す。実際に試聴・計時していなければ計画と実施結果を分ける。

- 音声だけで順序と主張、無音映像で入力と結果・文字、通しで尺と操作、本番環境で共有・音・認証を確認する。
- 初見の人に、誰の何が変わったか、主張と根拠、確認した範囲を言い直してもらう。
- 研究は問い・答え・根拠・限界、LLMデモはモデルと人・ツールの担当、資金調達は事業・進捗・依頼を確かめる。
- 止まった箇所の原因を前提、用語、図、密度、操作に分け、一つの修正を試す。
- 超過時に結果と結びへ戻る短縮版や、途中の質問からの復帰を練習する。
- デモは起動確認に加えて実際の共有画面、機器、提出URLからの再生を試す。録画へ代替できるかは大会に従う。

「相手・環境／理解した内容／止まった時刻／原因仮説／修正／再確認」の記録を作り、重要な変更を台本・画面へ反映する。未実施の理解テストを合格にしない。
