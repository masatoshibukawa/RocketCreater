# 話し方・質疑・練習

[共通の判断](../../SKILL.md)を確認し、このカテゴリで必要なものだけを読む。

話し方の印象だけでなく、聞き手が何を理解できたかを確かめる。原稿・音声・映像のうち、実際に確認できた媒体を明示する。

声と画面の同期は話し方、質問への返答は質疑、尺・誤解・共有画面の問題はリハーサルへ進む。音声を聞いていない段階で声色や話速を採点しない。

| サブカテゴリ | 選ぶ目的 |
| --- | --- |
| [声・間・身体・チーム](presentation-speaking/SKILL.md) | 説明と画面、視線、役割交代をそろえる |
| [質疑応答](presentation-questions/SKILL.md) | 質問に直接答え、根拠と未確認範囲を示す |
| [理解確認とリハーサル](presentation-rehearsal/SKILL.md) | 初見の理解、尺、本番環境から修正する |

目的と関係しない資料は追加しない。分類の背景や元文書の網羅性を調べる場合は [分類表](../../taxonomy.md) を参照する。
