# 質疑応答

利用時は [共通の判断](../../../SKILL.md) を確認する。

相手が判断したい点、主張を疑われる点、代替案、失敗条件から質問を選ぶ。

- 最後まで聞く→曖昧なら範囲を確認→短い答え→根拠→未確認の範囲、の順で練習する。
- 不明な値や未実施の比較を作らない。「試していない」と確認に必要な条件を述べる。
- 投資家は顧客・競争・資金使途、研究は方法・仮定・別解釈、デモは自作・動作範囲・期間内差分・技術選択を厚くする。
- 補足図に答える質問を付ける。本編を意図的に不完全にして質問を誘わない。
- 複数質問は順序を確認して答え、担当者へ渡す時も論点を共有する。
- 質問の有無だけで成否を決めない。割込みと質疑枠は場に従う。

「質問／最初の答え／根拠／未確認／担当・補足」の表と回答文を作る。Claude日本大会の審査員同士の約2分議論を参加者のQ&A枠にしない。
