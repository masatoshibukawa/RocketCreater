# 事例分析・調査

[共通の判断](../../SKILL.md)を確認し、このカテゴリで必要なものだけを読む。

分析対象、確認した媒体、出典の種類を記録する。作品や講演の良い点を記述することと、受賞・説得の因果効果を証明することを分ける。

講演の言葉と構成はTED分析、技法の原著・実務助言や要項・受賞・参加者レビューは出典評価を読む。両方を調べる場合も、観察と解釈と転用案を別の列に残す。

| サブカテゴリ | 選ぶ目的 |
| --- | --- |
| [TED・講演分析](presentation-ted-analysis/SKILL.md) | 発話・構成・背景から工夫を取り出し、映像観察と区別する |
| [出典評価・大会・受賞者調査](presentation-source-research/SKILL.md) | 研究・助言・募集・受賞事例の根拠と適用範囲を調べる |

目的と関係しない資料は追加しない。分類の背景や元文書の網羅性を調べる場合は [分類表](../../taxonomy.md) を参照する。
