# TED・講演分析

利用時は [共通の判断](../../../SKILL.md) を確認する。

講演名、開催回、話者の当時の背景、公式の講演と文字起こしを確認する。既存6例は比較資料として読み、新しい講演は一次資料を調べる。

- 発話順に「時刻／実際の発話や画面の要約／構成上の役割／転用案／未確認」を残す。
- Robinsonの会話とユーモア、Sinekの枠組みと反復、Brownの予想の更新、Roslingの図の読み方、Adichieの複数の立場、Urbanの比喩と転換を、異なる説明手段として比較する。
- 字幕で分かる言葉と笑い・拍手の表記を、声色、視線、身振り、沈黙の実測と混同しない。音声・映像を見たときだけ、その媒体での観察を記録する。
- 伝え方の明快さと、講演内容の科学的・歴史的正しさを別に評価する。人気や拍手で正しさを保証しない。
- 全文転載にせず公式字幕へリンクし、必要最小限の引用と独自要約を使う。日本語の要約を公式字幕の逐語訳と表示しない。
- 短いピッチへは足場や比較などの役割を移す。19分の脱線量や逸話を3分へ同じ割合で移さない。

成果物は講演ごとの背景・内容・時系列・工夫・良い点・限界・転用案と、確認した媒体と出典。実見していない演技・音楽は未確認とする。
