# ポスター

利用時は [共通の判断](../../../SKILL.md) を確認する。

学会指定の寸法・向き・印刷/電子版・提出条件を確認する。口頭スライドを縮小して貼るのではなく、不在でも入口と主結果が分かる構成を作る。

- 通りがかりの人には問いと答え、立ち止まった人には主要図と条件、議論する人には方法・例外・限界を辿れるようにする。
- 主結果の図、対象・比較・単位、範囲付きの結論を近くへ置く。詳細を減らしても根拠の条件を消さない。
- 20〜30秒程度の入口は短い会話を始める目安。相手の関心で次の図を選び、長い説明を全員に最初から押し付けない。
- QRや連絡先を付けても、本体の意味をリンク先だけへ逃がさない。
- ポスターの読みやすさと発表の対話はそれぞれ試す。相手が黙って読む時間も残す。

成果物はレイアウト・図の配置案またはポスター実物、短い入口の原稿、深掘りできる図の説明。具体的な書き出しが依頼されていれば、対応する制作手段で完成物を確認する。
