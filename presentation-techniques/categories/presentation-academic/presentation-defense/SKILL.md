# 学位・資格審査

利用時は [共通の判断](../../../SKILL.md) を確認する。

所属先の正式要件、委員への案内、時間、公開/非公開、言語、割込みを確かめる。MITのRQE、TUM、UChile等の一例を全審査の規則にしない。

- 問い、貢献、方法を選んだ理由、証拠、仮定、限界、既存研究との関係を説明する。
- 共同研究では自分の担当を明示する。独立して何を判断し、何を変えたかを根拠で示す。
- 代替案、公平な比較、感度・失敗条件、追加実験、導出など想定質問へ補足を対応させる。
- 質問の範囲を確認し、短い答えと根拠を出す。未検証を認め、確かめる方法へつなぐ。
- 途中で質問が入っても主要な貢献と結びへ戻れるように計時する。長く話すことを理解や能力の証明にしない。

成果物は所属先条件のメモ、発表原稿・時間表、個人貢献の説明、質問と補足の索引。制度本文が未取得なら、確認済みの条件と準備上の仮定を分ける。
