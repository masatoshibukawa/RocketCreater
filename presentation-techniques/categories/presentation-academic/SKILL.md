# 研究プレゼン

[共通の判断](../../SKILL.md)を確認し、このカテゴリで必要なものだけを読む。

成果の説明、次の研究判断、批判的な論文読解、能力の審査、計画への支援を区別する。研究分野に適した根拠を選び、実験研究だけの型へ押し込まない。

まず下表から場を選ぶ。科学図表の依頼は視覚カテゴリも読む。3MTの競技条件、学位審査の制度、研究費の募集要項は当該版を確認する。

| サブカテゴリ | 選ぶ目的 |
| --- | --- |
| [学会・研究成果の口頭発表](presentation-research-talks/SKILL.md) | 問い、貢献、方法、結果、解釈、範囲を論証する |
| [進捗報告・論文紹介](presentation-lab-journal/SKILL.md) | 次の研究判断と、論文の主張の批判的検討を進める |
| [ポスター](presentation-posters/SKILL.md) | 短い入口から図と対話へ進める |
| [学位・資格審査](presentation-defense/SKILL.md) | 貢献、方法の選択、担当、技術質問を説明する |
| [一般向け研究紹介・3MT](presentation-research-outreach/SKILL.md) | 専門外向けに研究を伝え、競技固有の媒体規則を守る |
| [研究費・研究計画](presentation-grant-pitches/SKILL.md) | 支援の理由、実行可能性、予備的根拠、リスクを示す |

目的と関係しない資料は追加しない。分類の背景や元文書の網羅性を調べる場合は [分類表](../../taxonomy.md) を参照する。
