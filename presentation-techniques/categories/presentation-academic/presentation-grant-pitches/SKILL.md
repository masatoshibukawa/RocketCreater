# 研究費・研究計画

利用時は [共通の判断](../../../SKILL.md) を確認する。

募集要項、審査者の専門性、支援対象、指定項目と時間を確認する。成果発表やスタートアップの投資家ピッチの項目をそのまま必須にしない。

- 問いと意義、既存研究の不足、着眼点、検証可能な予測、方法、予備的根拠、成否の判断を結ぶ。
- 既報、自己の予備データ、これから得たい結果を分ける。見込みを確認済みの成果へ変えない。
- チームの知識・データ・設備・協力体制が実行可能性をどう支えるかを示す。
- 主要な不確実性と代替策、支援で達成する節目を説明する。費目や予算の指定があれば、その募集に合わせる。
- 物語で証拠の不足を隠さない。教育記事の助言を採択率の実証結果と呼ばない。

成果物は指定項目に対応した原稿・構成と「計画／裏付け／不確実性／検証・代替策」の表。まだ不明な実験結果や資金条件は作り足さない。
