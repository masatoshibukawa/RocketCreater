# TED Talksの構成と話し方の事例集

確認日: 2026-11-06

有名なTED Talksから、説明の仕方を比較できるトークを選んだ。主張、時系列の構成、話し方の工夫、良い点、発表へ取り入れる方法を整理する。再生数の順位表ではない。TED本体の講演と、地域で独立開催されるTEDxの講演を区別して記載する。

## 文字起こしの使い方

各分析から、公式の英語・日本語の文字起こしを開ける。ページの「Read transcript」から本文を読む。6本について、公式ページに含まれる時刻付き英語字幕を取得し、日本語字幕が提供されていることも確認した。

本文には、全文の転載に代えて短い引用と、発話順に沿った日本語の要約を載せる。引用以外の日本語は分析・要約であり、公式字幕の翻訳文ではない。時刻は取得時の公式英語字幕の目安で、他の動画版や字幕言語ではずれる場合がある。

## 観察と解釈の範囲

- **確認したこと:** 公式の講演情報、時刻付き字幕の発話・笑い・拍手の表記、登壇者情報、関連する本人・団体の資料。
- **分析したこと:** 構成、言葉の選び方、対比、反復、語りの役割、発表へ応用する方法。
- **今回の範囲外:** 映像と音声の全編再生に基づく視線・身振り・声色の評価、音圧や話速の実測。字幕にない身体動作や声の強弱は推測して記載しない。

「良い点」は伝わり方についての分析であり、講演中の科学・歴史・社会に関する主張をすべて検証したという意味ではない。有名さや観客の笑い・拍手だけを、内容の正しさや技法の因果的な効果の証明にしない。
