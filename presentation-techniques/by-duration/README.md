# 時間別のビジネスプレゼンとピッチ

確認日: 2026-11-06

1分・2分・3分・5分・10分・15分・30分の発表を、聞き手に求める行動から設計する。短い発表では関心と次の接点を作り、時間が増えたら、根拠、代替案、実行条件、リスクを詳しく扱う。投資家面談や社内会議では、質疑と意思決定の時間も必要になる。

最初に、指定された時間が「発表のみ」か「質疑込みの会議全体」かを確認する。Techstarsは30分の投資家面談のうち説明を約10分にする例を示し、Duarteは30分の役員向け発表でも冒頭の短い要約から議論へ進むことを勧める。[Techstars](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)、[Duarte](https://www.duarte.com/blog/how-to-effectively-present-to-senior-executives/)

## 7種類の使い分け

次の時間配分・枚数は、原資料の助言を踏まえた作成開始用の提案。実験で確定した最適値ではない。枚数に補足資料は含めず、大会や面談先の指定を優先する。

| 発表時間 | 主な目的 | 残す内容 | スライドの開始目安 |
| --- | --- | --- | --- |
| 1分 | 何をする会社・提案か理解してもらう | 顧客・課題、改善、裏付け一つ、次の依頼 | なし〜1枚 |
| 2分 | 価値と信用を伝え、続きを聞いてもらう | 1分版に、利用場面と選ばれる理由を足す | 1〜3枚 |
| 3分 | 事業・提案の全体像を短く共有する | 課題、解決、証拠、事業の成立、チーム、依頼 | 3〜5枚 |
| 5分 | 価値を具体的な証拠で納得してもらう | 実演や事例、重要な比較、成立条件、次の計画 | 4〜6枚 |
| 10分 | 検討に必要な論点を一通り共有する | 市場・便益、モデル、競合、チーム、資金・計画 | 7〜10枚 |
| 15分 | 懸念と実行条件まで検討してもらう | 詳しい根拠、代替案、実行計画、リスクと対応 | 10〜15枚 |
| 30分 | 詳細を共有し判断につなげる | 冒頭の要約、根拠、比較、導入条件、実行と意思決定 | 全編発表なら12〜20枚を出発点にする |

30分の**面談枠**なら、上表の30分全編発表をそのまま入れない。10分前後の説明と、質問に応じて使う補足資料を準備する。

## 原資料で確認できた違い

MIT Orbitは1分、3分、5〜10分、詳しい面談を区別する。Seattle Universityは2分版の構成例を公開している。Bpifranceは5分、7〜12分、15〜20分という区分を示す。「エレベーターピッチ」という言葉自体にも、機関ごとに異なる長さの使い方がある。[MIT](https://orbit-kb.mit.edu/hc/en-us/articles/205147056-What-are-typical-pitch-durations-for-a-startup/)、[Seattle University](http://cms.seattleu.edu/media/seattle-university/albers-school-of-business/student-life/innovation-and-entrepreneurship-center-iec/files/HSBPC-Pitch-Outline.pdf)、[Bpifrance](https://bpifrance-creation.fr/encyclopedie/porteur-projet-preparation-droits-obligations/preparation/plan-type-pitch-presenter)

このため、名称だけで長さや情報量を決めず、持ち時間、聞き手、審査・承認項目、求める次の行動を確認する。
