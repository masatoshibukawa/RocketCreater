# 10分から30分のビジネスプレゼン

10分・15分・30分の**発表のみ**の構成例と、30分の**面談全体**の例を分ける。表の秒数と枚数は独自の作成案であり、原資料の指定ではない。相手の判断項目に合わせて調整する。

## 10分で検討の全体像を共有する

**向く場面:** 投資家への事業説明、具体的な営業提案、社内の予算・新規事業提案。

Bpifranceは7〜12分の中間的なピッチを、インキュベーター等の選考向けに挙げている。Riceの確認時の2027年向け案内にも10分の投資家向けピッチがある。どちらも、10分がすべての場面で最適という意味ではない。[Bpifrance](https://bpifrance-creation.fr/encyclopedie/porteur-projet-preparation-droits-obligations/preparation/plan-type-pitch-presenter)、[Rice](https://rbpc.rice.edu/compete/competition-rules-and-format)

| 時間 | 役割 | 話すこと |
| --- | --- | --- |
| 0:00〜0:40 | 中心の主張 | 誰の何を改善し、何を検討してほしいか |
| 0:40〜1:40 | 課題 | 顧客、現状、負担、既存の対処 |
| 1:40〜3:00 | 解決 | 利用の流れ、実演、今取り組む理由 |
| 3:00〜4:30 | 証拠 | 需要、成果、比較、検証条件 |
| 4:30〜5:30 | 対象と規模 | 市場と初期顧客、または導入範囲と便益 |
| 5:30〜6:30 | 成立の仕組み | 価格・販売・収益、または費用・運用 |
| 6:30〜7:30 | 選択の理由 | 競合や代替案との比較 |
| 7:30〜8:15 | 実行する人 | 関係する能力、役割、不足する役割 |
| 8:15〜9:30 | 資源と計画 | 資金・人員・期間、使途、到達目標 |
| 9:30〜10:00 | 結び | 主張、依頼、次の行動 |

**技法:** 5分版に、市場や導入範囲、事業・運用の成立、競争、実行計画を加える。各章を短く均等に並べるより、相手が疑問を持つ箇所に根拠を厚くする。

**スライド:** 7〜10枚を出発点にする。数表を全部読まず、必要な結論を見出しに置く。細かな前提や計算は補足へ分ける。

**質疑:** 発表だけで10分と指定された審査なら、その範囲で完結させる。投資家面談であれば、10分版を対話の入口として使い、質問に合わせて該当箇所へ移る。[Techstars](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)

## 15分で実行条件と懸念まで扱う

**向く場面:** 検討が進んだ投資家面談、具体的な導入提案、社内の承認審査。

Bpifranceは15〜20分を、投資家・銀行・支援組織等との長いピッチの区分として紹介する。相手が判断する事項に合わせ、追加の時間を実行の条件へ使う。[原文](https://bpifrance-creation.fr/encyclopedie/porteur-projet-preparation-droits-obligations/preparation/plan-type-pitch-presenter)

| 時間 | 役割 | 話すこと |
| --- | --- | --- |
| 0:00〜1:00 | 結論と目的 | 提案の内容、期待する成果、今回の判断 |
| 1:00〜3:00 | 問題と必要性 | 顧客・現場の状況、負担、現在の対処 |
| 3:00〜5:30 | 解決 | 具体的な使い方、実演、業務の変化 |
| 5:30〜8:00 | 証拠 | 顧客の反応、成果、比較の条件と限界 |
| 8:00〜10:00 | 成立条件 | 市場・収益、または導入範囲・費用対効果 |
| 10:00〜11:30 | 代替との比較 | 選ぶ理由と、採用しない案の理由 |
| 11:30〜13:00 | 実行とリスク | 段階的な計画、主要な不確実性、対応 |
| 13:00〜14:15 | 体制と資源 | チーム、資金・人員、到達目標 |
| 14:15〜15:00 | 結び | 承認・検討・次回確認を具体的に依頼 |

**技法:** 「提案は有望」という主張に、どの条件で成立し、どこまで確認できたかを添える。競合、現状維持、別の導入案などを比較し、なぜその選択かを説明する。長くなった分を機能紹介だけに使わない。

**スライド:** 10〜15枚を出発点に、課題と解決、証拠、比較、計画の章を見分けられるようにする。説明が必要なグラフは、軸と読み方を伝えてから結論へ進む。

**質疑:** 15分が会議全体なら、例えば10分説明・4分質疑・1分で次の行動という配分に変更する。15分の台本をそのまま読み、最後だけ質疑を急ぐ形にしない。

## 30分で詳細から判断へ進める

### 発表そのものが30分の場合

**向く場面:** 詳しい提案説明、複数部門への導入説明、事業・計画のレビュー。質疑が別枠かどうかを確認する。

Duarteは役員向けの30分枠でも、重要な発見、結論、提案、依頼を冒頭に置き、その後に根拠へ進むよう勧める。聞き手が結論を知るまで長く待つ構成を避ける。[原文](https://www.duarte.com/blog/how-to-effectively-present-to-senior-executives/)

| 時間 | 役割 | 話すこと |
| --- | --- | --- |
| 0:00〜2:00 | 結論と判断事項 | 提案、期待する成果、今日決めたいこと |
| 2:00〜6:00 | 課題と対象 | 現場、顧客、負担、優先度、対象範囲 |
| 6:00〜12:00 | 解決と利用 | 重要な場面の実演、業務・運用の変化 |
| 12:00〜17:00 | 証拠 | 顧客・実証・比較のデータと前提 |
| 17:00〜21:00 | 選択と経済性 | 代替案、市場・収益、または導入費用・便益 |
| 21:00〜25:00 | 実行とリスク | 段階、依存関係、評価方法、失敗時の対応 |
| 25:00〜28:00 | 体制と資源 | 担当、役割、人員、予算、判断の条件 |
| 28:00〜30:00 | 結論と行動 | 重要な論点の再提示、依頼、次の確認 |

**技法:** 課題・解決・証拠・実行という章を明確にし、章の終わりで分かったことを短くまとめる。主張とデータを対応させ、実演後は何を確認できたかを言う。詳しい例を増やす場合も、聞き手の判断に関係する違いを選ぶ。

**スライド:** 12〜20枚程度を作成開始の目安にする。込み入った一枚を長く読み解かせるなら分割し、単純な図や段階表示なら一分未満で進めてもよい。毎分一枚をノルマにしない。

### 面談全体が30分の場合

Techstarsは、30分の投資家面談で説明自体を約10分にする例を示す。Coralも、面談をプレゼンだけで使い切らず議論を残すよう勧める。[Techstars](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)、[Coral](https://coralcap.co/2019/07/3-mistakes-to-avoid-when-you-pitch-to-a-vc)

| 時間 | 役割 | 話すこと |
| --- | --- | --- |
| 0:00〜2:00 | 目的の合意 | 今日確認したいこと、相手の関心、時間の使い方 |
| 2:00〜10:00 | 要点の共有 | 提案・価値・強い証拠・計画・依頼を要約 |
| 10:00〜25:00 | 質疑と深掘り | 相手の疑問に沿い、補足資料や実演を使う |
| 25:00〜28:00 | 条件の整理 | 残る懸念、追加検証、関係者、判断の手順 |
| 28:00〜30:00 | 次の行動 | 誰が何をいつまでに行うかを確認 |

役員向けなら、要約をさらに短くし、判断に関係する問いを早めに扱う。営業の初回面談なら、顧客の現状を聞く時間を増やしてから、関係する提案へ進む。上表の比率をすべての会議へ固定しない。

## 長い発表で使う補足資料

本文では結論と重要な証拠を伝え、補足には数字の定義、詳細な比較、計算、導入手順、よくある質問を置く。補足の枚数を埋めるために資料を作らず、想定する質問から必要な情報を選ぶ。[Duarte](https://www.duarte.com/blog/how-to-effectively-present-to-senior-executives/)

## 10 20 30の意味

Guy Kawasakiの10/20/30は、**10枚のスライド・20分の説明・30ポイントの文字**という提案である。1分・10分・30分の分類や、30分話すという規則ではない。文字の読みやすさや説明の絞り込みを考える助言として使い、当日の会場と指定に合わせる。[Stanford GSBの講演紹介](https://www.gsb.stanford.edu/insights/10-steps-perfect-your-startup-pitch)
