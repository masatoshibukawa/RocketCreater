# 目的に応じた時間配分とピッチの練習

同じ持ち時間でも、相手に何を判断してもらうかで、使う証拠と依頼が変わる。以下は、[原資料の助言](sources.md)を資金調達・営業・社内提案へ適用した編集と練習の提案。

## 目的で強調する内容を変える

| 用途 | 相手が判断すること | 厚くする証拠 | 最後の依頼の例 |
| --- | --- | --- | --- |
| 資金調達 | 成長可能性、このチームの実行力、資金が必要な理由 | 顧客の需要、継続、収益、競争上の強み、調達後の到達点 | 次回面談、詳細な検討、懸念を確認する機会 |
| 営業提案 | 自社の課題を解けるか、導入する価値と条件 | 顧客の作業、効果、比較、価格、導入・運用の負担 | 課題確認、試験導入、対象範囲や担当者の合意 |
| 社内提案 | 戦略への適合、優先度、資源配分、実行可能性 | 現状と目標、便益と費用、代替案、担当、リスク、評価方法 | 予算・人員・検証期間の承認、条件付きの開始 |

Techstarsは、事業説明の最後の依頼が、投資家向けなら資金、メンター向けなら助言になると説明する。相手と目的に合わせて依頼を変えるという考え方を、営業や社内提案にも使う。[原文](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)

### 冒頭の型

- **資金調達:** 「私たちは［顧客］の［問題］を［方法］で改善しています。［確認できた証拠］があり、［到達目標］へ進むための調達を相談します。」
- **営業:** 「伺った［作業・状況］には［負担］があります。今回は［改善］を狙い、［範囲］での検証方法と導入条件を提案します。」
- **社内:** 「［施策］の［予算・人員・期間］を承認いただきたいです。［課題］に対し、［便益］を狙い、［評価方法］で継続を判断します。」

これらは独自に作成した型。未確認の課題や便益を事実として埋めず、必要なら仮説や検証目的として言う。

## 冒頭を結論から始めるか課題から始めるか

**意思決定者が前提を知っている場合は、結論と依頼から始める。** 特に社内の承認や役員への報告では、今回何を決めたいかを最初に置き、根拠、比較、条件へ進む。Duarteの役員向けの助言が参考になる。[原文](https://www.duarte.com/blog/how-to-effectively-present-to-senior-executives/)

**前提を知らない相手には、顧客の問題から短く理解を作る。** 誰の何を解くかを示し、解決、証拠、事業・提案が成立する理由へ進む。課題の説明だけが長くならないよう、一文の事業説明も早めに入れる。[Techstars](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)

長い創業史や一般的な市場紹介の後まで、提案や判断事項を隠さない。

## 質疑の時間と扱いを決める

Stanford GSBが紹介するKawasakiの助言には、質問を最後にまとめて説明を進める方法がある。一方、TechstarsやDuarteは対話に時間を残すことを重視する。どちらかを普遍的な正解にせず、会議の目的と相手に合わせて最初に合意する。[Stanford GSB](https://www.gsb.stanford.edu/insights/10-steps-perfect-your-startup-pitch)、[Techstars](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)、[Duarte](https://www.duarte.com/blog/how-to-effectively-present-to-senior-executives/)

| 状況 | 時間と対応の設計 |
| --- | --- |
| 1〜5分の指定された登壇 | 指定時間で完結させる。質疑が別枠か確認し、最後に依頼を残す |
| 10〜15分の説明と別枠の質疑 | 主張を最後まで通した後、比較・数字・計画を補足から答える |
| 質疑込み15分の会議 | 例えば10分説明・4分質疑・1分で次の行動。前提を知る相手なら説明をさらに短くする |
| 質疑込み30分の面談 | 例えば冒頭10分以内で要点を共有し、残りを質問・条件整理・次の行動へ使う |

質問には「結論→根拠→条件」で短く答え、必要な補足へ移る。趣旨が不明なら言い換えて確認する。分からない項目は確認して返す対象にする。重要な懸念は記録し、同じ疑問が繰り返されるなら本文を直す。[Bpifranceの質問への準備](https://bpifrance-creation.fr/encyclopedie/porteur-projet-preparation-droits-obligations/preparation/presenter-oralement-son)、[Coral](https://coralcap.co/2019/07/3-mistakes-to-avoid-when-you-pitch-to-a-vc)

## どの長さから作るか

最初に顧客・課題・解決・証拠・依頼を一枚のメモへ置き、3分版で流れを作る。その後、5〜15分版では重要な論点の根拠と実行条件を足し、1〜2分版では中心の価値と依頼を残す。Techstarsが3分版を基本として重視することを、制作の手順へ適用した方法である。[Techstars](https://www.techstars.com/blog/founder-advice/inside-week-1-a-sneak-peek-into-the-techstars-accelerator-experience)

| 短くする変更 | 削る・まとめる内容 | 残す内容 |
| --- | --- | --- |
| 30分から15分 | 二つ目の事例、細かな運用説明、重複するデータ | 結論、代表的な証拠、比較、主要な実行条件 |
| 15分から10分 | 詳細な代替案やリスクを補足へ移す | 重要な懸念への回答、資源と到達目標 |
| 10分から5分 | 市場や財務の説明を主要な主張へまとめる | 顧客、解決、証拠、成立する理由、依頼 |
| 5分から3分 | 実演を価値が分かる箇所へ短縮する | 課題から依頼までの一続きの流れ |
| 3分から2分 | 独立した章を利用場面と選ぶ理由へ統合する | 何を提供し、なぜ信用でき、何を求めるか |
| 2分から1分 | 二次的な比較や詳しい成立条件 | 対象顧客、便益、一つの根拠、次の行動 |

原稿の全文を比例して削ったり、同じ内容を速く読んだりする方法に頼らない。削る単位は文の長さより、聞き手の判断に必要な論点にする。

## 時間を測って練習する

1. **条件を確認する。** 発表と質疑の時間、スライドや動画の制限、画面の大きさ、必須の判断項目、相手の前提知識を確認する。
2. **区切りを置く。** 例えば5分なら、解決を2分までに説明し、残りで証拠と依頼へ進む。各区切りを実際の台本と対応させる。
3. **操作込みで通す。** 画面切替、デモ、動画、指示する動作も計時する。原稿の文字数だけから所要時間を決めない。
4. **初見の人に意味を確かめる。** 何をする提案か、証拠は何か、何を依頼されたかを言い直してもらう。曖昧だった見出しや図を直す。[YC](https://www.ycombinator.com/library/4T-how-to-design-a-better-pitch-deck)
5. **録画して直す。** 聞き取れる速さ、画面と発話の対応、数字や主張を理解する時間を確認する。第三者からも意見をもらう。[Seattle University](http://cms.seattleu.edu/media/seattle-university/albers-school-of-business/student-life/innovation-and-entrepreneurship-center-iec/files/HSBPC-Pitch-Outline.pdf)
6. **短縮と中断を試す。** 持ち時間が短くなった場合や、途中で質問された場合を練習する。省く部分を事前に決め、最後の依頼を残す。

MITの3分版に対する2分30秒の練習目標は、余裕を作る具体例になる。すべての発表で同じ割合を引く規則にはせず、操作や間を含む実測で決める。[MIT](https://orbit-kb.mit.edu/hc/en-us/articles/205147056-What-are-typical-pitch-durations-for-a-startup/)

## 制作用シート

| 項目 | 記入欄 |
| --- | --- |
| 相手と目的 | ［誰に、何を判断・実行してほしいか］ |
| 指定時間 | ［発表のみ／質疑込み、分数］ |
| 一文の主張 | ［対象と提案する変化］ |
| 最も強い証拠 | ［事実、対象、期間、出典］ |
| なぜ自分たちか | ［経験→判断→確認できた結果］ |
| 最後の依頼 | ［行動、担当、期限または次の機会］ |
| 時間超過時に省く部分 | ［事前に決めた事例・説明］ |
| 質疑用の補足 | ［質問と対応するページ］ |
| 実測と改善点 | ［所要時間、理解されなかった箇所、修正］ |
