# 画面・編集・音声・字幕の工夫

以下は公式の制作ガイドと実例を組み合わせた実務案。編集ソフトの購入や特定ツールの使用を前提にしない。

## 台本と絵を一緒に設計する

「話すことを完成させ、後から適当な画面を貼る」進め方では、説明と操作がずれやすい。台本とともに、開始画面、入力・クリック、変わった結果、注目箇所を並べる。TechSmithのストーリーボード教材も、画面状態と操作、ナレーション、注釈を対応させる。[G04](sources.md)

| 決めるもの | 記入する内容 |
| --- | --- |
| この場面の役割 | 見た人に何が分かるか |
| 開始状態 | 入力データ、ログイン、設定、表示位置 |
| 操作 | 価値を生む一つの変更 |
| 結果 | 何がどこで変わるか |
| ナレーション | 操作の目的、結果の読み方、意味 |
| 証拠の状態 | ライブ・録画・事前計算・モック、測定した範囲 |
| 表示と音 | 拡大、ラベル、字幕、作品の音、必要ならBGM |

## 見る場所を迷わせない

- 操作前に対象を指し、動いた後は結果へ視線を誘導する。カーソルを常に走り回らせない。
- 小さいUIは拡大・切り出しを使うが、元の画面の位置や前後関係が必要なら一度全体を見せる。
- ズームは「重要そうに見せる」ためだけに繰り返さず、入力欄、比較箇所、検査結果などの意味を持たせる。
- 強調色に加えて名称・記号を使う。字幕や顔の小窓で、結果や主要操作を隠さない。
- 複数人・複数端末なら、誰がどこを変え、どこに反映したかを並べる。Figmaのカーソル名や端末撮影が参考になる。[C01](sources.md)
- 身体操作では、操作する人と利用者が見る結果を両方示す。Appleの例を参考にしても、再現イメージと実際の画面収録を同一に扱わない。[C02](sources.md)

文字は編集画面の大きさだけで判断しない。提出先のプレイヤーサイズで、入力、単位、注釈、結果が読めるか確かめる。W3Cも、視覚情報の説明、十分なコントラスト、情報を処理する時間を重視する。[G05](sources.md)

## カットで理解を助け、実行条件を保つ

入力待ちや長い処理を省くことはできるが、省略が主張を変えないようにする。

| 編集 | 表示・記録すること |
| --- | --- |
| 処理を倍速にする | 倍速である箇所、性能を述べるなら実測時間と条件 |
| 前後を切ってつなぐ | 同じ入力・実行・成果物か。省略区間で何が起きたか |
| 事前の結果へ切り替える | 事前実行した記録であること、入力と版 |
| 別の例を見せる | 入力やシナリオが変わったこと |
| 想定画面を挿入する | モック・構想・説明図であること |
| 画面を追従させる | 製品内の移動か編集上の拡大か、重要な文脈が失われないか |

少数の成功場面をつなぐ編集と、代表的な条件での評価を分ける。AIが生成していない文を、出力字幕として付けない。モデル名を大きく出すより、実際の入力、道具の結果、判断の変化を対応させる。

## ナレーションは、ボタン名より目的と結果を話す

「ここをクリックします」に加え、「何を確かめるための操作か」「結果のどこを見るか」を伝える。説明を詰めるための全編高速化は避け、文を短くして不要な詳細を外す。

声を同時に録る方法と、画面を録って後から声を合わせる方法の両方がある。前者は操作との自然な対応、後者は文の整理や録り直しがしやすい。後録りでも、映像にない動作や成果を説明に足さない。[G03・G07](sources.md)

## 音楽と効果音

発話と必要な製品音を先に聞き取りやすくし、BGMは役割がある場合に加える。場面の導入、切替、雰囲気など、何に使うかを決める。作品の音を示す場面では、その音自体を証拠として聞けるようにする。

大きな音で機能を強そうに見せても、結果の根拠にはならない。W3Cの低い背景音への助言は理解を助ける制作上の参照とし、特定の音量差をすべてのデモ動画の法的義務にはしない。[G05](sources.md) BGMに関する学習研究の条件差は [既存の整理](../research/2026-11-06/04-demo-video-and-audio.md) を参照する。

今回、取得した8ファイルのうち7ファイルには音声トラックがなかった。Appleのgestures版にはトラックがあるが、聴取による音楽・声の分析は行っていない。この結果をYouTube版や長編の音設計へ一般化しない。

## 字幕とアクセシビリティ

同言語字幕、翻訳字幕、注目点の短いラベルを区別する。字幕は発話・必要な音情報と同期させ、専門語、否定、数値、単位を人が確認する。自動字幕があるだけで完成としない。[G06](sources.md)

日本語3分動画なら、台本を日本語で一度声に出し、画面の情報量と一緒に調整する。日英の長文を同時に焼き込む前に、字幕トラックや短い用語表示を検討する。発音の印象より、入力・結果・比較条件を正しく言い直せるかで理解を確かめる。
