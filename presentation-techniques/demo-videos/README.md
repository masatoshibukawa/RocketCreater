デモは「何をできるか」を説明するだけでなく、**入力・操作・変化・成果を、初見の人が確かめられる順に見せる**。広告、審査、導入説明、技術検証では必要な証拠が違う。Devpostは審査用に画面収録とナレーションを勧め、YCも創業者の応募動画と製品デモを区別している。[G01・G02](sources.md)

## 今回の確認方法

Figmaの4短編、Appleの2短編、Atlasの1短編、Googleのタイマー1短編について、公式ページが参照する公開ファイルを取得し、1〜2秒間隔のフレームとメタデータを確認した。**4事例群・8ファイルの画面観察**であり、8本の長編動画を音声付きで通して視聴したという意味ではない。原映像と抽出画像は資料集へ再配布せず、URL・ハッシュ・観察範囲を記録する。

AnthropicとNintendoの2事例は公式説明に基づく。映像の全編・字幕は取得しておらず、カット順、声色、BGMを観察済みとはしない。ブラウザ再生は環境設定で利用できなかった。長時間調査ツールも認証が完了せず、公開ページの直接調査と取得できた映像の分析へ切り替えた。

## 比較して分かったこと

| 事例 | 学べる見せ方 | 今回の確認 |
| --- | --- | --- |
| Figma Multiplayer／2016 | 名前付きカーソルと別端末で、共有状態を見えるものにする | 4短編のフレーム＋公式解説 |
| Apple Vision Pro／2023 | 操作する身体と、利用者が見る結果を対応させる | 2短編のフレーム＋公式説明 |
| All New Atlas／2024 | 一つの意外な動作を、広い画面で理解させる | 公式配布23秒版のフレーム |
| Geminiのタイマー生成／2023 | 生成コードの説明から、動く成果物へ進む | 14.56秒の結果映像＋入力の公式解説 |
| Claude Computer Use／2024 | 複数の道具を利用者の一つの目的でつなぐ | 公式説明。編集・音声は未確認 |
| Nintendo Switch初公開／2016 | 一つの価値を、場所・人数・操作形態の変化で展開する | 当時の公式発表。映像のカット順は未確認 |
