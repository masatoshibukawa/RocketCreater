# 話し方と練習と質疑応答

## 話し方を情報の構造に合わせる

話の切り替わり、結論、数字の意味を声でも明示する。Stanfordのガイドは、聞き手が構成を追えるように、移行表現や内部の要約を使うことを勧めている。[S06](https://oralcommprogram.stanford.edu/presentation-and-delivery/paper-presentation)

次は制作で試す方法。

- 一文に詰める情報を減らし、主語と判断を明確にする。
- 数字を言う前に、何の値かを伝える。
- 結論を述べた後は、図を見る間を残す。
- 見せる場所、説明する場所、強調する言葉をそろえる。
- 時間が超過したら、説明を整理して削る。全編を早口にしない。

すべての人に最適な話速を一つの値で決めない。専門用語、聴衆の言語習熟度、字幕、図の複雑さで必要な時間が変わる。

## 声と身体と視線

TEDのガイドは、時計を使った練習、異なる聴衆からのフィードバック、本番に近い環境でのリハーサルを勧める。身体の動きも、目的なく歩き続ける癖などを他者に確認してもらう。[S09](https://storage.ted.com/tedx/manuals/tedx_speaker_guide.pdf)

会場では、画面を隠さない立ち位置と、マイクから外れない顔の向きを確かめる。オンラインでは、声の明瞭さ、画面共有、ポインタ、通知、操作担当との受け渡しを一緒に練習する。指示語だけで済ませず、対象を言葉でも特定する。

## 練習を分ける

次の手順は、実務ガイドを制作へ適用したもの。反復回数を目標にせず、各回で一つの問題を直す。

| 練習 | 確認すること | 修正するもの |
| --- | --- | --- |
| 音声だけを録る | 何をする製品か、話の順序、長い文、語尾 | 台本、文の分割、つなぎ |
| 無音で映像を見る | 操作と結果が追えるか、重要な文字が読めるか | 拡大率、字幕、強調 |
| 初見の人に見せる | 主張と証拠を言い直せるか | 前提説明、順序、不要な情報 |
| 時間を測って通す | 操作、間、交代を含めて収まるか | 削る箇所と短縮ルート |
| 途中から再開する | 言葉を忘れても次の主張へ戻れるか | 要点メモ、復帰の文 |
| 本番環境で通す | 解像度、音、認証、共有画面、入力 | 機材と操作手順 |

PLOSの実務的な論説も、聴衆に合わせること、内容を詰めすぎないこと、練習、時間と論理を重視する。ただし「質問がないから失敗」といった個別の強い表現まで、全発表の判定基準にしない。[S08](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.0030077)

## 質疑応答を準備する

MITは、判断の理由や代替案について聴衆から出そうな質問を、資料作成中に考えることを勧める。[S05](https://mitcommlab.mit.edu/meche/commkit/technical-presentation/)

回答は次の順で練習する。

1. 最後まで聞き、質問が曖昧なら対象を確認する。
2. 最初に短い答えを示す。
3. 根拠となるデータ、実装、制約を一つ説明する。
4. 未確認の範囲があれば、その範囲と確かめ方を示して終える。

| 質問の種類 | 用意する内容 |
| --- | --- |
| なぜAIが必要か | LLMを外した場合、固定処理や手作業との比較 |
| なぜこのモデルか | 実際に必要な能力、比較の有無、選択の制約 |
| 結果を信用できるか | 評価条件、出典、再現方法、失敗例 |
| どこまで動くか | 完了した範囲、モック、未実装の境界 |
| 誰が使うか | 利用者の作業、接点、検証予定 |
| なぜ自分たちか | ドメインの経験が変えた設計や検証 |

補足スライドには、比較条件、評価方法、構成図、限界などを置く。質問を誘うために本編へ意図的な説明不足を残さない。東京大学のメモも、その手法は想定した質問が来ないことや、質疑時間を消費する問題を指摘している。[S38](https://www.graco.c.u-tokyo.ac.jp/labs/morihata/presentation_memo.htm)

## チームで発表する場合

発表者、操作担当、質問を受ける担当を決める。交代は話題の区切りに置き、全員が同じ説明を繰り返さない。短い発表では一人が主に話し、他の人が操作と専門的な質疑を担う案も試す。担当配分が大会要項に指定されている場合は、その条件を優先する。

## 有名な数値の扱い

Mehrabian本人は、7・38・55の比率が感情や態度の伝達を扱った実験に由来し、それ以外の通信へ適用できないと説明している。「内容は7%しか重要でない」という一般則には使わない。[S29](https://kaaj.com/psych/smorder.html)

Kawasakiの10枚・20分・30ポイントという指針は、投資家への説明を簡潔にするための実務的なルールとして読む。3分のハッカソンや詳細な学術発表で、枚数と時間をそのまま採用しない。[S30](https://guykawasaki.com/the_102030_rule/)
