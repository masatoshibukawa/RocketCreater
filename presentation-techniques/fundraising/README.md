# スタートアップの資金調達ピッチ

確認日: 2026-11-06

資金調達のピッチでは、顧客の問題、事業の成長可能性、そのチームが実現できる理由、資金で到達する成果を、一続きの説明にする。大きな構想を示すときも、現時点の実績、検証中の仮説、将来の目標を分ける。

英語、日本語、中国語、韓国語、フランス語、スペイン語の原語資料15件を比較した。VC、投資実務家、公的な起業支援機関による助言を中心に、資金調達の投資家面談を扱う。融資、補助金、営業、ハッカソンの審査では、目的と必要な証拠が変わる。

## 先に押さえること

1. **冒頭で事業を理解できるようにする。** 誰の何を、どう改善する会社なのかを一文で伝える。機能の一覧や長い創業史から始めない。[Sequoia](https://articles.sequoiacap.com/writing-a-business-plan)、[YCのメールの助言](https://www.ycombinator.com/blog/how-to-cold-email-investors-michael-seibel)
2. **大きな構想を、顧客と数字で支える。** 市場の総額に加え、最初に売る顧客、単価、顧客獲得方法を示す。実績の数字には期間・対象・定義を付ける。[Coralの市場規模の解説](https://coralcap.co/2018/05/how-to-create-a-defensible-market-size)、[INCIBEのガイド](https://www.incibe.es/sites/default/files/Emprendimiento/Guia%20r%C3%A1pida%20para%20elaborar%20tu%20pitch%20deck/INCIBE%20-%20GUIA-ES-4%20-%20Gu%C3%ADa%20r%C3%A1pida%20para%20elaborar%20tu%20Pitch%20Deck.pdf)
3. **なぜ自分たちが作れるかを、判断と行動で示す。** 業界知識、顧客へのアクセス、技術、過去の検証が、競合との差や実装にどう効くかを説明する。[Sequoia](https://articles.sequoiacap.com/writing-a-business-plan)、[BLTのIR構成](https://blt.kr/column?bmode=view&idx=11155144)
4. **調達額を達成目標へ結び付ける。** 必要な人員・開発・販売の費用と、資金で何を検証し、どの状態に到達するかを対応させる。[YCのシード調達ガイド](https://www.ycombinator.com/library/4A-a-guide-to-seed-fundraising)、[Bpifranceの構成案](https://bpifrance-creation.fr/encyclopedie/porteur-projet-preparation-droits-obligations/preparation/plan-type-pitch-presenter)
5. **面談を対話として設計する。** 説明で時間を使い切らず、投資家の懸念を聞く。最後に追加資料・次回面談などの次の行動を合意する。[Coralの面談の助言](https://coralcap.co/2019/07/3-mistakes-to-avoid-when-you-pitch-to-a-vc)、[YC](https://www.ycombinator.com/library/4A-a-guide-to-seed-fundraising)

## 言語ごとの調査

- [6言語の助言と使い分け](02-language-and-context.md) — 原語の検索語、資料ごとの重点、言語と文化を混同しない比較、翻訳時の確認
- [15件の出典と適用範囲](sources.md) — 原著のURL、支持する主張、古い数値や一般化の扱い

国別の性格を推定するより、相手の投資対象・専門性・検討段階と、送付用か登壇用かを先に確かめる。同じ言語でも、短時間の登壇と、社内で回覧される資料では情報量が異なる。
