# 資金調達ピッチの練習と面談のテンプレート

以下は[原語資料](sources.md)の助言を実行するための台本・準備用の型。時間配分と例文は独自に作成したもので、特定の投資家の指定ではない。［ ］には確認できる自社の情報を入れる。

## 60秒の紹介

| 時間 | 内容 |
| --- | --- |
| 0〜10秒 | ［会社］は［顧客］の［課題］を［方法］で改善します。 |
| 10〜25秒 | 現在は［対処方法］に［負担］があります。私たちは［変化する作業・成果］を提供します。 |
| 25〜40秒 | ［期間・対象・定義付きの実績、または需要・技術の検証］が得られています。 |
| 40〜50秒 | ［事業機会を作る変化］があり、私たちの［経験・技術・接点］が［判断や実装］に効いています。 |
| 50〜60秒 | ［額］を調達し、［期限と到達目標］を目指します。今回は［次の具体的な依頼］を相談したいです。 |

実績がない段階では、検証中の仮説と次の試験を伝える。長い経緯や略語を削り、何をする会社かが残るようにする。[YCの初回連絡の助言](https://www.ycombinator.com/blog/how-to-cold-email-investors-michael-seibel)

## 3分の登壇

| 時間 | 内容 |
| --- | --- |
| 0〜20秒 | 対象顧客と、一文の事業説明 |
| 20〜45秒 | 課題が起きる場面と、現在の対処 |
| 45〜80秒 | 解決の仕組みと、短い実演または結果 |
| 80〜110秒 | 需要・利用・売上・技術等の強い証拠 |
| 110〜140秒 | 最初の市場、価格、どう顧客へ届けるか |
| 140〜160秒 | チームの経験と実装・顧客理解の関係 |
| 160〜180秒 | 資金で達成する成果と、次の行動 |

競合やWhy nowは、課題・市場・チームの説明と関係する箇所に組み込む。投資家面談へ進んだときに詳しく答えられる資料を用意する。短い登壇で何を覚えてもらうかを先に決める。[YCのDemo Day向け解説](https://www.ycombinator.com/library/4T-how-to-design-a-better-pitch-deck)

## 10分の説明

| 時間 | 内容 |
| --- | --- |
| 0:00〜0:40 | 会社と中心の主張 |
| 0:40〜1:40 | 顧客、課題、現在の対処 |
| 1:40〜3:00 | 解決、実演、今取り組む理由 |
| 3:00〜4:30 | 需要と実績、数字の意味 |
| 4:30〜5:30 | 初期市場と拡張の余地 |
| 5:30〜6:30 | 事業モデルと顧客獲得 |
| 6:30〜7:30 | 競合、代替、優位性 |
| 7:30〜8:15 | チームと不足する役割 |
| 8:15〜9:30 | 財務、調達額、使途、到達目標 |
| 9:30〜10:00 | 中心の論点と次の行動 |

30分の面談なら、例えば10分の説明と20分の対話を予定し、冒頭で相手と確認する。質問が出たら該当する証拠へ移り、台本を最後まで読み終えることに固執しない。Coralは、説明で面談を使い切らず議論の時間を確保するよう勧めている。[原文](https://coralcap.co/2019/07/3-mistakes-to-avoid-when-you-pitch-to-a-vc)

## 話し方とスライドを直す

**一枚の見出しを主張にする。** 「トラクション」だけでなく「［期間］に［定義した指標］が［実数］へ増えた」のように、そのページで分かることを書く。図表は主張を支えるものを選び、グラフの軸・単位・対象を読める大きさにする。[KVIC](http://kvicnewsletter.co.kr/page/newsletter/vol58/html/06.html)

**短い文で話し、複雑さは質問に応じて足す。** 顧客の例を一つ示し、技術用語の前に何が変わるかを説明する。事業を知らない人に、スライドの意味を言い直してもらう。録画では聞き取りやすさ、数字を示すタイミング、オンラインの音・画角も確認する。[YC](https://www.ycombinator.com/library/4T-how-to-design-a-better-pitch-deck)、[Bpifrance Le Hub](https://lehub.bpifrance.fr/prise-de-parole-en-public-lart-de-pitcher/)

**確信と仮説を言い分ける。** 「確認したこと」「そう考える根拠」「まだ試す必要があること」を明確にする。質問への答えは、結論、証拠、条件の順に短く話す。不明な数字をその場で作らず、確認して返す項目にする。[YCの面談の助言](https://www.ycombinator.com/library/4A-a-guide-to-seed-fundraising)

## 想定質問と用意する証拠

| 質問 | 先に答えること | 補足する証拠 |
| --- | --- | --- |
| 誰が本当に困っているのか | 顧客と具体的な利用場面 | 観察、聞き取り、現在の費用や手順 |
| 誰がいくら払うのか | 利用者と支払者、価格の単位 | 有料契約、購入の試験、価格検証 |
| なぜ今なのか | 機会を作る具体的な変化 | 日付と出典、費用・行動・制度等の変化 |
| なぜ既存の方法では足りないのか | 顧客に重要な差 | 同じ条件での比較、顧客が選ぶ理由 |
| 市場は十分か | 顧客像と積み上げた範囲 | 顧客数・単価の根拠、初期市場と拡張 |
| 継続して使われるのか | どの顧客群がどう使い続けるか | 対象数と期間を含む継続・再利用のデータ |
| 顧客をどう増やすのか | 検証した経路と未検証の経路 | 営業の流れ、費用、期間、転換率の母数 |
| なぜこのチームなのか | 課題に関係する能力と行動 | 経験が変えた設計、検証結果、役割分担 |
| モデル事業者や競合が同じ機能を出したらどうするか | 顧客が自社を使う理由と残るリスク | 業務統合・評価・顧客接点等の実在する強み |
| お金は何に必要なのか | 使途、期限、到達目標 | 月次の資金計画と採用・開発・販売の対応 |
| 計画どおりに進まなかったらどうするか | 主要な不確実性と対応 | 小さく試す手順、支出調整、代替案 |

需要、チーム、競合、資金使途などはPlataforma ONEでも段階別の質問として整理されている。表のAIに関する質問は、それを今回の事業へ適用したもの。[原文](https://one.gob.es/es/contenidos/buscas-financiacion-trucos-para-acercarte-potenciales-organismos-inversores)

見送られた場合は、どこが懸念だったか、何が変われば再検討できるかを聞く。すべての助言を採用する必要はないが、理由を記録すると次の検証と説明の改善につながる。[Coral](https://coralcap.co/2019/07/3-mistakes-to-avoid-when-you-pitch-to-a-vc)

## 初回の連絡

次は独自に作成した例文。短く読み取れる事業・証拠・チームと、具体的な依頼を置く。相手に連絡する理由は、実際の投資方針や関心と結び付ける。[YC](https://www.ycombinator.com/blog/how-to-cold-email-investors-michael-seibel)

> 件名: ［会社名］｜［顧客と改善すること］｜［調達段階］
>
> ［氏名］様。［会社名］の［名前］です。私たちは［顧客］向けに［課題をどう改善するか］を提供しています。［期間・対象付きの事実］を確認しています。創業チームの［関係する経験］を活かし、［目標］に向けて資金調達を進めています。［相手に連絡した具体的な理由］から、ご関心を伺いたくご連絡しました。概要は［資料リンク］です。［短いオンライン面談など、次の依頼］をご相談できますでしょうか。

> Subject: ［Company］ — ［customer outcome］ — ［round］
>
> Hi ［Name］, I'm ［founder］ at ［company］. We help ［customer］ achieve ［outcome］ through ［solution］. We have ［verified evidence with timeframe］. Our team brings ［relevant experience］, and we're raising to reach ［milestone］. I'm reaching out because ［specific fit with this investor］. Here's a short overview: ［link］. Would you be open to ［specific next step］?

## 面談後の連絡

面談で合意したタイミングに、未回答の質問、依頼された資料、次の行動を返す。返信がないときも、短期間に催促を重ねず、新しい事実や明確な依頼があるかを確認する。開封や好意的なコメントを出資の合意と扱わない。[YCのメールの助言](https://www.ycombinator.com/blog/how-to-cold-email-investors-michael-seibel)、[YCの調達ガイド](https://www.ycombinator.com/library/4A-a-guide-to-seed-fundraising)

> 本日はありがとうございました。確認事項の［質問］について、［回答と根拠］を共有します。ご依頼の［資料］はこちらです。［未回答項目］は［合意した期限］にお送りします。次は［目的］のために［相手・方法・日程］を調整する、という理解でおります。

## 制作と改善の手順

1. **事実を集める。** 顧客、問題、実績、費用、チーム、調達計画を列挙し、各数字の出典・定義・確認日を付ける。
2. **一文と中心の主張を決める。** 誰に何を提供するか、なぜ大きくできるか、なぜ自分たちかを短く書く。
3. **見出しだけで流れを作る。** 各ページの見出しを順に読み、主張と証拠のつながりを確認する。
4. **送付用を作り、登壇用を調整する。** 同じ事実と数値を使い、送付用は自立した説明、登壇用は一目で分かる表示にする。
5. **初見の人に試す。** 事業・需要の証拠・優位性・資金の使途を言い直してもらい、分からなかった箇所を直す。
6. **時間と質疑を練習する。** 時間を測り、途中で質問されても答えた後に主張へ戻れるか試す。長いときは内容を減らす。
7. **面談ごとに更新する。** 質問と懸念を記録し、同じ疑問が続く箇所の本文か補足を改善する。共有した版と基準日を管理する。

| 面談の記録 | 内容 |
| --- | --- |
| 投資家と検討段階 | ［名前・関心・意思決定までの手順］ |
| 伝わった主張 | ［相手の言葉で確認できたこと］ |
| 懸念と未回答 | ［質問・必要な追加検証］ |
| 次の行動 | ［担当者・資料・期限・次回の目的］ |
