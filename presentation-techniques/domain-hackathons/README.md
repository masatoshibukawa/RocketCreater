# LLM事業者と専門分野のハッカソン

確認日: 2026-11-07。

Anthropic主催の大会と、ソフトウェア以外の専門知識を持つ人を集める大会を比較する。募集の狙い、提出物、審査、受賞作品を手掛かりに、専門知識とLLMの価値を実演する方法を整理する。

今回の日本大会は、深く知る世界の課題と、専門能力へのアクセスをテーマにしている。提供された参加者ガイドの配点は、インパクト30％、デモ25％、Claude活用25％、深さと実行20％。実際の動作を中心にした日本語3分以内の動画が必要になる。[D01・U01・U02](sources.md)

10の開催回・版の比較、25作品の事例、37件の公開出典と3件の提供資料を整理した。25作品のうち22件は公式受賞表示を確認し、生命科学の追加3件は公式Finalist表示と本人報告を区別している。10件には開催前の募集も含む。

調査から重視するのは、**自分たちの経験 → 特有の課題・判断基準 → Claudeで可能になった処理 → 利用者が得る結果 → 検証**のつながりである。「APIを呼んだ」「非エンジニアが作った」という属性だけでは、このつながりを説明できない。

大会の明文条件、主催者・作者の説明、こちらの提案を区別する。受賞作品だけの比較では勝因の因果関係や勝率を算出できない。今回の日本大会は確認日時点で結果発表前であり、過去の別大会の受賞例を参照する。

一般的な実演・収録方法は[ソフトウェアハッカソンのデモ発表](../hackathon-demos/README.md)、チームの発表方針は[ピッチとデモの方針](../pitch-demo-strategy.md)を参照する。
