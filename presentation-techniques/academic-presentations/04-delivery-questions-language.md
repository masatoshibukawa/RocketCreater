# 話し方・質疑・言語

## 図が変わったら、読む入口を作る

新しい図に切り替えた直後から結果を早口で説明すると、聞き手は軸・条件を探しながら話も追うことになる。制作と練習では次の順を試す。

1. 「ここでは［問い］を確かめます」
2. 「横軸は［対象・単位］、縦軸は［指標・単位］です」
3. 「比較しているのは［条件］です」
4. 「注目してほしいのは［差・傾向・例外］です」
5. 「この結果から［範囲付きの結論］と言えます」

全ての図で機械的に5文を読む必要はない。前の図と共通の軸なら簡潔に済ませ、変わった条件を強調する。発表の役割が図の解読支援になるようにする。[S01・F01](sources.md)

重要な結果の前後に間を置く。指示語だけで「これがこうなる」と済ませず、対象と変化を言葉にする。式や複雑な図では、何を見ればよいかを指してから説明する。

## 質疑は、問い・答え・根拠を対応させる

UChileのガイドは、質問を聞き、確認し、中心の答えを根拠で支えること、分からない点と今後の調べ方を説明することを勧める。[S13](sources.md)

| 状況 | 応答の型 |
| --- | --- |
| 質問を聞き取れなかった | 「［部分］をもう一度お願いできますか」 |
| 問いの範囲が曖昧 | 「［条件A］の場合についてのご質問でしょうか」 |
| 根拠がある | 「この条件では［答え］です。根拠は［図・解析］です」 |
| 別解釈を指摘された | 「その可能性は残ります。今回区別できたのは［範囲］です」 |
| 未検証 | 「その条件は試していません。確認するには［比較・追加資料］が必要です」 |
| 誤りに気付いた | 「その点は訂正します。影響する結論は［範囲］です」 |
| 複数の質問 | 要点を控え、答える順序を伝えて一つずつ回答する |

長く話すことより、質問に直接答えたかを確かめる。補足図を開く時は、その図で何を示すのかを先に述べる。質問がないことだけで、理解されなかった、あるいは完璧だったと決めない。

## 補足資料を作る

主要な主張ごとに、選んだ方法、比較の公平性、仮定、感度、失敗例、追加条件、関連研究を索引にする。共同研究では個人の担当と引用を明確にする。補足を増やすこと自体を目的にせず、想定質問へ辿れるようにする。

## 英語発表と多言語の聴衆

Amanoほかは環境科学の研究者908人への調査で、非母語話者の英語での準備・発信負担を報告している。自己申告を含む調査で、全分野の個人へ同じ負担を当てはめるものではない。[R03](sources.md)

ここからの実務上の提案は、原稿の語数を固定するより、図の説明、切替、質疑も含めた練習時間を確保することである。専門語、固有名詞、数字・単位の発音を先に確認し、短い文と一貫した用語を使う。

| 役割 | 英語の短い型 |
| --- | --- |
| 問い | “We ask whether …” |
| 比較条件 | “We compared … under the same …” |
| 範囲付きの結果 | “Under these conditions, we observed …” |
| 解釈 | “These results suggest …” |
| 未検証 | “We have not tested that condition.” |
| 確認 | “Could you clarify what you mean by …?” |

これらは文を組み立てる例であり、引用文ではない。suggestを使えば根拠の不足が解消するわけではないため、主張そのものの範囲を調整する。

日本語なら結論を最後、英語なら最初、と国や言語で固定しない。聴衆の専門性、時間、制度、目的を確かめる。日本語の専門内発表、英語の隣接分野向け発表、フランス語の一般向け競技では、説明すべき前提が違う。[S01・S02・S16](sources.md)

## アクセシビリティと遠隔発表

ACSのガイドを参考に、色に加えて記号・直接ラベルを使い、重要な図の内容を口頭でも説明する。配布版の画像説明、録画の字幕も検討する。自動字幕は専門語、否定、数字を確認する。[S15](sources.md)

遠隔では、実際の共有画面で文字が読めるか、音声、動画、数式、ポインター、補足への移動を試す。対話の取り方も冒頭で共有するとよい。話し手が見る画面と、聴衆が受け取る画面が同じとは限らない。[S14](sources.md)

研究室の対話、学会の質疑、学位審査で割込みの扱いは異なる。「途中の質問は最後まで待つ」と一律に決めず、その場の進行に合わせる。
