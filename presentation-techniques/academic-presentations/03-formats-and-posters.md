# 発表形式ごとの設計

## 学会口頭発表

本編には、問い、既存研究との差、主要な根拠、答え、適用範囲を置く。関連研究を網羅するより、何と比較してどこが新しいかを理解するための資料を選ぶ。方法の新規性が中心なら、仕組みの説明にも十分な時間を置く。

質疑の扱い、入替時間、ファイル形式、動画・音声の許可、提出期限は開催回の案内で確認する。発表枠が15分でも、本編15分なのか、質疑込みなのかで台本は変わる。

## 研究室の進捗報告

完成した物語より、次の判断に必要な情報を優先する。以下は進捗報告用の提案である。

| 項目 | 話すこと |
| --- | --- |
| 今回の問い | 前回から何を確かめようとしたか |
| 試したこと | 条件、方法、変えた点 |
| 得られたこと | 成功・失敗・予想外の結果、比較に使える根拠 |
| 未確定のこと | 原因候補と、まだ切り分けられない点 |
| 次の判断 | 次にする比較、必要な協力、助言が欲しい点 |

「うまくいかなかった」だけでなく、何が起きればどの仮説を疑うかを示す。装置、コード、解析を相談する時は、結果だけでなく再現条件を持ってくる。[S01・S02](sources.md)

## 論文紹介・ジャーナルクラブ

UVAのガイドは、中心的な主張を理解し、それを支える重要な実験を選び、議論を進める役割を重視する。[S09](sources.md)

各主要図について、次の4点を準備する。

1. 著者は何を確かめようとしたか。
2. 何を比較し、何が見えたか。
3. どの結論が支持され、何はまだ言えないか。
4. 自分ならどの別説明・追加検証を検討するか。

背景知識の説明と、論文の批判的評価を分ける。追加解析を自分で行った場合は、元論文の結果として提示しない。全図の紹介や読み上げに時間を使い切らず、重要な問いを議論する余白を取る。

## ポスターは、入口と深掘りを同居させる

Erren・BourneとMITのガイドは、ポスターを対話の入口と位置付ける。[S05・S06](sources.md) 下の階層は制作案であり、固定のレイアウト規則ではない。

| 読む深さ | 見つけられる内容 |
| --- | --- |
| 通りがかり | 何の問いに対して何が分かったか |
| 立ち止まる | 主結果の図と、重要な比較・条件 |
| 議論する | 方法、例外、不確実性、次の検証、関連研究 |

口頭では20〜30秒程度の入口を練習し、相手の関心に応じて図へ進む。これはMITの短いピッチという助言に基づく目安である。全員へ長い説明を最初から押し付けない。

不在でも、主要図の対象と結論が読めるようにする。連絡先や論文・データへのリンクを付ける場合も、QRコードだけで本体の意味が分からなくならないようにする。サイズ、縦横、印刷、電子版の条件は学会指定に従う。

## 学位審査・研究資格審査

研究内容に加えて、なぜその方法を選び、どこが限界で、自分が何を担ったかを説明する準備が必要になる。MIT EECSのRQEガイドは技術質問と補足資料、委員の期待の確認を重視する。その30分＋質疑30分という案内は当該ガイドのもので、博士審査全体の規則ではない。[S10](sources.md)

TUM NATでは公開・非公開部分や言語の確認を求める。UChileとNavarraの教材でも時間・進行の説明は異なる。[S11・S12・S19](sources.md) 「海外の学位審査はこう進む」と一括りにせず、自分の所属先の正式要件と審査者への案内を確認する。

## 3MT・MT180は、通常の研究講演と分ける

| 形式 | 今回確認した条件・評価 |
| --- | --- |
| UQ 3MT | 3分以内、静止1枚、追加音声・動画・小道具なし。理解・内容と関心・伝達を等しく評価。[S07・S08](sources.md) |
| MT180 France 2026版 | 180秒、フランス語、図中文字もフランス語、静止1枚、音声動画なし。ノートやレーザーポインターも認めない。[S16](sources.md) |

専門外の人が、問い、研究の工夫、意味を理解できる一つの説明を作る。長い講演を高速再生するような台本にしない。一般向けに言い換える時も、結果が出ていない段階を「解決した」としない。

3分という長さが同じでも、[Claude日本大会の動作デモ](../domain-hackathons/01-japan-and-chat.md)とは媒体の条件が異なる。3MTの静止1枚を、動画デモの指定へ持ち込まない。

## 研究費ピッチと研究成果発表

研究費ではこれから行う研究の価値と実行可能性、成果発表では既に得た結果と根拠が中心となる。研究費ピッチでは予備データと計画を区別し、審査者の専門性に合わせて説明する。[S18](sources.md)
