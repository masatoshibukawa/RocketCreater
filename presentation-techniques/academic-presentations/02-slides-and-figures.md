# スライドと科学図表

## 見出しに、図が答える問いを置く

「結果1」だけでなく、その図から言えることを見出しにすると、聞き手が注目する点を絞れる。まだ結論が出ていない図には、答えを作らず問いを置く。[S04](sources.md)

| 曖昧な見出し | 改善する方向の例 |
| --- | --- |
| 評価結果 | 対象条件で誤差が減ったが、外部条件では差が残る |
| 新手法 | 検証結果を次の候補選択に戻す |
| 考察 | 改善は観測されたが、その原因は切り分けられていない |
| 進捗 | 外れ値の原因を、測定と前処理に分けて調べる |

上記は説明用の例で、実在の測定結果ではない。見出しを強くするために、因果、一般化、精度をデータ以上に強くしない。

## 主張と視覚的な根拠の実験は、どこまで言えるか

Garner・Alleyの2013年研究は工学系学部生110人を無作為に2群へ分け、同じMRIのナレーションを異なるスライドで提示した。主張と視覚的根拠を組み合わせた群では、理解を記述する課題や遅延課題で良い成績が得られた。一方、即時の選択式テスト全体では有意な群差がなかった。[R01](sources.md)

見出し、図、本文量などを一緒に変えており、見出しだけの効果は分離していない。学生が技術的な仕組みを学ぶ条件の結果を、あらゆる専門学会、審査、発表者の評価へ一般化しない。

Kosslynほかの3研究は、スライド上の問題、経験した不満、問題の識別を扱う。好まれること、問題に気付けること、理解できることは別の評価である。[R02](sources.md) 資料の改善でも、見栄えの感想だけでなく、聞き手が問い・結果・限界を言い直せるか確かめる。

## 論文図を投影用に作り替える

図は媒体によって見方が変わる。論文の小さな多面図をそのまま貼ると、口頭説明を聞きながら短時間で読むのが難しくなる。[F01](sources.md)

制作では次の順に検討する。

1. この図で判断してほしい一点を決める。
2. その判断に必要な対象、対照、軸、条件を残す。
3. パネルが多ければ段階的に説明し、最後に関係を戻す。
4. 視線を誘導する注釈・直接ラベルを付ける。
5. 分割・拡大しても、元の条件や比較を読み違えないか確認する。

不要な装飾と、必要な反例・ばらつきは違う。簡潔にするために不利な条件だけを消さない。詳細な元図と解析手順は補足へ置く。

## データの構造が分かる表示

| データ・主張 | 表示で確認すること |
| --- | --- |
| 独立した2群 | 各群の対象、件数、分布、何を比較したか |
| 同じ対象の前後 | 対応関係と各対象の変化が見えるか |
| 実験を繰り返したデータ | 個々の観測と独立した実験の単位が区別できるか |
| 時系列 | 時間の単位、間隔、欠測、介入や条件変更の位置 |
| 推定値・モデル | 推定・実測・予測の区別、対象外の条件、誤差の意味 |
| 画像・顕微鏡・地図 | スケール、色の意味、前処理、選んだ範囲 |
| 定性研究 | 出典と文脈、抽出方法、解釈を支える事例と異なる事例 |

平均と誤差棒が似ていても、分布や対応関係が違う場合がある。[F04](sources.md) 棒グラフを一律に禁止するのではなく、今回の判断に必要な情報が見える図を選ぶ。

誤差棒にはSD、SE、CI等があり、役割が異なる。種類と独立した標本の単位を記す。[F02](sources.md) SuperPlotsは、細胞ごとの値と実験間のばらつきを一緒に表す例である。多数の点を描いたことだけで、その全てを独立した実験と数えられるわけではない。[F03](sources.md)

## 数式・アルゴリズム・複雑な装置

本編では、この式や処理が何を決めるかを先に伝える。記号、入力と出力、変えた点、重要な仮定を対応させる。全導出を見せる必要がある場合は、変形の理由を段階ごとに説明する。

装置図や処理図も、部品名・箱の数を読ませるより、入力がどこで変化し、どこを測るかを示す。矢印が因果、時間順、情報の流れのどれを表すか曖昧にしない。

## 画面と配布資料で読みやすさを確かめる

ACSは、色だけに意味を持たせず、記号や文字を組み合わせること、明瞭な文、字幕や画像説明を勧める。[S15](sources.md) 会場では後方から、遠隔では小さな共有画面で、凡例・数値・出典を読めるか確かめる。

1枚1分、1枚1主張などは整理の目安として使う。比較図をじっくり説明する場面や、短い段階表示もあるため、固定枚数より実際の説明と理解にかかる時間で調整する。
