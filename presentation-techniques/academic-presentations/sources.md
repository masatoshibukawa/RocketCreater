# 研究プレゼンの出典と確認範囲

確認日: 2026-11-07。日本語・英語・フランス語・スペイン語の26件。原著の実験・調査、研究データの表示を論じる論文、大学等の実務ガイド、特定制度の条件を分ける。教材が学術誌に掲載されていても、全てを効果検証実験とは扱わない。

## 確認方法

原文の本文、規則、抄録、方法・結果の該当箇所を確認し、制作案と区別した。R01は出版社PDFの方法・結果・考察を確認した。全引用論文の再解析、発表動画全編の評価は行っていない。

長時間調査ツールは認証が完了せず、公開ページの直接検索・閲覧で進めた。PSUのR01ミラーはタイムアウトしたため出版社版を利用した。NIHの検索結果にあったJournal Club Toolkitは404、AGU26の詳細は動的ページから本文を十分取得できなかったため、具体的な時間・条件の根拠に採用していない。
