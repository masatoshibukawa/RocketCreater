中心となる問いは、**何を調べ、何が分かり、どの根拠で、どこまで言えるか**である。進捗報告では未解決の点と求める助言、研究計画では何をどう確かめるかが加わる。

日本語・英語・フランス語・スペイン語の大学・学会・主催者資料と原著研究を参照する。専門家の助言、実験・調査の知見、特定制度の規則、こちらの制作案を分ける。26の出典記録を、26本の効果検証研究とは数えない。

全員へ同じ順序、1枚当たりの秒数、英語の話速を強制しない。分野、聴衆、発表目的、質疑を含むかどうか、主催者の指定を先に確かめる。
